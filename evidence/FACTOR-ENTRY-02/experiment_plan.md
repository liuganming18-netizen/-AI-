# FACTOR-ENTRY-02 实验方案：四组实验方法复核与改善来源验证

## 1. 工单背景与复核目标
- **工单编号**：FACTOR-ENTRY-02
- **研究边界**：纯离线隔离研究，不替换正式策略，不修改 UI、采集器、生产数据、模拟开仓闸门或账本。
- **复核动机**：上一轮汇总汇报（Baseline 205 笔 +101.53，Flow 122 笔 +32.42，Crowding 169 笔 +272.55，Combined 102 笔 +143.83）仅为待验收结果。必须从样本去重、时点对齐、数据缺失偏差、单因子独立贡献和微观路径上进行全面复核，确认上述改善是真实阿尔法，还是数据缺失导致的假象。

## 2. 第一阶段：证明比较成立的实施规约
1. **分阶段界定与时空范围**：
   - `TRAIN_IN_SAMPLE`: 2021-12-01 00:00:00 UTC ~ 2023-12-31 23:59:59 UTC
   - `VALIDATION`: 2024-01-01 00:00:00 UTC ~ 2024-12-31 23:59:59 UTC
   - `HOLDOUT_TEST`: 2025-01-01 00:00:00 UTC ~ 2026-10-18 01:00:00 UTC
   - 明确上一轮主报表汇报的 205/122/169/102 笔数字属于**全样本总和**。必须同时给出各阶段准确数字。
2. **参数与阈值选择过程披露**：
   - 坦诚披露：在 FACTOR-ENTRY-01 中，回测脚本是一次性遍历全时段计算输出，虽然规则设定初衷是基于早期经验，但留出期数据在同一批次中被直接观察到。因此，严格定义下不能宣称留出期为“未被污染的完全盲测留出”，必须以科学探索性视角定性。
3. **原 296 笔与现 205 笔去重映射与差异核销**：
   - 原 296 笔去重后对应 204 笔唯一入场。
   - 现 205 笔包含了这 204 笔，并增加了 1 笔因连续回测覆盖至 2026-10-18 最新发生的 `METISUSDT` (2026-10-11)。
   - 建立完整的一对多映射表 `trade_mapping_296_to_205.csv`，列清窗口截断孪生交易与消除理由。
4. **特征时点与 PIT 可用性审计**：
   - 冻结 `timing_audit_contract.json`：详细记录 source_time、available_at、decision_time、匹配方向与最大陈旧限制。严禁未来最近邻、未来回填，缺乏发布证据的字段明确标注假设。
5. **同一可用数据范围与共同基准 (Common Baseline)**：
   - 核心纠偏：四组必须在同一可用数据范围公平比较。
   - 分别报告因缺失数据排除、规则拒绝、执行拒绝和实际成交的数量。
   - 补充“共同可用样本基线”：排除 2022 年因 Metrics 缺失而被拒单的 24 笔交易，在纯非缺失的 181 笔共同样本上重新评估基线与各组表现。

## 3. 第二阶段：微观路径归因与敏感性检验
1. **微观收益与路径提取**：
   - 针对 Crowding 保留与过滤的每一笔交易，提取入场后 15m、1h、4h 收益。
   - 记录持仓期间的 MAE / MFE 及先后发生时间。
2. **回落类型解耦**：
   - `EARLY_ADVERSE` (入场即弱)：入场后未产生有效 MFE（MFE < 0.5R），先达到 MAE >= 0.8R。
   - `MFE_PULLBACK` (浮盈回吐)：曾达 MFE >= 1.5R 但最终平仓 net_pnl <= 0。
   - 明确定义早期回落率 = `EARLY_ADVERSE 笔数 / 实际入场笔数`。
3. **利润集中度与剔除敏感性测试**：
   - 计算利润前 5 笔交易的集中度百分比。
   - 剔除前 5 笔最大盈利交易后，重新计算胜率、盈亏比 PF 和净期望，评估策略对“极少数幸运交易”的依赖度。

## 4. 第三阶段：有限消融与单因子独立贡献
1. **Crowding 实际指标拆解**：
   - 子规则 A：散户多空比 `retail_account_ls_ratio <= 3.0`
   - 子规则 B：大户持仓多空比 `top_position_ls_ratio >= 0.60`
   - 子规则 C：结算资金费率 `funding_rate <= 0.0005`
2. **单因子剥离与消融测试**：
   - 在共同可用样本 (181 笔) 上分别测试：
     - 单独 A (Only Retail)
     - 单独 B (Only TopPos)
     - 单独 C (Only Funding)
     - A + B
     - A + C
     - 全部 A + B + C (完整 Crowding)
   - 明确回答每项指标的真实触发次数、过滤笔数与净盈亏贡献。

## 5. 最终结论四个核心问题回答框架
- ① 原四组比较是否成立？
- ② Crowding 是否确实减少“买入后立即回落”？
- ③ 改善是否依赖少数交易或单一时期？
- ④ 哪些仍未证明？
