# STEP1-C｜因子契约与四组实验边界审计结题报告

## 一、工单概述与审计边界

本工单（`STEP1-C`）严格遵循只读审计原则，对当前工程中的流数据、持仓量（OI）及大户情绪因子研究体系进行全面的定义、版本、时间可用性与测试缺口整理。
本审计**未修改任何工程代码、未重算任何特征、未重新运行回测实验、未调整任何阈值或参数**。
所有发现与候选表均基于历史产物、代码静态审计以及对 Work 交付的 [`evidence/FLOW-DATA-01/`](file:///Users/boos/Desktop/威科夫因子共振趋势/evidence/FLOW-DATA-01) 真实物理数据的对照核验。

> [!IMPORTANT]
> **结论声明与限制**：
> 1. 本工单仅提供“因子与实验冻结候选表”及“前视偏差与冲突清单”，**绝不宣称因子有效，亦不认定历史回测已正式通过**。
> 2. 由于发现 `FLOW-OI-01` 存在严重的当根 K 线未收盘前视泄露（Lookahead Bias），受未来数据影响的原回测结果（包括四组实验总收益、胜率、PF、走弱笔数下降等）**已正式登记为不可用于实盘与正式投产决策**。
> 3. 历史旧产物原样保留于 [`evidence/FLOW-OI-01/`](file:///Users/boos/Desktop/威科夫因子共振趋势/evidence/FLOW-OI-01)，不删除、不覆盖。

## 三、五大核心冲突与前视偏差清单

详细代码行与物理证据请参见 [05_因子与实验冻结候选表及冲突清单.md](file:///Users/boos/Desktop/威科夫因子共振趋势/evidence/STEP1-C/05_因子与实验冻结候选表及冲突清单.md)：

1. **当根 K 线未收盘前视泄露（严重度：致命 / P0）**：
   - **代码位置**：[`scripts/generate_flow_oi_01.py#L90-L96`](file:///Users/boos/Desktop/威科夫因子共振趋势/scripts/generate_flow_oi_01.py#L90-L96)
   - **机制**：样本快照时刻 `ts` 为整点（如 `12:00:00.000`），`df_c["open_time"] <= ts` 匹配到了 `open_time == ts` 的蜡烛。该蜡烛在 `12:59:59.999` 才收盘。决策时刻根本无法获取其成交量、主动买入比例与影线。
2. **Metrics 统计桶可用性时间错位（严重度：高 / P1）**：
   - **代码位置**：[`scripts/generate_flow_oi_01.py#L125-L131`](file:///Users/boos/Desktop/威科夫因子共振趋势/scripts/generate_flow_oi_01.py#L125-L131)
   - **机制**：5 分钟桶数据在桶结束（`create_time + 300_000`）并在交易所计算完成后才可消费，直接取 `create_time <= ts` 包含了未来 5 分钟的统计量。
3. **硬编码 COMPLETE 掩盖历史真实数据真空（严重度：高 / P1）**：
   - **代码位置**：[`scripts/generate_flow_oi_01.py#L169`](file:///Users/boos/Desktop/威科夫因子共振趋势/scripts/generate_flow_oi_01.py#L169)
   - **证据**：根据 Work `FLOW-DATA-01` 审计，币安官方归档中 2022 年 metrics 数据存在 87% 的缺失（如 `APEUSDT`、`OPUSDT`、`DYDXUSDT` 等），上游物理无数据。生成脚本将其填 0 并标为 `COMPLETE`，伪造了数据完备性。
4. **窗口代际 15 分钟快照时戳偏差（严重度：中 / P2）**：
   - **机制**：EA04 的 163 笔 `cand_ev` 采用固定整点快照，而旧版 42 笔 `old_cand` 的快照时戳偏移了 15 分钟，两代样本对齐精度不一致。
5. **机械硬过滤对趋势策略肥尾大赢家的钝化误伤（严重度：高 / 策略逻辑缺陷）**：
   - **机制**：Group 4 规则将放量突破拦截为“极端放量见顶风险”，错失了全周期盈利贡献最大的 `SOONUSDT`（+188.26 USDT）与 `SAFEUSDT`（+22.43 USDT），导致策略总收益从 +101.54 暴跌至 -14.62 USDT。

## 四、因子与实验冻结候选建议

```
┌────────────────────────────────────────────────────────────────────────┐
│                        STEP1-C 状态决议矩阵                             │
├──────────────────────────┬─────────────────────────────────────────────┤
│ 1. 27 项因子字段定义     │ [通过] 契约与命名严禁项已冻结               │
│ 2. EA04 / FE09 账本绑定  │ [通过] 205 笔样本身份与净盈亏基准一致       │
│ 3. FLOW-OI-01 回测结果   │ [废弃] 存在当根未收盘严重泄露，不可采信     │
│ 4. 2022 年大户指标数据   │ [废弃] 官方源头缺失 87%，不可用默认值冒充   │
│ 5. 5m 细拆与聪明钱       │ [未实施/不可用] 官方历史无 5m，聪明钱无历史 │
└──────────────────────────┴─────────────────────────────────────────────┘
```

### 准予冻结（作为 STEP2 修复基准）：
- **字段物理契约**：严格按 [01_因子契约与字段映射表.md](file:///Users/boos/Desktop/威科夫因子共振趋势/evidence/STEP1-C/01_因子契约与字段映射表.md) 规定的 27 个标准字段与命名红线执行；
- **点位时间可用性契约（严格 PIT）**：
  - K 线只读已收盘蜡烛：`close_time < ts`（或上一根 `open_time <= ts - bar_interval`）；
  - 统计桶只读已生成发布桶：`create_time + 300_000 <= ts`；
- **缺失与异常契约**：官方源头缺失记录必须显式标记为 `MISSING`，严禁填充默认 0，严禁虚标 `COMPLETE`。

### 明确不可用与废弃项：
- `evidence/FLOW-OI-01/` 中的所有评价指标、胜率、PF 改善及走弱消除统计全部作废；
- 5m 历史细拆方案（币安官方历史仅支持从 2025-10 起的 5m 数据）；
- 聪明钱（Smart Signal）因子（仅有当前单点快照，无历史时序）；
- 全市场/大户多空平均持仓价因子（交易所未发布，不可用 VWAP 冒充）。
