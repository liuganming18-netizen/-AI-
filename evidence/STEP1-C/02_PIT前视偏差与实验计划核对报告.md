## 二、核心前视偏差解剖：为什么 `open_time <= ts` 不是完整 PIT 证明？

### 1. 物理事实与时间轴真相
在币安行情系统中，一根 1 小时 K 线代表的时间范围是：
$$[\text{open\_time}, \text{close\_time}] = [T, T + 3,599,999\text{ ms}]$$
例如，`open_time = 17:00:00.000` 的 1h K 线，其收盘时刻是 `17:59:59.999`。

- **决策时刻**：全部 227 笔候选的 `snapshot_time_ms` 均严格处于整点（如 `2021-12-23 17:00:00.000`）；
- **代码行为**：执行 `df_c["open_time"] <= ts` 时，包含了 `open_time == 17:00:00.000` 这根 K 线；
- **泄露真相**：
  在 `17:00:00.000` 这一瞬间，从该整点开始形成的 1h K 线**连一秒钟都还没走完**！
  然而，代码从中提取了：
  - `bar_volume` / `bar_quote_volume`：未来整整 60 分钟内发生的全量成交额；
  - `bar_taker_buy_ratio`：未来整整 60 分钟内主动买卖力量博弈的最终胜负比率；
  - `bar_upper_shadow_ratio`：未来整整 60 分钟内价格冲高回落形成的最终上影线形态；
  - `bar_return`：未来整整 60 分钟的价格真实涨跌幅！

### 2. 实证典型案例（UNIUSDT）
| 数据项 | 实际数值 | 现实发生时间 |
| :--- | :--- | :--- |
| 候选标识 | `cand_ev_..._binance_UNIUSDT_1639627200000_1640278800000` | — |
| 信号快照时刻 `snapshot_time_ms` | `2021-12-23 17:00:00.000` | 决策发生的当下这一秒 |
| 提取的 K 线 `open_time` | `2021-12-23 17:00:00.000` | 同一整点瞬间 |
| 提取的 K 线 `close_time` | `2021-12-23 17:59:59.999` | **比信号时刻晚整整 59 分 59 秒** |
| 提取的成交量 `bar_volume` | `922,120 UNI` | 17:00 到 18:00 一整小时才累计产生的量 |
| 提取的收益率 `bar_return` | `-0.2694%` | 17:00 到 18:00 一整小时后的收盘涨跌 |
| 提取的主动买比 `bar_taker_buy_ratio` | `0.4578` | 17:00 到 18:00 的最终主动买入占比 |

**结论**：在 17:00:00 进行入场决策时，上述三个指标在现实世界中**根本不存在**！策略实质上是在“预知了未来一小时量价最终结果”的前提下做出过滤决策。

## 三、特征（自变量）与事后标签（因变量）的边界混淆

在 FLOW-OI-01 报告中，作者得出核心结论：“引入主动成交与价格过滤后，早期走弱率由 32.68% 降至 29.53%，成功规避了 23 笔早期走弱”。

然而，审计发现此处存在严重的**因果倒置与标签泄露**：
1. **因变量（事后标签）定义**：
   - `fwd_ret_15m`、`fwd_ret_1h`：入场后未来 15 分钟与 1 小时的价格回报；
   - `EARLY_WEAKNESS`（早期走弱）：当 $r_{4h} < 0 \land mfe_{atr, 4h} < 0.5 \land mae_{atr, 4h} \ge 0.5$ 时判定为早期走弱。
2. **自变量（特征）的实际构成**：
   - 由于前述前视偏差，所谓“突破当根”的 `bar_return` 和 `bar_upper_shadow_ratio` 本身就是入场后未来 1 小时的价格轨迹！
3. **边界击穿真相**：
   - 用未来 60 分钟的价格跌幅和冲高回落形态（自变量），去预测未来 15m/1h/4h 是否会走弱（因变量），**无异于用未来的答案去预测未来**！
   - 因此，“早期走弱减少 23 笔”并非微观因子具有先验预测力，而是直接利用了泄露的后验行情数据。
