## 一、工单概述与纪律遵守声明

本工单（`FRAME-VERIFY-02`）受命对两个 Work 窗口分别交付的 **`FRAME-PIT-01`**（防未来数据前视门禁）与 **`FRAME-FIT-01`**（实验登记、配置冻结与防过拟合约束）开展独立的技术核验。

本轮验证严格恪守以下纪律：
1. **调用真实入口，拒绝模拟空转**：打在实际生产代码与研究提取函数上，严禁用自写模拟逻辑、关键词搜索或硬编码错误字符串代替真实行为检验；
2. **零修改与零污染**：未修改任何 Work 负责的实现代码，未触碰生产数据库、服务、采集器或交易账本，所有反例均在隔离临时沙箱与内存对象上运行；
3. **如实出具技术裁决依据**：测试失败直接返回非零退出码（Exit Code 1），统计结论由测试套件执行结果动态驱动生成，绝不粉饰太平；
4. **结论声明**：本单仅出具客观技术验证结果与问题归属清单，最终验收由 Codex 裁决；本单不宣称策略盈利、不解除正式回测或实盘资格。

## 三、两大优先核心问题实测结论与漏洞定性

### 1. 【问题 A】FLOW-OI 实验入口是否仍绕过 PIT？ —— **【FAIL / 严重漏洞仍存】**
- **实测报告**：[02_FLOW_OI实验入口绕过PIT实测.md](file:///Users/boos/Desktop/威科夫因子共振趋势/evidence/FRAME-VERIFY-02/02_FLOW_OI实验入口绕过PIT实测.md)
- **实际被测入口**：`evidence/FLOW-OI-01/generate_flow_oi_01.py::extract_features_for_candidate`
- **实测行为**：
  在快照整点 `12:00:00` 注入未收盘 1h 未来蜡烛（包含极端未来成交量 `volume=8888888.0` 和暴涨收盘价 `close=148.0`）及未结束 5m Metrics 桶（`ts=12:00:00`, `OI=99999.0`）：
  - 代码毫无察觉地将未收盘未来蜡烛吃入特征字典，`bar_volume` 赫然变成 `8888888.0`，`bar_return` 计算出未来暴涨 `45.1%`，`oi_base` 吃入未来 5 分钟数据；
  - 数据覆盖状态直接标记为 `"COMPLETE"`；
  - 产物字典中**完全缺失 `pit_proven` 或 `qualified` 等资格鉴别字段**。
- **问题根源**：`FRAME-PIT-01` 仅在 `event_trend_v0_1` 策略内部接入了 K 线闭合闸，而将真实产生 FLOW-OI 四组实验特征的入口 `generate_flow_oi_01.py` 完全遗漏，未做任何修改与接入。
- **责任归属**：**`FRAME-PIT-01`**
- **最小整改要求**：将 `generate_flow_oi_01.py` 中的 K 线切片修正为 `close_time < ts`，5m 桶修正为 `ts + 300000 <= ts`，引入 `pit_guard` 硬校验并透出资格标记。

### 2. 【问题 B】第一次正式实验能否正常启动？ —— **【FAIL / 死锁阻断合法业务】**
- **实测报告**：[03_首次正式实验启动死锁验证.md](file:///Users/boos/Desktop/威科夫因子共振趋势/evidence/FRAME-VERIFY-02/03_首次正式实验启动死锁验证.md)
- **实际被测入口**：`框架/backend/backtest_api.py::create_run` → `guard_create`
- **实测行为**：
  构造一个模式为 `formal`、配置完整分组策略、未受样本污染、已成功冻结、但尚无任何运行记录（`runs == []`）的合法首次正式实验：
  - 调用 `create_run` 发起创建，接口返回 **HTTP 409 Conflict** 拒绝！
  - 报错阻断项为：`尚无已登记运行（试验次数为 0，不能宣称有结果）`。
- **死锁原因**：
  `guard_create` 在创建运行阶段错误地调用了 `reg.formal_eligible(eid)`，后者硬编码了对 `exp["runs"]` 的非空检查。
  导致：**必须已有运行记录才能创建运行；但要产生运行记录，又必须先创建运行**。在正式模式下，没有任何合法新实验能够启动！
- **责任归属**：**`FRAME-FIT-01`**
- **最小整改要求**：严格解耦“运行启动许可”与“结果正式交付资格”。`guard_create` 只校验冻结状态、身份一致性、分组自洽性与防污染，绝不得在创建运行阶段要求 `runs` 或 `trials` 非空。
