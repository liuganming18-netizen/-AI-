## 二、 终点错位深层根因分析与代码级修复

### 1. 终点脱节相差 66 天的底层机理
上一工单中，主图视窗终点为 `1736222400`（2025-01-07 12:00:00 UTC），而资金图终点停留在 `1730505600`（2024-11-02 00:00:00 UTC），相差整整 66 天，却因断言仅比较了 `fromDiffSec` 而被放水判定为通过。
深入排查发现三个致命缺陷：
1. **程序化聚焦广播漏发**：主图选中交易或订单定位时，在调用内部 `setViewport` 后，未能将目标视窗范围通过 `crosshairBus.emitViewport` 毫秒级广播给资金图，资金图停留在初始的全域视窗中；
2. **稀疏 Whitespace 锚点下的时间轴映射失效**：`LabFundingPanel.tsx` 在接收外部视窗广播时，直接调用官方库的 `chart.timeScale().setVisibleRange({ from, to })`。由于资金图采用离散日结 Whitespace 补齐，在稀疏时间网格下，`setVisibleRange` 无法精确落位于连续秒制区间；
3. **数据到达时的无脑覆盖**：在 `LabFundingPanel.tsx` 第 459 行，当权益数据刷新到达后，直接执行了 `fitContent()`，将已经由主图对齐的视窗强行拉回了三年全域；
4. **右侧边距（rightOffset）不统一**：主图配置了 4 根蜡烛的右侧留白，而资金图配置为 2，导致即使逻辑视窗相同，右侧物理终点也存在柱偏移。

### 2. 代码级修复方案
1. **统一时间轴留白与逻辑映射**（`LabFundingPanel.tsx`）：
   - 将资金图 `timeScale.rightOffset` 从 2 统一为 4，与主图物理对齐；
   - 接收 `crosshairBus.registerViewport` 广播时，使用 `ts.timeToIndex(from)` 与 `ts.timeToIndex(to)` 转换为离散网格索引，通过 `ts.setVisibleLogicalRange({ from: fromIdx, to: toIdx })` 进行绝对精确落位；
   - 引入 `targetViewportRef`，在数据到达时优先保留既有视窗，彻底阻止 `fitContent()` 将已对齐视窗无脑覆盖。
2. **广播通道完整闭环**（`LabChartPanel.tsx`）：
   - 在选中交易、订单点击聚焦的 `useEffect` 中，在调用 `handle.setViewport` 的同时，立即通过 `crosshairBus.emitViewport('lab-chart', fromMs, toMs + stepMs)` 广播给资金图；
   - 增加手动视窗恢复的独立优先同步 Effect，确保深链打开时第一时间将手动视窗广播至资金图。
3. **手动视窗恢复与自动交易聚焦彻底解耦**（`LabChartPanel.tsx`、`BacktestWorkbench.tsx`）：
   - 在交易自动聚焦 Effect 中加入守卫：若当前存在有效的 `manualViewport`，坚决不被第一笔成交的自动聚焦覆盖；
   - 点击订单或成交行时显式清理 `manualViewport`，实现“恢复手动视窗”与“订单自动居中”两种能力的清晰解耦。
