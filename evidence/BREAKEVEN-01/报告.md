## 三、差异从哪来（逐笔分解）

### 3.1 B（1R 保本）

| 项 | 笔数 | 金额（U） |
|---|---:|---:|
| 保本触发 | 75 | — |
| 触发后结局没变（价格没再回到保本价） | 47 | 0 |
| A 本来要亏 → B 少亏 | 12 | A -91.83 → B +3.40，**少亏 95.24** |
| A 本来要赚 → B 提前扫出 | **16**（触发且 A 盈利的共 63 笔，其中 47 笔价格没回到保本价） | A +137.33 → B -1.01，**放弃 138.34** |
| **净效果** | 13 好 / 16 坏 / 177 平 | **-42.98** |

> 说明：13 笔「变好」里有 12 笔是保本直接救回来的（合计 +95.24 U），
> 另 1 笔是同 run 资金耦合（前一笔被提前平仓 ⇒ 后一笔仓位变化，+0.11 U），不是保本直接作用。
> 16 笔「变坏」全部是保本直接扫出，这 16 笔本身 A 合计 +137.33 U、B 合计 -1.01 U，差 -138.34 U。
> 另一组数字容易混淆：**「触发且 A 盈利」共 63 笔，A 合计 +981.16 U、B 合计 +842.83 U**——
> 这 63 笔里只有 16 笔真的被扫出，其余 47 笔保本止损从头到尾没被触及，结局与 A 完全相同。
> 所以 **-138.34 U 只能对应 16 笔**，不能拿 63 笔的合计去当基数。

按基准最大浮盈分档（A 的 MFE）：

| MFE 区间 | 笔数 | A 净额 | B 净额 | 差 |
|---|---:|---:|---:|---:|
| 0 ~ 1R | 131 | -834.02 | -833.91 | +0.11 |
| 1 ~ 2R | 49 | +178.51 | +204.14 | **+25.62** |
| 2 ~ 3R | 13 | +150.21 | +138.14 | -12.07 |
| ≥ 3R | 13 | +560.61 | +503.96 | **-56.65** |

这张表说明一件事：**1R 保本只在「刚过 1R 就回落」的那一档赚钱（+25.6 U），
但在真正的大行情（≥3R）上代价最大（-56.7 U）。** 因为能涨到 3R 以上的单，
中途几乎都会回踩到 1R 附近，保本止损把它们全部扫掉。

> 注意：`0~1R` 那一档的 +0.11 U **不是保本的作用**（这一档根本没触发保本），
> 而是前面说的那笔同 run 资金耦合。

### 3.2 C（2R 保本）

| 项 | 笔数 | 金额（U） |
|---|---:|---:|
| 保本触发 | 26 | — |
| 触发后结局没变 | 25 | 0 |
| A 本来要亏 → C 少亏 | 1 | **少亏 3.05** |
| A 本来要赚 → C 提前扫出 | 0 | 0 |
| **净效果** | 1 好 / 0 坏 / 205 平 | **+3.05** |

原因很直接：**A 自己已经有 2R 跟踪止损**（冻结规则 §4）。到了 2R，
多数情况下 4h 通道给出的止损已经比保本价更紧，或者价格压根没回头。
所以 C 与 A 的差别被压到几乎为零。

### 3.2.1 C 唯一生效的那一笔（`paired_trades.csv` 里可查）

**1000LUNCUSDT，2023-06-04 03:15 入场**

| 项 | A 原始 | C（2R 保本） |
|---|---|---|
| 入场 / 初始止损 / R | 0.09213 / 0.082932 / 0.009198 | 同左 |
| 2R 触发 | — | 2023-06-04 16:00，触及阈值 0.11053（=入场+2R） |
| 保本价 / 生效 | — | 0.09227（16:15 起生效） |
| 退出 | 2023-06-06 08:00 @ 0.08940（跟踪止损） | 2023-06-05 16:00 @ 0.09224（保本止损） |
| 净额 | **-3.07 U** | **-0.02 U** |
| 持有 | 52.8 小时 | 36.8 小时 |

这一笔是 C 全部 +3.05 U 的来源。原因很巧：触发 2R 后，A 的 4h 通道止损在 0.08940，

这不是「保本普遍更优」，只是**这一笔的 4h 通道恰好比保本价更松**——

所以 C 的 +3.05 U 不具备可复制性，不能当「2R 保本有效」的证据。

## 六、基准 A 的复现校验（不一致的那 1 笔）

- 校验方式：重跑同一 (组, 标的, 窗口)，逐笔比对 `net_pnl` 与 `FULL_SWEEP` 原始记录。
- 结果：**285 笔中 284 笔逐位一致（差 ≤ 1e-6 U）**，1 笔不一致。

**不一致的那笔：TRXUSDT，2023-01-16 ~ 2024-01-16 窗口**

| 项 | 原始记录 | 本次重跑 |
|---|---:|---:|
| 净额 | -3.840894 | -3.858656 |
| 仓位 | 865 | 869 |
| 该 run 的候选数 | 2 | 1 |

**根因（已定位到具体事件，不是猜测）**：
原始全扫描跑在 **2026-10-18 03:57~05:37**，而 `trading_core/pit_guard.py`
在 **2026-10-18 21:54** 被 PIT 整改（FRAME-PIT-01）改过：OI 可用判据从
`ts <= decision` 改成 `ts + 5m <= decision`（5m 桶起点必须加 5 分钟才算已收盘）。

改完之后，该标的 2023-05-29 那个事件的 6 小时 OI 增长从「≥2%」变成 **1.07%**，
被 OI 门槛拒掉（`OI_REJECTED: 6小时OI增长率不足2%(实际: 1.07%)`），
于是这个 run 的候选从 2 个变 1 个。少了一笔 -9.86 的亏损之后，
账户权益回到 2000，下一笔仓位从 865 变成 869，净额随之变化 **0.0178 U**。

**影响量级**：0.0178 U，占该笔 0.46%，占全样本净额 55.31 U 的 **0.03%**。
**处理**：不回退 PIT 守卫（那是安全修复，回退等于重新引入未来函数），
以当前代码的 A 作为基准；A/B/C 三组全部用同一份代码、同一个 run，**组间比较不受影响**。

## 七、怎么读这个结论（三条限制）

1. **样本不是「296 笔」，是 206 个独立信号。**
   原 `FULL_SWEEP` 的 200 个窗口重叠约 97%，同一个信号会被截断成不同结局
   （窗口末尾强平 vs 持有到 10 天）。按 `signal_id` 去重后是 206 个，
   其中 57 个存在多窗口不同结局。原报告的「296 笔 / 276 笔唯一交易」是重复计数。

   还要再收一层：这 206 个是**候选编号**，不是 206 次独立行情机会。
   有 5 组是「同标的、同入场时刻、同一根 K 线」，只因 4h 箱体起点不同而生成两个候选，
   初始止损差 0.0004%~0.1%、仓位差 0~1 股 —— 同一笔交易被数了两次。
   按事件级去重后是 **201 笔**，A +105.44 / B +52.54 / C +108.49，
   **B 的净损失从 -42.98 扩大到 -52.90，C 仍是 +3.05**。
   主表保留候选级（这是策略自身候选空间的定义），去重结果见 `out/dedup_sensitivity.json`。
   **两种口径下结论方向完全一致，只是 B 的亏损更明确。**

2. **这批样本本身证明不了策略赚钱。** A 的 206 笔合计 +55.31 U，
   每笔 +0.268 U，标准差 17.86，**t = 0.22**（B 组 t=0.05，C 组 t=0.23）——
   三组都与 0 无法区分。所以本单只能回答「保本让结果变好还是变坏」，
   不能回答「策略值不值得做」，更不能因为 C 比 A 多 3 U 就说 C 更好。

3. **保本救不了「一开仓就错」的单。** 单笔最差 -10.75 U、最差 5 笔 -52.59 U，
   A/B/C 三组**完全一样**。因为那些单从来没到过 1R。
   保本只能改「先赚后亏」的单，而这类单在亏损总额里只占约 9.5%（-91.83 / -965.47）。

## 八、边界与未完成项

### 已遵守的边界
- `策略/`、`框架/`、`UI界面/` 零改动（哈希见 `out/versions.json`）；
- 未改交易闸门、生产账本、采集器；未下载/迁移数据；未扩大币池；
- 未跑四组因子实验；未做参数搜索（只跑 1R / 2R 两个工单指定阈值）；
- 原产物只读，新结果只写 `evidence/BREAKEVEN-01/`。

### 未完成项（明确不做，不拿替代品冒充）
1. **震荡吸筹策略无法测**：`research_cache/w1..w11` 的代码/配置/币池/逐笔本机全无，
   只剩一张汇总表，入场规则不可复现（详见 `ACCUM-STRAT-01`）。
   **本单未用任何替代入场条件冒充它。**
2. **没有 1 分钟及更细价格路径**：本机最细是 15m。因此保本触发最多滞后 15 分钟、
   止损抬升最多滞后 15 分钟（下一根 bar 才生效）。这会让 B/C 的效果**偏保守**
   （真实盘中保本会更早触发，收益与代价都会放大）。
3. **账户级回撤未计算**：样本是单标的独立账户，不构成组合，按工单要求不得冒充。
4. **资金费只算已发生部分**：保本价不含触发后的未来资金费，因此少数保本退出
   仍会小亏（B 17 笔合计 -1.38 U，平均 -0.08 U/笔）。
5. **C 与 A 的 2R 跟踪存在粒度差**：A 用 4h 收盘判 2R，C 用 15m 最高价判 2R，
   C 可能早最多 4 小时激活。这是规则定义差异，不是实现偏差，但会让 C 显得略「更早保护」。
