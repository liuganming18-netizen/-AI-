### 1. 核查点一：`custom_stoploss` 抛出 `RuntimeError` 是否被引擎捕获

#### (1) 源码证据
- **调用位置**：`evidence/FT-BASELINE-01/.venv/lib/python3.11/site-packages/freqtrade/strategy/interface.py` 第 1567–1569 行：
  ```python
  if self.use_custom_stoploss and dir_correct:
      stop_loss_value_custom = strategy_safe_wrapper(
          self.custom_stoploss, default_retval=None, supress_error=True
      )(
          pair=trade.pair,
          trade=trade,
          current_time=current_time,
          current_rate=(bound or current_rate),
          current_profit=bound_profit,
          after_fill=after_fill,
      )
  ```
- **包装器捕获逻辑**：`evidence/FT-BASELINE-01/.venv/lib/python3.11/site-packages/freqtrade/strategy/strategy_wrapper.py` 第 34–39 行：
  ```python
  except Exception as error:
      logger.exception(f"{message}Unexpected error {repr(error)} calling {f}")
      if default_retval is None and not supress_error:
  ```

## 二、 任务二：最小修复清单

针对上述两项复现事实，反重力在隔离目录 [`evidence/FT-BASELINE-05/`](file:///Users/boos/Desktop/威科夫因子共振趋势/evidence/FT-BASELINE-05/) 实施了最小闭环修复：

1. **唯一候选严格绑定（彻底废除时间窗替换）**：
   - 在 [`user_data/strategies/WyckoffEventTrendBaseline.py`](file:///Users/boos/Desktop/威科夫因子共振趋势/evidence/FT-BASELINE-05/user_data/strategies/WyckoffEventTrendBaseline.py) 的 `confirm_trade_entry`、`custom_stake_amount` 与 `custom_stoploss` 中，**彻底删除时间窗兜底分支**，强制仅按 `candidate_id == entry_tag` 进行精准唯一匹配。
2. **开仓前两道防线严格拒单与记录原因**：
   - 防线一（`custom_stake_amount`）：候选缺失或 ID 不匹配时直接返回仓位 `0.0`；
   - 防线二（`confirm_trade_entry`）：若候选缺失、ID 不匹配、P0 非法（None/NaN/<=0）或 P0 >= rate 时，记录 ERROR 日志并 `return False`，引擎记录拒单原因并统计入 `Rejected Entry signals`。
3. **持仓后绑定异常持久化（状态落盘机制）**：
   - 在策略中引入运行有效性状态文件 [`user_data/run_validation_status.json`](file:///Users/boos/Desktop/威科夫因子共振趋势/evidence/FT-BASELINE-05/user_data/run_validation_status.json)；
   - 一旦持仓在 `custom_stoploss` 中检测到候选丢失或 P0 非法：
     - 调用 `record_invalidation()` 将状态标记为 `is_valid: False`、`status: INVALID`，记录发生阶段、时刻、标的、trade_id、enter_tag 等完整上下文，并即时持久化落盘；
     - 抛出 `RuntimeError`。
4. **统一指标与汇总入口门禁（Metrics Entrypoint Guard）**：
   - 建立统一指标与审计入口脚本 [`code/metrics_entrypoint.py`](file:///Users/boos/Desktop/威科夫因子共振趋势/evidence/FT-BASELINE-05/code/metrics_entrypoint.py)（以及同步兼容 [`code/02_build_audit_tables.py`](file:///Users/boos/Desktop/威科夫因子共振趋势/evidence/FT-BASELINE-05/code/02_build_audit_tables.py)）；
   - 入口第一步强制读取 `run_validation_status.json`：
     - 若状态非 `VALID` 或 `is_valid == False`，**坚决拒绝采纳，中断执行并退出非零码（Exit code 1），绝不生成任何指标表和对账表**；
     - 仅当状态合格时，才放行解析并生成指标。
