# FRAME-VERIFY-01｜01. 真实入口与绕过受控路径静态审查清单

## 一、审查背景与目标

本清单针对量化系统中的数据流转全链路（从底层存储、数据仓储、因子提取、策略执行到回测与 API 暴露），开展只读静态代码审查。
审查核心目标：
1. 梳理系统内所有实际存在的数据读取与执行入口（Real Entrypoints）；
2. 识别真实代码中是否存在**直接读取原始数据、绕过受控门禁的旁路（Bypass Paths）**；
3. 检查所谓的“安全约束”（PIT 门禁、Holdout 守卫、防改参指纹等）是否**仅作为孤立工具函数存在，而在真实实验/回测入口中未被调用或被空转绕过**。

## 三、绕过受控入口的具体物理路径（Bypass Paths）

### 绕过路径 1：因子提取直接 Glob 扫盘读取（P0 级旁路）
- **文件与行号**：[`evidence/FLOW-OI-01/generate_flow_oi_01.py#L44-L69`](file:///Users/boos/Desktop/威科夫因子共振趋势/evidence/FLOW-OI-01/generate_flow_oi_01.py#L44-L69)
- **代码实现**：
  ```python
  def load_symbol_data(sym: str, kind: str, timeframe: str = None) -> pd.DataFrame:
      if kind == "candles":
          pattern = f"{MARKET_DATA_DIR}/candles/binance/um/{sym}/{timeframe}/*.parquet"
      ...
      files = glob.glob(pattern)
      for f in files:
          dfs.append(pd.read_parquet(f))
  ```
- **绕过实质**：完全绕过了系统内建的 `MarketDataRepository`，绕过了任何时间窗口截断与发布延迟检查。任何研究者在编写因子时只要直接读取 parquet 文件，就等同于拥有了“全知全能的上帝视角”，能读到数据集内的任何未来时间点数据。

### 绕过路径 2：未收盘 K 线以“整点对齐”之名全量泄露（P0 级前视漏洞）
- **文件与行号**：[`evidence/FLOW-OI-01/generate_flow_oi_01.py#L120-L135`](file:///Users/boos/Desktop/威科夫因子共振趋势/evidence/FLOW-OI-01/generate_flow_oi_01.py#L120-L135)
- **代码实现**：
  ```python
  c_pit = df_c[df_c["open_time"] <= ts]
  bar = c_pit.iloc[-1]
  b_close = float(bar["close"])
  b_vol = float(bar["volume"])
  b_taker_buy_q = float(bar["taker_buy_quote_volume"])
  ```
- **绕过实质**：当突破信号发生在整点（如 `12:00:00`），`open_time <= ts` 取到的正是 `12:00:00` 开盘、`12:59:59` 收盘的这根 1h 蜡烛。代码声称是 PIT，但实际读取了这根蜡烛未来 60 分钟的完整成交量和收盘价。

### 绕过路径 3：回测 Runner 乐观对齐（P1 级时延忽略）
- **文件与行号**：[`框架/backend/backtest_runner.py#L386-L392`](file:///Users/boos/Desktop/威科夫因子共振趋势/框架/backend/backtest_runner.py#L386-L392)
- **代码实现**：
  ```python
  close_ms = sig_df["timestamp"].to_numpy(np.int64) + iv_sig
  if len(oi_ts):
      pos = np.searchsorted(oi_ts, close_ms, side="right") - 1  # <= close 的最近一条
      aligned[ok] = oi_val[pos[ok]]
  ```
- **绕过实质**：`oi_ts` 为交易所指标的生成/观测时间。在真实的物理网络中，`12:00:00` 生成的 5m OI 至少需要数秒乃至数分钟才会被推送到客户端。直接以 `oi_ts <= close_ms` 对齐，属于忽略网络和计算时延的乐观读取。虽然在 runner 末尾有 `oi_pit` 字典记录，但实际计算时已将乐观数据作为自变量喂入了策略。

### 绕过路径 4：防拟合守卫完全架空（P0 级选型泄露）
- **现存状态**：
  新策略 `event_trend_v0_1` 的代码树（`contracts.py`、`runner.py`、`engine_adapter.py`）中**完全没有导入任何 Holdout 守卫**。
  曾有的 `_legacy_archive_v31/segments.py` 中的 `assert_no_holdout` 已经被移入历史归档，新策略零调用。
- **绕过实质**：任何人都可以随意使用 2026 年甚至最新日期的数据作为回测样本，改动参数、重新挑选子集，没有任何物理拦截、没有任何试验日志审计，完全失去防过拟合（Data Snooping / P-hacking）保护。

## 四、第一阶段结论与整改靶标

1. **“伪约束”与“真绕过”并存**：系统虽然有 `trading_core/pit.py` 这种规范的 PIT 定义文件，但在因子研究核心脚本中被 100% 旁路绕过；
2. **防拟合机制全面真空**：除归档目录的历史残余外，当前活跃框架没有任何强制的 Holdout 物理隔离与改参追踪；
3. **靶标明确**：两个 Work 窗口分别承接的 `FRAME-PIT-01` 与 `FRAME-FIT-01` 必须将防护逻辑强制注入到 `MarketDataRepository`、`load_symbol_data`、`backtest_runner.py` 与策略入口处，严禁以“实现方自测文档”充当通过证明。
