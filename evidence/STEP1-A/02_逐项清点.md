### 3.3 初始资金

- `EventTrendConfig.initial_equity = 2000.0`（`config.py` 第 69 行）。
- **2125 个 run 的 `summary.trading_summary.initial_equity` 全部为 2000.0**，无例外。
- 注意：同文件第 67–68 行注释写「10000 USDT 是本轮研究口径，已写入每次 Run 的 inputs.json / summary」，
  与实际字段值 2000 不符 ⇒ 见 `03_冲突与未知.md` 第 4 条。

### 3.4 账户模式

- **单标的独立账户**：每个 run 目录 = 一个标的 + 一套 2000 本金 + 一套独立账本

- 因此 `max_active_positions = 3`、`max_total_risk_budget = 0.015`、`max_total_notional = 0.90`
  这些**组合级**限制在单标的账户里退化：一个标的最多 1 仓（`max_symbol_positions = 1`），
  组合级上限永远碰不到。
- 全工程**没有**跨标的共享账户的回测产物（`AUDIT-375-V3` 也明确「单币盈亏严禁解释为共享组合收益」）。
