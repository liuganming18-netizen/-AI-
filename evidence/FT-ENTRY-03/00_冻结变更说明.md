# FT-ENTRY-03｜冻结变更说明与验证方案

> **任务标识**：FT-ENTRY-03（严格突破前入场验证）  
> **验证目标**：严格验证 A 路线在“信号收盘价严格低于突破位 H”下能否提高交易质量。本轮不增加参数组合。  
> **基线对比**：1 组 Baseline（原突破入场） + 9 组 A 路线（严格突破前）。  
> **归档与继承**：FT-ENTRY-02 历史结果全量保全，新旧差异明确拆解，严禁混淆概念。

## 一、唯一规则变更对照

本轮对策略逻辑执行**单变量唯一规则修正**，所有其他外部与内部环境条件保持完全冻结。

| 规则维度 | FT-ENTRY-02（旧规则） | FT-ENTRY-03（本轮新规则） | 变更定性与目的 |
|---|---|---|---|
| **A 路线入场上限** | `close_p <= H + 0.1 * A` | **`close_p < H`** | **唯一规则修正**：收盘价必须**严格低于**当时可知的箱体突破位 H，杜绝越过突破位后的伪“提前入场” |
| **A 路线入场下限** | `close_p >= H - offset * A` | `close_p >= H - offset * A` | 完全冻结保持一致（`offset` 取 0.6, 0.4, 0.2） |
| **A 路线参数空间** | 9 组网格 (`offset`×`vol_mult`) | 9 组网格 (`offset`×`vol_mult`) | **完全复用，不增加任何新参数** |
| **突破兜底分支** | 无（未设兜底突破） | 无（未设兜底突破） | 本轮专注严格检验“纯粹突破前”入场的独立成效 |
| **OI 过滤条件** | 6h OI 增幅 $\ge 2.0\%$ | 6h OI 增幅 $\ge 2.0\%$ | 完全冻结保持一致 |
| **初始止损逻辑** | $L_r - 0.1 * A$（回踩低点） | $L_r - 0.1 * A$（回踩低点） | 完全冻结保持一致 |
| **跟踪止盈与退出** | 5.0% 启动，0.8% 跟踪，240h 超时 | 5.0% 启动，0.8% 跟踪，240h 超时 | 完全冻结保持一致 |
| **交易手续费率** | 0.05%（单边万五） | 0.05%（单边万五） | 完全冻结保持一致 |
| **资金与槽位管理** | 初始 2000 U，最多 3 个槽位 | 初始 2000 U，最多 3 个槽位 | 完全冻结保持一致 |

## 二、样本范围与输入资格的严格区分

根据 Work 审计反馈与独立核验，严禁将“样本变化”与“入场边界变化”混称为参数增益：

1. **输入资格版本与真实样本池**：
   - Work 冻结研究期清单（`evidence/FT-FACTOR-AUDIT-01/out/04_冻结研究期输入清单_v1.csv`）共列出 **241 个 L1 基础价量候选标的**；
   - 但这 241 个标的其 **L2 完整策略资格为 0**（因全池 OI 1h 因子无合格区间，映射与发布时点未证实）。因此，**不能直接把 241 个基础候选都标为完整策略合格**；
   - 当前 freqtrade 本地实际提供数据的标的为 74 个；
   - 经逐币区间核验，74 个标的中只有 **70 个标的**在研究期（2021-12-01 ~ 2024-12-31）满足 200 根 4h 预热并落在 L1 候选池内；
   - 其余 4 个标的（`AEROUSDT`, `AIXBTUSDT`, `AVAUSDT`, `CGPTUSDT`）上架太晚，无法完成预热，研究期内不具备候选资格。
   - 本轮 FT-ENTRY-03 回测中，**Baseline 与 9 组 A 路线统一在严格合格的 70 币样本池上运行**，确保两者的样本空间 100% 绝对一致。

2. **双重维度的独立拆解（非混称承诺）**：
   - 维度 A（边界收缩）：从 `close <= H + 0.1A` 到 `close < H`；
   - 维度 B（样本校准）：从名义 74 币（含 4 个无效币）到规范合格 70 币；
   - 新旧结果对比表中，单独列明交易数、胜率、净收益的差额，绝不将样本调整带来的波动粉饰为参数优化增益。

## 四、官方检查与合规原则

1. **取消“退出码0即PASS”**：
   - 必须真实解析 Freqtrade 官方 `recursive-analysis` 与 `lookahead-analysis` 的控制台输出与导出 CSV；
   - 若单币低频交易笔数不足官方分析工具门槛（10 笔），官方直接输出 `too few trades caught / Test failed / Cancelling`，必须实事求是标明为 **“未完成 (交易样本不足)”**，严禁使用脚本 returncode == 0 伪造通过。
   - 所有在官方工具未闭合条件下的回测结果，均明确声明为**探索性研究**。
2. **非空前缀一致性检验**：
   - 选取产生过真实候选的标的，通过截断未来数据供给，执行因果隔离测试，验证状态机前缀决策是否 100% 保持一致。
