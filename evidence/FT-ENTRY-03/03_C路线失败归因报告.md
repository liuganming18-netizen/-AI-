## 三、归因维度二：退出原因透视（亏损主要通过何种方式发生？）

**核心亏损 100% 来自固定硬止损（`stop_loss`）的高频触发**！

- 虽然跟踪止盈表现良好（胜率 82%、均赢 +20.5 U），但由于胜单占比不足 20%，产生的收益完全无法抵消占压倒性多数的止损磨损（总亏损逾 2,100 U vs 盈利仅 1,400 U）。

## 四、归因维度三：入场状态与机制缺陷（为什么在回踩阶段入场会失败？）

从威科夫量价因果与状态机设计剖析 C 路线的本质缺陷：

1. **“假回踩”的因果未闭合**：
   - C 路线在状态机处于 `SWEEP` 之后，只要价格落在 $L \le low \le L + Zone$ 且缩量阳线收盘，便立刻判定为 `RETEST` 并在该根收盘提前入场；
   - 然而在实际市场中，在箱体底部的“扫低缩量反弹”有极高概率只是**震荡区间内部的普通无序杂波**，根本不是主力二次测试蓄势；
   - 价格并未突破箱体上沿 $H$，上方依然面临沉重的箱体套牢盘与均线压制。
2. **止损锚点设置过窄且极易被扫**：
   - C 路线以扫低点 $S - 0.1A$ 作为硬止损；
   - 在尚未走出箱体的弱势震荡期，标的极易发生“二次下探”、“三次下探”或继续破位阴跌，频繁在 $S$ 附近打掉止损后重新拉起，导致胜率坍塌至 16%~20%。
3. **与 A 路线的本质对比**：
   - A 路线是在价格已经**成功完成 RETEST 并重新发起向上突破波段、收盘价攻入箱体上半部（$H - 0.6A$）且伴随成交量与 OI 双重放大**时才入场；
   - C 路线在底部左侧强行猜底，缺乏后续资金共振的确认，属于典型的因果倒置与胜率牺牲。

- 尤其在 2024 年牛市大背景下，净亏损依然高达 -204 U，胜率仅 18.5%，证明其缺陷绝非“市场环境不适”，而是**底层策略逻辑在统计上存在结构性负期望**。

- 在所有产生交易的 60 多个币种中，多达 **48 个币种（占比 80%）累计净盈亏为负**；
- 亏损分布在绝大多数主流与山寨币种中（如 `BIGTIME`, `COMP`, `ARK`, `CFX`, `BEL` 均累计亏损超过 -30 U）；
- 没有任何一个币种能够稳定跑赢其自身的止损磨损。

## 六、归因总括与最终处置结论

1. **定性归因**：C 路线（回踩阶段提前入场）的彻底失败，是由于其入场过早，试图在尚未证实突破动能的震荡左侧建仓，导致将大量“箱体内无序折返”误认为“缩量回踩测试”。
2. **定量归因**：亏损由近 **78% 的硬止损被扫单**高频累积而成，单笔平均亏损 -8.1 U，极端损失占比极低，全年度全币种弥散性亏损，具有不可逆的结构性负期望。
3. **策略决策**：**坚决停止 C 路线的任何后续参数调优与衍生拓展**，本轮归档结论作为其技术生命周期终止的历史封存凭证。
