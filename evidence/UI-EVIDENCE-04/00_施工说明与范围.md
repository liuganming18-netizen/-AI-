## 4. 判定纪律

1. **三态**：PASS / FAIL / UNVERIFIED。未验证不计入通过。
2. **来源必须真实**：字段路径要能在源文件里走到；走不到就写「字段不存在」，不写看起来像真的路径。
3. **哈希分两种**：`computed_by_test_script`（脚本自算）与官方来源（manifest / run.json.hashes）。两者不可混称。
4. **重复不算覆盖**：字节相同的截图只能算一张画面。
5. **对不上就 FAIL**：run_id 三方不一致、源目录不存在，一律失败，不回落固定目录代填。
6. **脚本改对 ≠ 端到端通过**：本轮只交付「脚本修改 + 离线测试」，集成验收待 A 通过后另开。
