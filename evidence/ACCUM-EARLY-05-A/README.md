## 一、核心交付成果提要

### 1. 规则与代码对照发现的重大断层（已标记给 05-B）
- **局部压制位定义脱节**：04-A 推荐的 `swing_high_k3_lookback48`（摆动高点）在 04-B 代码白名单中**未实现**（04-B 仅实现了 `prior_n_high` 与 `box_high`）。05-A 建议在最小决策中收敛使用 04-B 已支持的 `prior_n_high(N=24)`，避免扩增工程风险。
- **成交量量纲差异**：04-A 取名义额占比（`quote_volume`），04-B 取币数占比（`volume`）。05-B 应统一至名义额口径。
- **结构失效锚点差异**：04-A 以箱体下沿 L 为防守线，04-B 以本次扫低的针尖低点 `sweep_low` 为防守线。

### 2. 五项收敛决策摘要（待用户裁决）
1. **扫低对象**：推荐 **`box_low`（箱体下沿 L）**。依据：04-A 证明扫局部支撑引入的几千笔新增机会全亏（-220R），提前入场的价值仅集中在箱底附近重叠区。
2. **局部压制位**：推荐 **`prior_n_high`（前 24 根最高，N=24）**。依据：代码已现成支持，且表现优于摆动高点与箱体中位。
3. **承接过滤门槛**：推荐 **基准 1.0 倍（作为硬门槛）**。依据：不盲目采纳 1.2 倍单点过拟合参数，保留合理样本。
4. **确认方案分流**：推荐 **甲/乙/丙三组继续并行隔离验证**。依据：三组在已有数据上均未通过方向一致性检验，无任何一组具备压倒性优势，继续并行是最诚实低成本的选择。
5. **成本与风控口径**：推荐 **保守口径（滑点 5bps，3 仓上限，参与率 0.1%）**。依据：防范滑点与冲击摩擦击穿回测假设。

### 3. 数据区间使用审计定性
- **区间一（研究）**：2025-01-01 ~ 2026-07-01（546天），全负结果，作为唯一的研究基准；
- **区间二（已失效验证集）**：2026-07-01 ~ 2026-10-12（103天），**在 04-A 中已完整计算并公开结果，信息已泄露，严禁再作为独立样本外验证集**；
- **区间三（未来独立测试集）**：必须使用 2026-10-12 之后的全新行情数据，规则冻结后严格一次性盲测。
