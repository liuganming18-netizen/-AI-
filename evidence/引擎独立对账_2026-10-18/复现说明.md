# 复现说明

## 环境

必须用装了 numpy / pandas / duckdb / pyarrow 的解释器。本机可用：

```
/Users/boos/.workbuddy-ai/binaries/python/envs/default/bin/python
```

注意 `envs/wyckoff-framework` 里没有 numpy，跑不起来。

## 命令

```
cd "/Users/boos/Desktop/威科夫因子共振趋势"
/Users/boos/.workbuddy-ai/binaries/python/envs/default/bin/python audit_reconciliation.py
```

默认参数：窗口 2026-09-01 ~ 2026-10-18，标的为「该窗口 528 标的全量回测中所有产生成交的 12 个标的」。
换窗口用 `--start` / `--end`，换标的用 `--symbols A,B,C`。

退出码：三阶段全通过为 0，任一阶段存在差异为 1。

## 重跑会覆盖什么

脚本会就地重写项目根目录下的四个文件：

- `audit_reconciliation.py` 不写自己
- `audit_stage1_bare_signal_diff.csv`
- `audit_stage2_friction_attribution.csv`
- `audit_stage3_truncation_diff.csv`
- `audit_reconciliation_report.md`

本目录是这四份文件在 2026-10-18 03:29 的副本，用于留痕对照。

## 只读约束

脚本不写入 `策略/WyckoffMaster/event_trend_v0_1/` 与 `策略/WyckoffMaster/trading_core/` 下的任何文件，
不 monkey-patch，不改全局配置。参数覆盖全部通过 `dataclasses.replace(...)` 生成新配置对象完成。
报告里的「策略文件 / 撮合内核」两组 SHA256 就是用来核对这一点的：跑前跑后必须不变。
