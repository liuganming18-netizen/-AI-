## 二、旧表述彻底撤回与真实费用根因澄清

### 1. 彻底撤回“163 笔为真实 0 费用”的旧表述
早期研究（FACTOR-ENTRY-01 ~ 05）曾有叙述称“163 笔连续回放样本的手续费与资金费为真实 0”、“未扣除交易摩擦成本”。
**在此正式声明：该表述彻底撤回！**

### 2. 字段读取错误的确凿证据
`ENTRY-AUDIT-03` 查明并重放证实：
- **出错位置**：`evidence/FACTOR-ENTRY-01/stage2_candidate_feature_pipeline.py:255-256`：
  ```python
  trade_fees    = float(matched_trade.get("total_fees", 0.0))
  trade_funding = float(matched_trade.get("total_funding", 0.0))
  ```
- **真实键名**：底层引擎 `engine.py:1038` 导出的键名为 `"fees"`（`entry_fee + exit_fee`）与 `"funding_fee"`（`cum_funding_fee`）。
- **事故机理**：由于键名不匹配，`.get(key, 0.0)` 静默返回默认值 `0.0`，导致上游特征表中遗漏了费用与资金费明细列。
- **重放真实值**：同一批 163 笔样本在真实回测账本中：
  - 真实手续费非零比例：**163 / 163 (100.0%)**，合计 **`10.308546 USDT`**；
  - 真实资金费非零比例：**163 / 163 (100.0%)**，合计 **`5.209154 USDT`**（122 笔支出、41 笔收入）。

### 3. 净盈亏对账与标签稳定性证实
一个此前未被清晰阐明的关键事实：
- 上游旧表在读取净盈亏时，代码为 `matched_trade.get("net_pnl")`。
- 回测引擎在生成成交记录时，**已经执行了 `net_pnl = gross_pnl - fees - funding_fee`**！
- 因此，旧特征表里的 `net_pnl` 数值**原本就已经是扣除了真实手续费和资金费之后的真实净盈亏**！
- 本轮在接入 `ENTRY-AUDIT-03` 的校正账本后：
  $$\text{net\_pnl}_{\text{EA03}} \equiv \text{net\_pnl}_{\text{FE06}} \quad (\text{逐笔绝对偏差} = 0.0)$$
  $$\text{恒等式 } \text{net\_pnl} \equiv \text{gross\_pnl} - \text{fee\_paid} - \text{funding\_cost} \quad (\text{最大残差 } 2.84 \times 10^{-14})$$
- **结论**：净盈亏正负符号**发生 0 笔翻转**；在保持 FE06 分类契约定义完全不变的条件下，依赖 `net_pnl` 的 `MFE_PULLBACK`（浮盈回吐）与 `SUSTAINED_TREND`（持续主升）**分类标签未发生漂移，分类计数保持高度稳定**。

## 四、四大限制结论与严禁事项声明

虽然校正账本在数据层面完成了完全闭环与契约对齐，但**绝不能因此恢复策略有效性结论**，必须明确以下四点铁律：

1. **历史合约规格全池仍未验证（`verified = 0`）**：
   - 227 条记录的 `spec_qualification` 中，`verified` 数量为 **0 条**；全量记录的 `formal_pass_allowed` 全为 **`false`**。本回测所用名义参数仍未经过历史真实盘口规则确证，不可直接用于生产决策。
2. **PIT 发布时点未证实**：
   - 信号与因子的点位发布时间（Point-In-Time）未获得独立时间戳穿透验证，无法彻底排除前瞻偏差假设。
3. **两代际样本严重对立，严禁宣称组合收益**：
   - 连续回放代际（163 笔成交）净盈亏为 **`+144.1060 USDT`**；
   - 窗口切片代际（42 笔成交）净盈亏为 **`-42.5740 USDT`**；
   - **两代际收益方向彻底对立**！简单将二者相加宣称“合并净盈利 +101.53 USDT”属于学术欺骗，任何分析必须拆分为 163 笔与 42 笔独立报告。
4. **样本性质仍为探索性假设**：
   - 本次回测样本（205 笔）为反复观测过的事后样本，所有分类探索与阈值（如 0.8 ATR、4.5%）仍仅属于假设探索，严禁重新宣称“Crowding 因子改善了策略收益”。
