## 三、从完整逐笔母表独立重算收益来源

### 3.1 计算方法

缩量样本由 206 行逐笔表对应的 `prev_1h_low_vol_drop` 行级布尔标记重新筛选，再按重建的 201 个事件集合核对。过滤意味着未开仓、净额 0 U，因此每笔：

- `少亏 = max(−A_net, 0)`；
- `错失盈利金额 = max(A_net, 0)`（下表“影响”记负号）；
- `过滤净差额 = 0 − A_net = 少亏 − 错失盈利金额`。

**算术结果**：少亏 +27.446471 U，错失盈利金额 77.977014 U（对组合影响 −77.977014 U），过滤净差额 **−50.530543 U**。三项对账精确成立。206/201 两种口径各自重算均相同。整个重算没有按 A 组盈亏挑选样本：A 净额只用于量化已由入场前特征决定的过滤结果。

## 五、冻结规则、是否挑样本及被排除分支

### 5.1 实际运行的缩量规则

源代码 `VOLUME-BE-02/code/vbe2_core.py::extract_entry_features`：只用 `close_time <= entry_ms` 的已收盘 1h bar；上一根 1h 收盘低于开盘，且该根成交量低于其之前最多 20 根已完成 1h bar 的均量（比较均量时排除该根）。代码在可用历史均量根数少于 5 时有回退到该根自身成交量的分支；本次没有从底层 K 线重跑特征，故不声称逐事件重新验算过均量原值。`02_run_abcd_fixed.py` 直接以 `prev_1h_low_vol_drop` 作为入场过滤布尔值；未筛选别的价量形态，也没有重新搜索阈值。该代码检查与对应文件 SHA-256 见 `out/independent_recalculation.json`。

**必须披露的报告文字差异：**`ENTRY-VOLUME-01/报告.md` 将规则写为还需 `close < entry_price`；但 VOLUME-BE-02 的实际 `prev_1h_low_vol_drop` 定义和 C 组连线均**没有**这一项。本次 14 笔成员是由实际保存的因子布尔标记及 `C_status` 重建，不是按报告里多写的条件重算。`close < entry_price` 出现在早期契约对“持仓期间缩量退出”的定义中；本单不把它挪作入场条件。此处按代码/冻结契约报告，原报告未被改写。

### 5.2 无结果挑样本

- 过滤样本先由完整 206 行母表对应的 `prev_1h_low_vol_drop` 布尔值全量取出，再核对 201 去重身份；共 14 笔，两套身份一致。
- 没有依据 A 净盈亏、退出原因、收益大小或研究结论选择任何成员。
- 去重仅按事件身份与 `group` 数值先后，五组保留/剔除表不含盈亏筛选条件。

### 5.3 持仓缩量退出明确排除

`hypotheses_evaluation_detail.csv` 虽保存独立研究用的 `pos_exit_*` 列，但主对照的 C 组由入场因子决定：命中则 `C_status=FILTERED_NOT_ENTERED, C_net=0`；未命中则继承 A 的结果。本次脚本只读取入场因子标记、A/C 逐笔结果与去重身份；完全不读取 `pos_exit_*`，也没有使用平仓之后的走势重新选退出时点。所有 206 行过滤组合账都逐行复算通过。

## 七、限定于当前样本的结论

在这批 201 个去重事件（对应 206 个候选）中，实际保存的入场前已闭合 1h 低量下跌标记命中 14 笔。若这些信号在入场时过滤、未开仓记 0 U，则少亏 +27.446471 U，但放弃 +77.977014 U，净额减少 **50.530543 U**；逐一移除任意一笔后仍为负。本结论是按已观察 A 组结果计算的当前样本描述，不证明该形态具有或不具有未来预测力；**通过本次定向验收不等于样本外有效，也不构成生产规则建议。**
