## 2. 样本单位（重复候选不算独立样本）

- 物理候选事件键：`(symbol, event_id, box_ms)`。
- 同网格同事件多笔成交：合并为 1 个事件（PnL 求和），用于网格内 ITT；报告中同时给出名义成交数。
- 跨 9 个参数网格重复出现的同一事件：**池化时按事件等权、跨 9 网格取平均**（未成交/未出现的网格记 0），不把 27 组或 9 组净收益相加当账户收益。
- 每笔成交的 `open_timestamp` 必须落在该币准入区间 `[q_start_ms, q_end_ms]` 内；违规数必须为 0（若有，逐笔列示、保留交易、不删除）。

## 3. 指标定义

| 指标 | 定义 | 主/次 |
|---|---|---|
| 净收益 | 逐笔 `profit_abs` 求和（扣双边万五与真实资金费） | 描述 |
| 胜/负/平 | `profit_abs >0 / <0 / =0` | 描述 |
| 胜率 | 盈利笔数 / 成交笔数（成交口径）；另报事件级条件胜率 | 次 |
| 平均盈亏 | 净收益 / 成交笔数；另报平均盈利、平均亏损 | 描述 |
| 净期望 | 事件级 ITT：每候选事件的 PnL（未成交记 0）均值；网格内与池化两种 | **主** |
| 快速止损率 | `trade_duration<=720min` 且 `profit_abs<0` 且 `MFE=(max_rate-open_rate)/open_rate<3%`，占成交笔数 | 次 |
| 匹配口径 | 仅取"原模式与新模都成交"的事件，比较胜率/快速止损率 | 次（质量口径） |
| 过滤/延迟/新增分解 | 原模式有、新模式无的盈亏（取反）+ 共同成交的 PnL 差 + 新模式独有的 PnL | **主（机制）** |

## 4. 比较族与校正（预先指定，不留空）

- **时间块**：30 天日历块，2021-12-01 起，共 **38 块**（与 AUDIT-04/05/06/07/08 相同）。
- **重采样**：配对块 Bootstrap **5000** 次 → 95% 百分位 CI；块级符号翻转置换 **5000** 次 → p；seed=**20261020**。
- **主族 A（18 项）**：C1−C0 × 9 网格 + C2−C0 × 9 网格，指标 = **事件级净期望**。
  - 校正：**Holm-Bonferroni（族内 18 项）** + **单步 maxT FWER（同组块符号同时施加到 18 项）**；两者都报。
- **主族 B（9 项）**：C2−C1 × 9 网格，指标 = 事件级净期望。
  - 校正：**Holm-Bonferroni（族内 9 项）** + **单步 maxT FWER（9 项）**。
- **次要指标**（胜率、快速止损率）：按同一族结构分别做匹配事件配对检验，并各自 Holm 校正；**不参与主判定**，只作解释。
- **池化事件级检验**：C1−C0、C2−C0、C2−C1 各 1 项，报原始 p 与 95%CI；**不作为族错误率声明**，只作支持性证据。
- **不留空**：每一项对照都必须有"点估计 + CI + p + 校正后 p"四列；任一缺失即标"未完成"，不得宣称覆盖。

## 5. 判定阈值（预先固定）

### C1：统一资格后是否仍有稳定增益

**支持进入独立验证** 需同时满足：

1. 池化事件级净期望差 > 0，且 95%CI 排除 0；
2. ≥7/9 网格点估计为正；
3. 贡献最大单币占改善 < 50%（剔除该币后均值 > 全样本均值的 50%）；
4. 剔除 top5 极端盈利单后，事件级净期望差仍 > 0。

**证据不足**：方向满足 2–4，但池化 CI 含 0 或主族校正后不显著。

**不支持**：≤4/9 网格为正，或池化净期望差 ≤0 且 CI 上界 <0。

### C2：相对 C1 是否有稳定增益

**支持进入独立验证** 需同时满足：

1. 池化 C2−C1 净期望差 > 0，且 95%CI 排除 0；
2. ≥7/9 网格为正；
3. 机制分解中"被 C2 额外过滤掉的 C1 交易"净额 ≤0（即过滤掉的是亏损/中性交易），或延迟效应足以覆盖过滤成本。

**证据不足**：点估计为正但 CI 含 0，或网格为正 5~6/9。

**不支持**：池化差 ≤0 且 ≥6/9 网格为负，或机制分解显示系统性滤掉净盈利交易。

### 最终三问

- 统一资格后 C1 的胜率/净期望改善是否仍成立？
- C2 相对 C1 是否有稳定增益？
- 是否值得进入独立验证？

档位仅取：**支持进入独立验证 / 证据不足 / 不支持**。

## 6. 稳健性与机制检查（必须执行）

1. **跨币**：贡献前 1/前 3 币剔除；逐币留一范围；单币贡献占比。
2. **跨时间**：分年、分半年；38 块正负块数与最大单块占比。
3. **极端盈利单**：去 top1/top3/top5（按各模式事件级 PnL），重算净期望差。
4. **仓位竞争**：分别报 C1-only / C2-only 成交的事件数、笔数、净额；这部分不得算作"确认条件改善"，只作为槽位释放影响单列。
5. **过滤 vs 质量**：共同成交事件的胜率/快速止损率差，与全样本差对比；明确"改善来自过滤还是同批交易变好"。

## 7. 准入边界与候选跨界（开跑前核对项）

- **200 根 4h 预热收盘时间**：q_start 取第 200 根 4h 的**收盘时刻**（首根 open + 200×4h），与 AUDIT-08 定义一致；研究期开始前已满 200 根者取 2021-12-01 00:00。
- **边界包含性**：交易 `open_timestamp >= q_start_ms` 且 `open_timestamp <= q_end_ms` 为合格；闭区间/开区间以反重力代码为准，逐笔核对时按代码实际判定，并在报告中写明。
- **候选跨界**：分别统计
  - 信号时刻 < q_start 的候选（必须为 0）；
  - 箱体形成 < q_start、但信号 ≥ q_start 的候选（按代码规则判定，报告数量）；
  - 成交 open < q_start 或 close > q_end 的交易（必须为 0）。
- **除统一准入外的变化**：将 FT-ENTRY-09 策略基类与 FT-ENTRY-07 基类逐函数对比；只允许"准入过滤"相关改动，其余（P0/仓位/止损/退出/OI/执行时刻/参数网格）必须一致；若发现其他改动，登记并说明是否混杂。

## 8. 保留的限制（结论必须附带）

1. 样本内、已看样本；2025+ 留出期未打开，**不构成独立验证**。
2. OI 5m→1h 映射与发布时点未证实（FT-ENTRY-03 L2=0），OI 过滤仍属探索性。
3. 执行模型只含手续费/资金费，未含滑点/冲击；延迟成本可能被低估。
4. 块级重采样只处理时间聚集，未处理同期跨币相关；有效样本量可能小于物理事件数。
5. 3 槽位组合/资金占用未做账户级复利模拟；所有净额为网格/事件算术量。
6. 统一准入会改变样本与事件数；与 FT-ENTRY-07 的差异只能作背景对照，不能直接归因于"资格修正"。
7. 若 27 组不完整或代码/config 缺失，则不出最终档位。
