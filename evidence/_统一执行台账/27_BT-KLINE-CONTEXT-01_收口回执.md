## 1. 一句话回答

「为什么只有 7 根？」——**不是渲染丢数据，是这个 run 自己只消费了 6.75 小时**。

`FT-ENTRY-09` 那批 run 的窗口只有 0.25~27 小时（`1000XECUSDT` 恰为 7 根），而策略前置条件是
**7 天箱体 + 24h 冷却** ⇒ 只画 run 区间，**生成信号的那个箱体根本不在画面里**。
用户选定「扩 ±7 天」⇒ 现在 run 区间**之外**前后各补 7 天真实行情（只加不改）。

## 4. 过程中自查发现的两个真 bug（用户没报）

| 现象 | 根因 | 修法 |
|---|---|---|
| 上下文 343 根到位，屏幕只框住 **30 根 / 30 小时** | 打开页面时 `selectedTradeId` 被**自动**设成本 run 第一笔，定位 effect 立刻用 `entry ± 12 根` 收窄视窗 | **首屏让位**：每个新视图首屏按完整数据域落位，自动选中不算用户意图 |
| 切周期又缩回去：15m → **51 根**、4h → **26 根** | 切周期重建图表实例，但定位 effect 在「旧句柄还在、新实例未挂载」那一帧先跑一次并消耗门闩 | 门闩键里并入**句柄身份** |
| 放大看某根后动窗口被甩到最右缘 | CENTER-01 的 `ResizeObserver` 用了 `scrollToPosition` | 只纠正被顶歪的 `rightOffset`，**不动缩放、不动平移** |
