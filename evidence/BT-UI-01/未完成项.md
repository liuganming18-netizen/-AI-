## 三、留给验收方复核的三件事

1. **数据同源**：随便点一笔批次逐笔，页面上的运行 ID / 交易 ID / 候选 ID 应能直接在
   `回测日志/event_trend_v0_1/runs_sep_all_latest/<运行ID>/trades.jsonl` 与
   `candidates.jsonl` 里查到（`四类案例对照.md` 给了 3 笔的逐字段对照）。
2. **不造数**：把某个 run 的 `chart.json` 临时改名（**只改名、别删**），刷新页面应看到
   「读时重建 · 非原始 chart.json」或「缺 K 线，不伪造」，且 run 目录里**不会**多出 `chart.json`。
3. **自洽徽章**：批次栏应显示 `自洽：汇总 = 逐笔合计`；若显示 `不自洽`，说明该批次的
   `summary.json` 与 `trades.jsonl` 本身对不上，那是数据问题、不是页面问题。
