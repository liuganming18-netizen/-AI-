## 一、后端（新增 1 / 修改 2 / 测试 1）

### 1. 新增 `框架/backend/backtest_batches.py`

把「批次 = 一次批量运行的真实目录」做成一等读取对象。

- 批次根：`回测日志/event_trend_v0_1`，批次 = 该目录下 `runs` 与 `runs_*`（共 8 个：`runs` / `runs_sep_all_latest` / `runs_sep50{,_check,_full,_strict}` / `runs_2025aug100` / `runs_aug100`）。
- `_batch_dir()` 拒绝路径穿越；`batch_ids()` 只认前缀。
- `_run_facts()`：**只读** `summary.json`（`summary_variant_a` 的 `net_pnl / trade_count / initial_equity / fee_total / funding_total`），`run.json` 仅在 summary 缺失时读，`inputs.json` 仅在取窗口时读（省 I/O）。
- `_batch_facts(full=False)`：只 `scandir` 数目录（0.03–0.06 秒，列表用）。
- `_batch_facts(full=True)`：8 线程并发读 + 汇总；**同一次扫描同时产出 `runs_rows`**（run 清单），`/runs` 与 `/summary` 共用一份缓存。
- `batch_trades()`：逐 run 读 `trades.jsonl`，只为**真有成交**的 run 读 `chart.json` 建索引；逐笔补齐
  `trade_id`(+来源) / `signal_time_ms`(+来源) / `initial_stop`(+来源)，缺失计数如实返回。
- `batch_summary()`：给出 `checks{trades_total_matches_rows, net_pnl_matches_rows, ...}` 自洽核对。
- 缓存 300 秒，支持 `?refresh=1` 强制重算。
- `warm_all()`：只预热「页面会默认选中」的那一个批次（原来把 8 个批次 2130 个 run 全算一遍，把首屏请求堵了 19 秒）。

### 2. 修改 `框架/backend/backtest_store.py`

- 新增 `read_run_dir(run_id)`：**只读**定位 run 目录 = 默认根 → 同级批次目录（`runs*`，索引缓存 120 秒）；都没有 ⇒ `RunNotFound`。
- 切换为只读定位的函数：`read_run` / `read_chart` / `read_snapshot` / `ledger_path` / `read_ledger_rows`。
- **写入边界不变**：`create_run` / `write_run` / `write_snapshot` / `write_chart` / 账本写入仍只走 `run_dir()`（默认根）。
- `list_runs()`：8 线程并发读 + **120 秒**缓存（有待跑 run 时 3 秒）+ 构建锁双检；首次 18–28 秒 → 冷 7.4 秒 / 热 0.12 秒。
  （缓存原来只有 10 秒：页面停一会儿再刷新就重扫 1198 个目录，和批次请求抢磁盘，首屏图表要等到 19 秒。）

### 3. 修改 `框架/backend/backtest_api.py`

- 新增批次路由（必须排在 `run_id` 判定之前）：
  `GET /api/v1/backtests/batches`、`/batches/{id}`、`/batches/{id}/summary|runs|trades`，均支持 `?refresh=1`。
- 读取路径改用 `S.read_run_dir`（5 处）。
- `/trades` 每行补 `initial_stop` / `initial_stop_source` / `signal_time_ms` / `signal_time_source`，envelope 增加 `missing_initial_stop` / `missing_signal_time`；新增 `_signal_index()`（`chart.signals` → `signal_id` 到时刻的映射，带缓存）。
- `get_chart`：缺 `chart.json` 时走 `_fallback_chart_cached`（内存 LRU，**不落盘**）。
- `_generate_fallback_chart` 重写：标的一律取 `summary.json`、窗口一律取该 run 自己的 `inputs.json(data_summary.time_range_1h)`（退路：账本权益曲线首尾）；取不到就抛错，由上层如实报「缺 K 线，不伪造」；返回值带 `derived_from` 说明。
- `startup()` 预热改为 `BATCH.warm_all()`。

### 4. 新增 `框架/backend/tests/test_bt_ui_01_read_path.py`（8 项，全绿）

守住四条纪律：批内 run 可读 / 写入边界不放宽 / `trade_count=0` 不等于缺失 / 重建图表用本 run 窗口且不写盘 / 汇总与逐笔自洽。
