# 05 新旧行为对照

**唯一变量**：OI 观测的「可得时刻」规则。

| | 旧规则 | 新规则 |
|---|---|---|
| 判据 | `ts <= decision_time` | `ts + 5 分钟 <= decision_time` |
| 含义 | 桶开始了就算知道 | 桶结束了才算知道 |
| 决策时刻 | `1h 开盘 + 3600s` | **完全相同**（未动） |
| 阈值 / 撮合 / 费用 / 防拟合 | —— | **全部未动** |

---

## 一、真实 227 条样本（`runs/regression_227.csv`）

数据来源：`evidence/ENTRY-AUDIT-04/handoff/ledger_handoff.parquet`（227 行）
+ 真实 OI parquet（528 标的）。

| 指标 | 数值 |
|---|---|
| 交接包行数 | 227 |
| 唯一「标的 + 快照时刻」 | **226** |
| 可判定 | 226 |
| **旧规则取到未来桶** | **226 / 226（100%）** |
| **新规则取到未来桶** | **0 / 226** |
| 选中观测改变 | 226 / 226 |
| OI 取值改变 | 226 / 226 |
| 旧规则超出决策时刻的毫秒数 | 全部恰好 **300000ms（5 分钟）** |
| 新规则状态 | 226 条全为 `ok_assumed`（值可用，但可得时刻是假设的） |

**为什么恰好 5 分钟**：决策时刻是整点，5 分钟桶的起点也落在整点上，
所以旧规则总会选中「起点 == 决策时刻」那一桶，而它覆盖 `[决策时刻, +5 分钟)`。
这不是偶发，是结构性的。

## 三、结论会不会变

**会，但只变一点。**

2% 门槛（`oi_min_growth_pct = 0.02`）判定：

| | 通过数 |
|---|---|
| 旧规则 | 226 |
| 新规则 | **223** |
| **翻转** | **3** |

3 个翻转时点：

| 标的 | 决策时刻（UTC） | 旧增幅 | 新增幅 | 说明 |
|---|---|---|---|---|
| TRXUSDT | 2023-06-02 22:00 | 5.44% | 1.07% | 从明显通过变成明显不通过 |
| UNIUSDT | 2022-09-27 02:00 | 2.74% | 1.79% | 卡在门槛附近翻转 |
| USDCUSDT | 2026-02-04 18:00 | 2.11% | 1.95% | 卡在门槛附近翻转 |

⇒ **226 个时点里有 3 个（1.3%）会因这次修正而不再通过 OI 门槛。**
这个数字不大，但它说明旧口径确实影响过结论，不是纯理论问题。
