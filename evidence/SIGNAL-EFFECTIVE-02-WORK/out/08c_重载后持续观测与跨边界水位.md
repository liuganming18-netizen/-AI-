### 1.1 一个容易看错的点：`OI_UNAVAILABLE` 从 51 变成 0

- `history`：bootstrap 回放 2,937.5 小时历史时的累计（含 51 条被 OI 门槛挡下的候选）；

### 3.1 这一小时里扫描器做了什么（`funnel.since_start`）

```
BOX 3 / SWEEP 1 / RETEST 0 / CANDIDATE 0 / OI_UNAVAILABLE 0 / OI_REJECTED 0
INVALIDATED 0 / EXPIRED 4 / MISSED_WITHOUT_RETEST 0
```

读法（严格按计数器语义，不推断）：

- 重载后这一小时里，扫描器**确实识别出 3 个箱体、1 个扫低** ⇒ 管道在走，不是死链；
- 但 **RETEST = 0** —— 没有任何一个结构等到回踩确认；
- 于是 `EXPIRED` 累计到 **4**（等回踩超时淘汰）。**数字上 4 = 3 个箱体 + 1 个扫低，但本单没有逐条结构追踪，不宣称"一一对应"**，只记"这一小时有 4 次等待超时"；
- `EXPIRED` 而不是 `INVALIDATED`（结构被破坏），也不是 `MISSED_WITHOUT_RETEST`；
- `OI_UNAVAILABLE = 0` 是因为**根本没走到 OI 判定那一步**（OI 判定在候选之后），不是 OI 门槛关了。

这与项目既有定案一致：FT-LOW4H 是反转策略（`BOX → SWEEP(须跌破下沿) → RETEST → 突破上沿`），单边行情里箱体会一直等不到回踩。**本单只如实记录这一小时的事实，不据此宣称"策略失效"或"信号层已通"。**
