# UI-CRASH-01｜回测复盘「点记录就崩」修复

日期：2026-10-18 · 范围：前端回测复盘 + 逐笔汇总数据 + 批量脚本写盘口径
未触碰：策略核心、撮合、开仓闸门、账本、清理信号。

---

## 一、现象

在「回测复盘」里点任意一条实验记录后，页面像是坏了：

1. 下面「⑤ 逐笔明细」列的还是**别的币**的成交（点 AEROUSDT 的记录，表里全是 METISUSDT/BBUSDT…）；
2. 右侧「③ 资金分析 · 水下回撤」定位到一个 `ord_…` 号，且那个号属于**另一个标的**；
3. 控制台刷出一堆「two children with the same key」；
4. 浏览器网络面板里出现 `GET /api/v1/backtests/<当前run>/trades/ord_…` → **404**。

## 二、根因（两层，缺一不成灾）

### 第 1 层 · 数据层：订单号冒充成交号

`UI界面/web/public/all_trades.json`（批量脚本生成的「全市场逐笔」汇总）里
**70 行 / 70 行** 的 `trade_id` 全部是 `ord_…`（订单号），而账本真实成交号是 `trd_…`。

生成代码原样：

```python
t["trade_id"] = t.get("trade_id") or t.get("order_id")   # ← 缺失就拿订单号顶替
```

这一句在 4 个地方都有：`run_batch_2026_aug_20.py`、`run_batch_2026_sep_oct_50.py`、
`run_batch_2025q4_100_batch2.py`、`工具_同步前端逐笔.py`。

后果：单笔详情接口 `GET /trades/{trade_id}` 只认账本里的 `trd_…`，拿 `ord_…` 去查必然 404。

### 第 2 层 · 前端：跨 run 回退选中

两处逻辑把上面那份数据的「订单号」直接当成当前 run 的成交号：

- `BacktestWorkbench.tsx` 实验记录行点击：`setSelectedTradeId(runTrade.trade_id)`（不校验是否属于本 run）；
- 自动选中：`displayTrades.find(t => t.run_id === selectedRunId) ?? displayTrades[0]`
  —— 找不到就**回退到全市场第一笔**，于是把别的标的的号塞进当前 run。

再叠加「逐笔明细默认视图 = 全市场成交（`viewAllTrades` 默认 `true`）」，
点开任何一条记录，看到的第一眼就是别人的成交 —— 观感上就是「崩了」。

## 三、修法

### 前端（`UI界面/web/src`）

| 文件 | 改动 |
|---|---|
| `components/BacktestWorkbench.tsx` | 新增 `queryableTradeId()`：只认**本 run 逐笔里真实存在**的 `trade_id`，否则返回 `null` |
| 同上 | 实验记录行点击：改为 `setSelectedTradeId(queryableTradeId(runTrade, r.run_id))` |
| 同上 | 逐笔行点击：跨 run 时先切 run 并**清空**选中，等新 run 逐笔到位由自动选中接管 |
| 同上 | 自动选中：只在 `run_id === selectedRunId` 的候选里选，**删掉 `?? displayTrades[0]` 回退** |
| 同上 | 逐笔行 `key` 改为 `run_id\|trade_id\|order_id\|行号`（原 `key={trade_id}` 因重复/缺失导致 React 吞行） |
| 同上 | 逐笔明细默认视图改为**当前标的**（`viewAllTrades` 默认 `false`）；全市场视图保留为可切换 |
| 同上 | `focusTrade` 增加 run 校验，避免同号跨 run 串标的 |
| 同上 | `trade_id` 列为空时显示 `—`（不拿订单号冒充） |
| `api/labBacktest.ts` | `LabTradeRow` 增加可选 `order_id` 字段与说明注释 |

### 数据与脚本（治本，防外部进程再次写坏）

- `public/all_trades.json`：70 行 `trade_id` 的 `ord_…` 搬回 `order_id`，`trade_id` 置 `null`，并写入 `note` 说明。
- 4 个脚本的 `t["trade_id"] = t.get("trade_id") or t.get("order_id")` 改为
  `t["order_id"] = t.get("order_id"); t["trade_id"] = t.get("trade_id") or None`，附事故注释。

## 七、定版（14:45）：撤掉独立端口，改在 3000 上修

用户明确要求：**不要独立端口，统一用 3000**。已执行：

- 停掉 8080 服务、删除 `serve_dist.py`（不留多余入口）。
- 重启 3000 的 vite 并清空 `node_modules/.vite` 依赖缓存（旧客户端拿到的可能是过期模块 ⇒ 白屏）。
- **在 `index.html` 加「白屏自愈」**：5 秒后若 `#root` 仍为空，带 `_r=` 参数强制重载**一次**；
  重载后仍空则不再刷（`sessionStorage` 标记），页面正常时清掉标记以便下次仍可自愈。
