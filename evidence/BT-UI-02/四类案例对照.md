# BT-UI-02 四类案例：原账本 → API → 逐笔 → 图表 四方核对

核对口径：**每一行都指向同一份原始记录**。

- **原账本** = run 目录里跑批时落盘的 `positions.jsonl` / `fills.jsonl` / `orders.jsonl` / `trades.jsonl`；
- **API** = 正式实例 `http://127.0.0.1:8787` 的 `bt_api_v1` 读取接口；
- **逐笔** = 批次条里那一行（`/batches/{批次}/trades`）；
- **图表** = `/{run_id}/chart` 返回的 K 线 + 信号点 + 成交点。

时区：**接口与页面一律 UTC 显示**，括号内给出北京时间（UTC+8）便于对照。
信号点与成交点分开：信号点是「候选信号成立的那根 K 线」，成交点是「下一根 K 线开盘实际成交」，
两者相差 1 根 15m（900 秒），图上分别画成空心箭头与实心方块。
