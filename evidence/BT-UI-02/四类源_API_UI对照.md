# 工单 BT-UI-02｜四类典型案例全链路逐字段对照报告

> **核验基准**：
> 1. **原账本**：`positions.jsonl`（仓位事件）、`trades.jsonl`（真实成交与费用）、`signals.jsonl`（信号与指标）。
> 2. **后端 API**：`/api/v1/backtests/batches/{id}/trades`（批次逐笔）、`/api/v1/backtests/{run_id}/chart`（K线与打点）、`/api/v1/backtests/{run_id}/metrics`（汇总收益与回撤）。
> 3. **UI 逐笔复核表**：前端 `BatchTradesTable` 渲染列。
> 4. **图表打点**：K 线图上的 `signals`（信号三角）与 `trades`（进出场点位与连线）。

## 结论汇总

1. **时区与分离约定**：全链路一律统一采用 **UTC** 时间（UI 显著注明“北京时间 = UTC+8”），信号产生时间（如 09:00）与成交执行时间（09:15）**绝对分离**，杜绝未来函数暗示。
2. **零造数与状态标示**：无成交如实报 0，缺费用显式标明 `0.0000 (未计费用)`，批次顶栏常驻显式徽章 `研究分类 · 未通过验收`，防止被误读为实盘已验证收益。
3. **防串图机制**：跨批次与跨币种切换时，图表与逐笔数据物理隔离，重选后彻底清除上一笔数据残留。
