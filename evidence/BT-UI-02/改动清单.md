# 工单 BT-UI-02｜代码与配置改动清单

## 1. 改动设计原则
1. **最小修改原则**：仅针对“正式实例复验、图表时间窗口纠偏、缺费用与研究状态诚实标示”做只读展示与接口层的最小修正。
2. **严守生产与策略安全边界**：
   - 绝不修改实盘策略逻辑（`strategies/`、`WyckoffMaster/`）。
   - 绝不修改撮合引擎与订单执行（`engine.py`、`fills.py`）。
   - 绝不修改原始历史数据、研究分类底表（`FACTOR-ENTRY-05/06`）与账本（`positions/trades.jsonl`）。
   - 绝不伪造 K 线或虚构 0 手续费。
3. **保留 BT-UI-01 产物**：所有新产物独立沉淀至 `evidence/BT-UI-02/`，不破坏已有资产。

## 2. 修改文件清单

| 文件路径 | 改动性质 | 核心修改说明 |
| :--- | :--- | :--- |
| `框架/backend/backtest_batches.py` | 后端读取层最小增强 | 增加 `_chart_window_reject_reason` 校验，拦截 83 个历史写死窗口（2024 上半年）错图；启用 `_fallback_chart_cached` 动态对齐各 run 真实 inputs.json 窗口并从 parquet 重建蜡烛线与打点 |
| `框架/backend/tests/test_bt_ui_02_chart_window.py` | 新增自动化测试 | 覆盖窗口校验拒收逻辑、动态补图正确性、止损点回填、缺失费用显式为 None（不默认为 0）等核心契约 |
| `UI界面/web/src/components/backtest/RunInfoCard.tsx` | 前端指标渲染修正 | 修正手续费与资金费展示：当 `metrics.total_fees === 0 && total_trades > 0` 时显式渲染为 `0.0000 (未计费用)`，避免误导为零交易成本 |
| `UI界面/web/src/components/backtest/AnalysisPanel.tsx` | 前端因子分析面板修正 | 同步毛利/手续费/资金费展示逻辑：对手续费为 0 且存在成交的探索性 run 标注 `0.00 (未计费用)` |
| `UI界面/web/src/components/backtest/BatchTradesTable.tsx` | 前端逐笔表表脚修正 | 在表脚补充研究状态与未计费用声明：“若账本未计费用则未含交易成本，属研究样本状态，非实盘已验证收益” |
