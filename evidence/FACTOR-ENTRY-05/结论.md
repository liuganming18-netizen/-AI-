## 一、问题根因核查与受影响范围

### 1.1 问题溯源与代码定位
经逐行代码与数据审计，42 笔记录缺少真实 ATR 并触发回退的链条已被完全复现锁定：
1. **产生根源**：在 [`evidence/FACTOR-ENTRY-01/enrich_unified_candidate_dataset.py`](file:///Users/boos/Desktop/威科夫因子共振趋势/evidence/FACTOR-ENTRY-01/enrich_unified_candidate_dataset.py#L317-L324) 中，从旧运行 `FULL_SWEEP_200x100` 补充 42 笔历史成交时，硬编码写入了：
   ```python
   "box_high": float(ot.get("p_in", 0.0)),
   "box_low": float(ot.get("stop_px", 0.0)),
   "box_atr_4h": np.nan,  # <-- 箱体真实 ATR 填空
   "initial_risk_r": float(ot.get("r_abs", 0.0)),
   ```
2. **发生回退点**：在 [`evidence/FACTOR-ENTRY-03/attribution_analysis.py`](file:///Users/boos/Desktop/威科夫因子共振趋势/evidence/FACTOR-ENTRY-03/attribution_analysis.py#L56-L60) 与 `FACTOR-ENTRY-04` 中，微观路径计算模块设置了如下回退链条：
   ```python
   atr_4h = float(rec.get("box_atr_4h", 0.0))
   if pd.isna(atr_4h) or atr_4h <= 0:
       atr_4h = float(rec.get("initial_risk_r", 0.0))  # <-- 致命回退！
   if pd.isna(atr_4h) or atr_4h <= 0:
       atr_4h = p_entry * 0.03
   ```
3. **受影响字段**：
   - 4h 与 24h 路径归一化尺度：`mae_r_4h`, `mfe_r_4h`, `mae_r_24h`, `mfe_r_24h`；
   - 首次极值方向判定：`first_move_4h`（$\pm 0.3 \text{ ATR}$ 触发时间与次序）；
   - 质量分类：`entry_quality_category`（`EARLY_WEAKNESS` 判定门槛）；
   - 几何距离分析：`breakout_atr_dist`（因缺失而未进入前序回归分析）。

### 1.2 物理尺度的失真度量
- 真实 4h Wilder ATR 占入场价中位数：**2.60%**；
- 替代值 `initial_risk_r`（止损距离）占入场价中位数：**16.86%**；
- **真实比例失真**：替代值比真实 ATR 大了 **6.61 倍**（在 42 笔中实际放大倍数分布在 4.0 ~ 10.8 倍之间）；
- 这导致这 42 笔交易在计算 `mae_r_4h = (p_entry - low) / atr` 时，分母被严重放大，原本超过 $0.5 \text{ ATR}$ 的深度下杀被压缩至 $0.08 \text{ ATR}$，直接逃过了早期走弱的判别规则。

## 二、真实 ATR 重建方法与两套语义隔离

本工单严格复用策略原生实现的 Wilder ATR(14) 算法，并在数据结构上实现两套语义的物理隔离：

### 2.1 两套 ATR 语义隔离契约
1. **`box_atr_formation`（箱体形成时冻结 ATR）**：
   - 对应状态机 42 根 4h K 线建箱收盘时刻的 ATR 值，用于箱体几何宽度判定；

2. **`signal_atr_snapshot`（突破信号/入场时刻动态 4h ATR）**：
   - 严格取入场时刻 $t_{\text{in}}$（或快照时刻 $t_{\text{snap}}$）**当时已经闭合的最晚一根 4h K 线的真实 Wilder ATR(14)**；
   - 纯粹基于当时已知历史行情，预热根数全部在 300 ~ 1500 根之间，无前视偏差；
   - **205 笔成交记录全部 100% 成功重建并验证**。

### 3.2 事实与因果彻底解耦（关键财务发现）
对订正后的真实分组进行全生命周期真实财务对账：

```
真实财务事实检验：
  · 新先不利组 (101 笔)：合计净盈亏 +70.51 USDT (平均每笔 +0.70 USDT，胜率 40.59%)
  · 非先不利组 (104 笔)：合计净盈亏 +31.02 USDT (平均每笔 +0.30 USDT，胜率 41.35%)
```

**对账分析与因果撤回**：
1. **“先跌必亏”假设破产**：在数据上，4h 内先出现不利下杀的 101 笔交易，其全周期净盈亏总和（$+70.51\text{ USDT}$）反而显著高于没有先下杀的交易（$+31.02\text{ USDT}$）；
2. **市场机制解释**：加密市场突破交易中，突破后的回踩确认（Pullback）、深蹲洗盘（Spring-like Shakeout）非常普遍。许多超级主升浪交易均经历了前 4 小时的剧烈深蹲，随后走出数十倍 R 的单边大牛（例如 `SOONUSDT` 入场 4h 先跌 4.4%，最终暴赚 $+188.26\text{ USDT}$）；
3. **撤回声明**：**正式撤回“追高导致早期下杀，早期下杀导致策略亏损”的单一因果假说**。早期价格下探属于突破形态的微观路径特征，与最终能否实现策略盈利不构成负向因果绑定。
