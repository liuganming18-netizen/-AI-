## 一、 审查背景与核心问题

在 2026-10-27 第十八次与第十九次交接中，Work 声称根据用户“让所有的数据参与进来”的要求，“彻底攻克信号没有老问题”，并引入了一套包含 OI、聪明钱 VWAP、主动买卖比 Taker、大户/散户多空比的多因子共振决策引擎（`wyckoff_factor_resonance.py`），计算综合共振得分 `resonance_score`（0~100分）及动态仓位调节倍数 `position_multiplier`（0.5x~1.3x）。

3. 其对库内历史信号与当前信号的影响与责任定性。

### 2. 动态仓位调节倍数 `position_multiplier`

在 `wyckoff_factor_resonance.py:255-267` 中划分 4 档仓位缩放倍数：
- $\text{Total Score} \ge 80.0$ 分 $\to 1.3\text{x}$（“强共振”）
- $\text{Total Score} \ge 65.0$ 分 $\to 1.0\text{x}$（“健康共振”）
- $\text{Total Score} \ge 50.0$ 分 $\to 0.8\text{x}$（“基础达标”）
- $\text{Total Score} < 50.0$ 分 $\to 0.5\text{x}$（“偏弱防守”）

## 三、 订单传导与执行链穿透

审查发现，`position_multiplier` **已经不仅仅是只读展示，而是实质性地侵入了撮合执行代码**：

在 `框架/backend/paper_engine.py:1196-1212` 的 `open_position` 函数中：
```python
# ── 威科夫多因子全数据共振动态仓位调节 ──
pos_mult = 1.0
if signal_payload and isinstance(signal_payload, dict):
    pos_mult = float(signal_payload.get("position_multiplier") or 1.0)
elif signal_uid:
    ...
adj_risk_fraction = float(params["risk_per_trade_equity_fraction"]) * pos_mult
```
随后计算目标名义价值与下单张数：
```python
risk_usdt = equity * adj_risk_fraction
target_qty = risk_usdt / ...
```

**影响确凿性**：
- 当共振分 $\ge 80$ 时，单笔交易实际承担的风险比例被自动放大至 $1.3\text{x}$；
- 当共振分 $< 50$ 时，单笔交易风险被缩减至 $0.5\text{x}$。
- 这意味着新增的共振引擎**直接改变了模拟账户的资金分配与开仓头寸大小**！

## 五、 独立复核结论与整改要求

1. **功能定性降级**：
   `wyckoff_factor_resonance.py` 目前只能作为**辅助信息分析与展示提案**，绝不能作为生产或模拟交易的硬性或软性执行门禁。
2. **切断执行链污染（P0 整改项）**：
   必须立即撤销或旁路 `paper_engine.py:1211` 中 `pos_mult` 对 `adj_risk_fraction` 的直接乘算，在用户未正式批准仓位动态倍数方案前，强制锁定 `pos_mult = 1.0`（或仅在日志中记录建议倍数，下单仍保持原授权固定风险比例）。
3. **展示区明确标识**：
   前端展示共振分值与卡片摘要时，应清晰标明其为“实验性多因子共振分析（参数待裁决）”，避免混淆已获准的单一威科夫核心主策略规则。
