## 改动（只动了 1 个生产文件）

`src/components/PositionPanel.tsx`（完整 diff 见 `02_改动diff.txt`，SHA 见 `04_源码哈希.json`）：

1. **三态可区分**（原 `paperConnected && scopedPending.length>0` ⇒ 0 笔时整块消失）：
   `data-state = has_pending / empty / unreadable`，`data-n-pending` 未知时写 `-1` 而不是 `0`。
2. **失败态**：账本读不到时显示 `paper-pending-error`（原因原样透出），
   **不渲染上一次缓存的挂单**（父层失败时保留旧 accounts，直接渲染=把旧快照当当前挂单）。
3. **补齐契约字段**：`#pending_id`（身份）、状态中文+原码、来源文案、等待原因、`signal_uid`。
4. **负向自律**：行内明确标注「方向 / 数量 / 预计成交价：服务端挂单接口未提供 ⇒ 本页不推断」。
5. 未新增任何交易语义、未改后端、未改 API 层、未改其他窗口脚本、未动 `App.tsx`。
