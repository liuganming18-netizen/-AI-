# SYSTEM-CLOSELOOP-03｜02 正常成交、止损自动上移、自动退出及重启恢复事件链

## 1. 验证目标与事件链路概述

本项验证直接调用撮合执行核心（`PaperEngine`），在隔离环境下模拟全生命周期流转，验证以下完整链条：
1. **信号入场与订单成交**：合法信号触发买单、撮合生成成交明细、建仓并建立初始止损。
2. **4小时K线闭合推进**：引擎根据收盘数据自动计算候选止损，满足上移条件时持久化历史轨迹。
3. **幂等性与单调性**：低价格 K 线推进不触发下移，重复调用不产生冗余记录。
4. **服务重启恢复**：模拟引擎重启后，从数据库恢复最新止损价格及历史更新轨迹。
5. **触发退出与订单强关联**：价格下穿止损线，引擎自动触发退出，生成平仓订单及平仓成交，`order_id` 强关联。
