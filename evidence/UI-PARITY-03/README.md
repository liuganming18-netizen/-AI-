# UI-PARITY-03 · 回测复盘页中栏对齐设计稿（2026-10-18 晚）

## 一句话
设计稿的中栏是「K 线 → 净值/回撤两张并排卡 → 留存记录清单 → 单条记录回放」，
本项目原先把「逐笔明细 / 实验记录」摆在**三栏之外、左右并排**，还多一条「批次逐笔复核」折叠条。
本轮把它们按设计稿搬进中栏、删掉并排容器，页尾只留一行折叠与一排小按钮。
**第二轮**（同日更晚）补上设计稿图表区缺的两条：**持仓量（OI）** 与**独立「成交量」一条**，
并把三段竖排的时间轴收成只剩最底一行。

## 改了什么
| 位置 | 改前 | 改后 |
|---|---|---|
| 中栏第 3 块 | 无（在三栏之外） | 留存记录清单（原「实验记录」，点一行回放该次运行） |
| 中栏第 4 块 | 无（在三栏之外） | 单条记录回放（原「逐笔明细」+ 单笔详情折叠） |
| 三栏之外 | 逐笔明细、实验记录左右并排（`.ds-dash` / `.ds-col-5` / `.ds-col-7`） | 已删除，两块都进中栏 |
| 三栏之外 | 「批次逐笔复核」整块表 | 收成一行折叠「整批逐笔（跨 run）」，缺省收起 |
| 留存记录清单列 | 8 列常显（创建时间/回撤/失败原因恒为 —） | 5 列常显（标的/运行 ID/状态/净收益/笔数），其余进「更多列」 |
| 回撤曲线卡 | 联动「已定位」徽章在单图模式下被整块隐藏 | 只在回撤卡显示（净值卡不重复），点徽章恢复全区间 |
| 资金曲线画布 | 底色写死 `#ffffff` ⇒ 深色模式一块白 | 深色读令牌，浅色保持原值不变 |
| 图表区第 3 段 | 无（设计稿有「持仓量（OI）」92px） | 真实 5m 归档 OI 柱形副图 + 悬停读数 + 万/亿刻度 |
| 图表区第 2 段 | 成交量以 `scaleMargins:{top:0.78}` 叠在 K 线 pane 内 | 独立 84px「成交量」一条，自带左标签与右轴刻度（设计稿三段竖排） |
| 时间轴 | K 线图与 OI 图各一行日期（两排刻度） | 只有最底一条显示日期，上面两条裁掉 |

## 仍然不同（故意，不算完成）
1. 设计稿左栏第二张卡是「留存与复盘筛选」（4 个纯筛选器，无数据源），本项目放的是**可用的**「回测范围」（批次 / 取数口径 / 运行）。不换成假控件。
2. 设计稿右栏第 4 张卡「量化指标补充」（索提诺 / 年化波动率 / 回撤持续时间 / 恢复因子 …）后端没算，**不造数**。
3. 设计稿「单条记录回放」是四步时间线（信号 → 入场 → 持仓 → 离场），本项目是逐笔表 + 单笔详情折叠；数据齐但没做时间线。
4. 三栏之外仍留「更多视图」一排小按钮（结果身份 / 订单 / 拒单 / 资金费 / 口径与审计），设计稿没有这一排；它们是审计面板的唯一入口，暂时保留。
5. 设计稿 OI 条右侧有 2 个刻度（52.50亿 / 50.00亿），本项目 OI 条只显示末值徽章 `1.03亿`：`base` 取「窗内下缘再低 12%」后价格轴区间被压得很窄，官方库选不出第二个刻度；数值仍可从徽章与悬停读数读。
