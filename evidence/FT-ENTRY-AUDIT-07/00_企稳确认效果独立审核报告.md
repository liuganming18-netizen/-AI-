### 3.3 快速止损（quick_stop）指标口径缺陷 —— 27/27 格复现定位

**对方代码定义**（`evidence/FT-ENTRY-07/code/02_reconcile_and_analyze.py` 第 71–76 行）：

```python
# 快速止损定义 (沿用 FT-ENTRY-06):
# 持仓时间 <= 12小时 (720分钟) 且 亏损 (profit_abs < 0) 且 MFE < 3% (max_rate < 0.03)
df["quick_stop"] = (df["trade_duration"] <= 720) & df["is_loss"] & (df["max_rate"] < 0.03)
```

**缺陷**：freqtrade 的 `max_rate` 是**持仓期最高成交价（绝对价格，USDT）**，不是收益率。注释写的「MFE < 3%」与代码写的 `max_rate < 0.03` 不是同一件事——后者实际筛出的是**币价 < 0.03 USDT 的廉价币**，与入场后是否快速止损无关。

**证据链（`queries/07_quickstop_definition_audit.py`）**：

1. **复现**：用对方的 bug 口径在我方上游逐笔 CSV 上重算，与对方 `01_全部运行索引与指标总表.csv` 的 `quick_stop_count` **27/27 格逐格一致**（C0 209 / C1 32 / C2 30）⇒ 差异来源唯一地是该定义，不是样本、不是数据、不是计算精度。
2. **集合构成自证伪影**：对方标记的 209 笔 C0「快速止损」只涉及 **12 个币种**，`max_rate` 全部落在 [0.00044, 0.02855]——1000BONK / 1000CHEEMS / 1000PEPE / 1000SATS / 1000SHIB / 1000XEC / ACH / ANKR / BEAMX / BOME / CELR / CKB，即「低价币名单」而非「快止损行为名单」。C0 全部 3081 笔中 `max_rate<0.03` 的有 349 笔，也印证这是价格分档。
3. **正确口径重算**（MFE = (max_rate−open_rate)/open_rate < 3%）：

| 车道 | 对方 flag | 正确口径 | 倍数 | 对方漏检 |
|---|---|---|---|---|
| C0 | 209 (6.78%) | **1456 (47.26%)** | 7.0× | 1256/1456 = **86.3%** |
| C1 | 32 (4.24%) | **304 (40.26%)** | 9.5× | — |

5. **归因链整体派生**：对方 02 表的 `避免快速止损 (AVOIDED_QUICK_STOP)` 标签由 `c0_quick_stop` 直接派生（代码第 281/301 行）。我方按 bug 口径复算事件级计数 = **C1 152 笔 / C2 154 笔**，与对方报告「C1 成功过滤了 152 笔原版快速止损」**完全吻合** ⇒ 该归因数字是单位错误的派生物。按正确口径，事件级「避免快速止损」= **C1 1121 / C2 1155**，另「避免普通亏损」C1 767。

7. **注释的出处也不可证**：对方代码称「沿用 FT-ENTRY-06」，但 FT-ENTRY-06 的 `code/generate_ft_entry_06_evidence.py` **不含任何 quick_stop/max_rate 计量**（grep 计数 0），其报告中的「快速止损」仅是文字案例（且该案例把 MFE 当百分比用：MFE 0.09%）——即注释的传承声明无代码支撑。
8. **对方两表自相矛盾（附带）**：`01_全部运行索引与指标总表.csv` C0 合计 209，而 `02_逐候选对照表.csv` C0 flag 合计 **179**，差 30。机理已定位：对方 02 表用 `c0_dict[eid] = row` **覆盖式建索引**（代码第 199 行附近），同一 event_id 的多笔复入只保留 1 行 ⇒ C0 3081 笔被压成 **2995 行**（唯一 event 数经我方独立复算恰为 2995，逐格吻合），**86 笔静默消失**，其中 30 笔带 bug flag；C1/C2 无同事件复入（755/602 笔 = 唯一 event 数）故两表一致（32/32、30/30）。⇒ 同一交付内两个产物对不上，报告作者未察觉。

**结论（口径）**：对方全部 quick_stop 相关数字（209/32/30、占比 6.78/4.24/4.98、84.7% 降幅、避免快速止损 152 笔、72.7% 占比）**一律不可引用**；需对方以 `MFE=(max_rate−open_rate)/open_rate < 0.03` 更正后重算。我方可提供的正确口径基准：**C0 1456 / C1 304 / C2 248；发生率 47.26% / 40.26% / 41.20%**。
