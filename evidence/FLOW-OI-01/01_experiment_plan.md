## 一、研究背景与核心目标

在突破交易中，经典技术分析依赖价格与成交量形态，但无法区分成交背后的微观驱动力量：
1. **正常放量突破**：主动买入推升价格，伴随新增持仓（OI 上升），属于健康的趋势启动过程；
2. **极端放量滞涨（接盘/派发）**：主动买入虽然巨量，但价格无法有效推进，或者冲高大幅回落，往往伴随着被动大单卖出接盘，易引发入场后迅速走弱；
3. **承接吸收过程**：主动卖出占优，但价格在支撑位附近跌幅收窄或止跌，伴随持仓量沉淀，往往孕育阶段性反转；
4. **空头轧空衰竭**：价格上涨但持仓量大幅下降，行情完全由空头平仓驱动，缺乏新资金进场，容易在冲高后迅速枯竭。

**本实验的核心目标**：
在不改变底层策略撮合内核、不碰交易闸门与正式生产账本的前提下，基于已验证的 227 笔特征样本（205 笔已成交，22 笔未成交），以隔离研究方式验证：**主动成交净额/CVD、真实 OI 变动与币安大户持仓指标，能否有效减少突破入场后的走弱概率，提升入场质量**。

## 二、四大微观过程假设与反例观察

研究必须先于规则制定，本实验围绕以下四个微观假设进行系统性考察：

| 假设编号 | 市场微观情景描述 | 预期微观逻辑 | 潜在反例与风险陷阱 |
| :--- | :--- | :--- | :--- |
| **假设 A** | **主动卖出占优、OI 增加，价格跌幅收窄/不再创新低** | 被动买盘强力承接（吸收吸收），卖压被大资金在区间内消化 | 假承接：大空头持续增仓砸盘，价格停顿只是下跌中继，随后击穿支撑加速下行 |
| **假设 B** | **主动买入占优、OI 增加，价格持续推进** | 健康的主动资金与新持仓共振，动能强劲推进趋势 | 冲高诱多：多头主力拉高后反手倒货，突破后 1h 内即转入深幅回调（假突破） |
| **假设 C** | **主动买入占优、OI 激增，但价格涨不动或冲高回落** | 极端放量接盘滞涨，大单被动供给极为充沛，买单沦为对手盘流动性 | 顺延蓄势：短期遇到阶段性密集挂单，经短暂停顿后被多头一举扫清，随后开启超级主升（误伤大赢家） |
| **假设 D** | **价格上涨、OI 显著下降（与增仓上涨区别）** | 纯空头止损/轧空平仓，缺乏新进资金建仓，反弹持续性差 | 轧空暴拉：空头踩踏引发流动性黑洞，价格无需新资金亦可产生脉冲式巨大涨幅 |

### 观察时点划分：
- **突破前（Pre-breakout, 箱体内 24h）**：观察是否有低位承接（假设 A）或隐性派发；
- **突破时（Breakout Bar, 决策时点 $t_0$）**：观察放量质量、买入占比、上影线与价格推进效率（假设 B vs 假设 C）；
- **突破后（Post-breakout 1h/4h/24h）**：仅作为样本外评价指标，严禁用于决策时点特征构造！

## 三、特征工程与 Point-in-Time（PIT）时间轴纪律

### 1. 严格防窥视原则
- 决策时点为快照时刻 $t_0 = \text{snapshot\_time\_ms}$。
- 所有特征计算所用数据的时间戳必须严格满足：$\text{open\_time} \le t_0$ 或 $\text{ts} \le t_0$。
- 后续 15m/1h/4h/24h 的价格路径、前向收益及入场质量分类仅作为验证评价的因变量（Label），严禁反向渗入自变量。

### 2. 回看窗口与重置机制
- **突破当根指标（1h Bar）**：
  - `bar_taker_buy_ratio = taker_buy_quote_volume / quote_volume`
  - `bar_taker_net_quote = 2 * taker_buy_quote_volume - quote_volume`
  - `bar_volume_ratio_24h = quote_volume / mean_quote_volume_24h`
  - `bar_upper_shadow_ratio = (high - max(open, close)) / (high - low + 1e-8)`
- **突破前 24h 窗口累积指标（滚动 24h 重置）**：
  - `quote_cvd_24h = sum_{24h}(2 * taker_buy_quote_volume - quote_volume)`
  - `base_cvd_24h = sum_{24h}(2 * taker_buy_volume - volume)`
  - 为避免不同币种成交额量级差异，跨币种标准化采用：
    $$\text{norm\_cvd\_24h} = \frac{\text{quote\_cvd\_24h}}{\text{total\_quote\_volume\_24h}}$$
- **OI 持仓变动指标**：
  - `oi_base = sum_open_interest`（基础资产张数/币数）
  - `delta_oi_base_24h = (oi_base_{t_0} - oi_base_{t_0 - 24h}) / (oi_base_{t_0 - 24h} + 1e-8)`
  - `oi_quote = sum_open_interest_value`（名义金额）
  - `delta_oi_quote_24h = (oi_quote_{t_0} - oi_quote_{t_0 - 24h}) / (oi_quote_{t_0 - 24h} + 1e-8)`
- **币安大户多空指标**：
  - `top_pos_ratio = sum_toptrader_long_short_ratio`（大户持仓量多空比）
  - `top_acc_ratio = count_toptrader_long_short_ratio`（大户账户数多空比）
  - `global_acc_ratio = count_long_short_ratio`（全市场账户数多空比）

## 四、四组有限对照回测方案（规则冻结）

严格限制变体组数（最多 4 组），严禁机械叠加与穷举网格搜索。每组相对前一组均有唯一清晰的新增信息维度：

### 组 1：原策略基线（Baseline）
- **规则**：原策略未经任何微观流因子过滤的入场表现（分母 205 笔已成交，22 笔未成交）。
- **定位**：对照基准，记录原始胜率、净盈亏、PF、早期走弱率（32.68%）。

### 组 2：基线 ＋ 主动成交与价格推进过滤
- **唯一新增信息**：主动买入成交占比与价格推进结构的匹配度（识别假设 C 接盘滞涨与假突破）。
- **过滤规则**：
  1. **排除卖压逆风假突破**：当根突破 bar `bar_taker_buy_ratio < 0.45`（主动卖单压倒主动买单，突破缺乏买盘支撑）；
  2. **排除极端放量接盘滞涨（派发）**：当根成交量异常放大（`bar_volume_ratio_24h >= 2.0`），但上影线占比严重超标（`bar_upper_shadow_ratio >= 0.50`）且价格实体推进极差（实体占蜡烛全长 $< 30\%$）。

### 组 3：组 2 ＋ OI 持仓增减过滤
- **唯一新增信息**：真实持仓量变动 $\Delta \text{OI}_{\text{base}}$（识别假设 D 纯空头踩踏衰竭与无资金支撑突破）。
- **过滤规则**：
  - 在组 2 准入的前提下，要求突破过程伴随增量资金沉淀；
  - **排除纯平仓踩踏型衰竭突破**：若突破前 24h 至突破时基础资产持仓量大幅下降（$\Delta \text{OI}_{\text{base}} \le -5\%$），判定为缺乏新多头参与的纯轧空尾声，予以剔除。

### 组 4：组 3 ＋ 币安大户指标过滤
- **唯一新增信息**：币安大户持仓多空比 `top_pos_ratio` 与全市场散户账户比 `global_acc_ratio` 的背离关系。
- **过滤规则**：
  - 在组 3 准入的前提下，核验主力大户态度；
  - **排除散户狂热大户做空极端背离**：全市场散户账户数极度看多（`global_acc_ratio > 1.8`），而大户持仓量多空比却处于弱势看空（`top_pos_ratio < 0.9`），即散户追多接盘而大户减仓压盘的严重背离情形。

## 五、评判指标与回答责任清单

本实验必须明确回答工单提出的全部六大核心问题：
1. **入场走弱改善**：入场后 15m/1h/4h 早期走弱（`EARLY_WEAKNESS`）数量与比例的变化；
2. **增量信息价值**：主动成交、OI 与大户指标各自分别提供了什么独立信息？
3. **少亏 vs 错失盈利**：减少了多少亏损金额？漏掉了多少盈利交易，尤其是否错失了大赢家？
4. **统计收益质量**：净盈亏、期望收益、Profit Factor (PF)、交易频次、最大不利偏移 (MAE)、最大有利偏移 (MFE) 及利润集中度的变化；
5. **稳健性检验**：改善是系统性的，还是仅仅由个别异常币种或单一年份驱动？
6. **证伪与反例**：哪些先验假设被实证反例明确推翻？
