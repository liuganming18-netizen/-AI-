## 2. 第①项：统计稳定性（全预定对照）

### 2.1 方法与预定对照

- **复用** AUDIT-04/05/06/07 已预锁方法（`queries/_common.py` 常数完全相同）：30 天日历块（2021-12-01 起，**38 块**）、配对 Bootstrap **5000** 次、块级符号翻转置换 **5000** 次、**Holm-Bonferroni**、单步 **maxT FWER**；seed=20261020。
- 代码层面与 `AUDIT-05/queries/_common.py` 的 `paired_bootstrap` / `block_permutation_p` / `holm` / `maxt_fwer` 逐函数对照，**只把统计量从"块和"改为"块内事件均值"**（分母固定为事件数，以匹配事件级口径）；检验族、阈值、重采样次数、随机种子均未改。
- **主族**：C1−C0、C2−C0 × 9 网格 = **18 个对照**；**次族**：C2−C1 × 9；**池化**：事件等权 C1−C0、C2−C0、C2−C1。
- **指标口径分开**（避免把"不交易"当亏损）：
  - **净期望**：ITT 候选级，C1/C2 未成交记 0；
  - **胜率 / 快速止损率**：只在成交事件上定义，配对检验用"C0 与 C1/C2 都成交"的匹配事件；
  - 同时报成交口径（与交付一致）与匹配口径，不混用。

### 2.2 池化结果（事件等权，n=622）

| 对照 | 净期望/候选 C0→C1/C2 | 差值 (95%CI) | p | 事件级成交胜率 | 匹配胜率差 | 事件级成交快速止损 | 匹配快速止损差 |

## 3. 第②项：入场下限 L−0.2A → P0 的实际影响

### 3.1 先指出 AUDIT-07 T6 的方法缺口

T6 的核对对象是 `audit_orders_*.csv`，即 **`confirm_trade_entry` 之后**的订单记录。但下限实际生效在**更早一层**：

```python
# populate_entry_trend（信号生成）
mask = (cand_valid == 1) & (open >= cand_h) & (open <= cand_max_price)
# C0:   cand_h = L - 0.2A
# C1/2: cand_h = P0 = S - 0.1A
```

`open < min_entry` 的候选**根本不会产生入场信号，也不会写 audit_orders**。因此"0 笔额外拒单"只能证明"已进入订单评估的候选未被拒"，**不能证明下限改动对全部候选无影响**。本轮补查这一层。

### 3.2 箱体重建的正确性证明

`event_id` 尾部即 4h 箱体形成收盘时刻；按冻结规则取"收盘 ≤ 该时刻"的 42 根 4h，H=max(high)、L=min(low)、A=Wilder ATR(14)。用运行期账本对拍：

| 校验 | C1 | C2 |
|---|---:|---:|
| 成交订单数 | 755 | 602 |
| **重算 H 与 `frozen_H` 精确相等（1e-9）** | **755/755** | **602/602** |
| 成交价 ≤ `confirm_close + 0.5A`（上限自洽） | 755/755 | 602/602 |
| 重算箱体满足 2A≤宽≤8A 且 ER≤0.30 | 755/755 | 602/602 |
| `P0 + 0.1A = S < L`（扫低确实低于箱底） | 755/755 | 602/602 |

⇒ 重算的 L、A 可用于反事实下限；4 笔 BEAMX 拒单的成交价 0.018282 高于重算上限 0.0182695（差 1.25e-5），进一步验证 A 的精度。

### 3.3 全部确认候选的逐候选重演

对 **C1 778 个、C2 619 个确认通过**的候选（不只成交），按 `populate_entry_trend` 重演确认后 4 根 15m 的门槛价，分别用旧下限 `L−0.2A` 与新下限 `P0` 判定：

| 仅新规则触发（新规放宽） | 0 | 0 |
| 触发根改变 | 0 | 0 |
| 两者都不触发 | 0 | 0 |
| **受影响合计** | **0** | **0** |

- **0 笔成交价低于旧下限，0 笔低于新下限**。
- P0 相对旧下限的方向并非一边倒：**427 个候选 P0 更紧、970 个更松、0 个相等**；但**实测 1397 个候选第一根 15m 的 open 均同时高于旧、新下限**（确认收盘至少为 L+0.1A，对旧下限 L−0.2A 留有 0.3A 余量；首根 15m 的跳空未吃掉该余量），所以**触发根完全不变**。

- 典型边界：1000CHEEMS 的 C0 交易在 2024-12-26，早于其 200 根起点（2024-12-28）2 天；CHILLGUY 的 200 根起点落在研究期结束后。所有 115 笔都发生在箱体已形成之后，因果链本身未被破坏——问题在于"资格口径"与"策略实际预热"不是同一件事。

### 4.3 结论

- **不合格区间已明确**：44 币的"上架→200 根 4h 完成"预热窗口 + 4 币的整个研究期。**115 笔受影响交易全部落在 44 个"期内后段合格"币的预热窗口内**（4 个全程不合格币 0 成交），已逐笔列出（`out/04_不合格区间涉及交易_v1.csv`）。
- **未删除任何交易**，未生成"清洗后账户"；`04_逐币交易与区间_v1.csv` 保留每币交易与区间对照。
- 引用 27 组绝对净额时须注明：这是**74 币名义池、按策略实际预热**的结果；若按 FT-ENTRY-03 的 200 根 L1 严格口径，约 1.99%~2.86% 的交易位于资格起点之前。

## 5. 三问回答（唯一结论）

### Q1：C1 是否提高胜率及净期望，且改善是否稳定？

**净期望：方向性提高；胜率：只在"少交易"口径提高，同批交易没有提高。**

- 九组汇总 −4243.26 → **+239.30U**（改善 +4482.56U）；事件级 **+0.801U/候选**（95%CI 0.120~1.410，p=0.033）；**C1 9/9 网格点估计为正**（全部 18 个主族对照亦全为正）。
- 但 **maxT（18 对照）p=0.189、Holm 0/18、剔除贡献前 3 币 p=0.114** ⇒ **稳定性不足以宣称统计显著**。
- 逐笔胜率 18.73%→22.78%、快速止损 47.26%→40.26% 确实存在，但分解显示：**C1 把 394 个 C0 事件整个放弃**（毛避免亏损 727.86U），延迟成本 −215.85U；在 **219 个共同成交事件**上，胜率差 **−2.15pp**（p=0.147）、快速止损差 **+2.26pp**（p=0.036，反而更差）。
- 跨币/跨年/极值依赖均未推翻方向（逐币留一 0.730~0.913U，去 top5 盈利单后 1.171U），故"方向稳定"成立；"显著改善"不成立。

**判定：支持继续验证**（不是"有效"）。

### Q2：C2 相对 C1 是否有增益？

**没有，点估计与机制分解一致为负。**

- 九组汇总 **−386.20U**（C1 +239.30 → C2 −146.91）；事件级 **−0.069U/候选**（95%CI −0.521~0.207，p=0.919）；**6/9 网格为负**（仅 Vs04 三格为正）。
- 匹配口径胜率差 **0.00pp**、快速止损差 **+0.25pp**（均 p=1.0）⇒ 没有任何质量增益。
- 分解：C2 额外过滤掉的 31 个 C1 事件原本净 **+56.27U**（把盈利单滤掉），延迟效应仅回收 +13.35U，净 **−42.91U**。

**判定：不支持**（作为 C1 之上的附加过滤）。

### Q3：是否值得进入下一项实验？哪些证据仍不足？

**只建议以 C1 进入下一项验证；C2 不建议。当前不能把"指标重算一致"当成"策略有效"。**

仍不足的证据（按重要性）：

1. **多重比较后不显著**：18 个主族对照 maxT p=0.189，Holm 无 <0.05；剔除贡献前 3 币 p=0.114。
2. **样本内、已看样本**：2021-12~2024-12；2025+ 留出期未打开，无独立 OOS。
3. **有效样本仅 613 个物理事件**（C1 228 / C2 197）；跨 9 参数网格的重复不能增加独立样本，块级检验功效有限。
4. **胜率/快速止损改善是选择效应**：共同成交事件上无改善（胜率 −2.15pp、快速止损 +2.26pp），不能宣传为"交易质量提升"。
5. **执行成本不完整**：只含双边万五与真实资金费，未含滑点/冲击；延迟入场的 −215.85U（网格均值）可能被低估。
6. **块级重采样只处理时间聚集，未处理同期跨币相关**：同一时段多币同时信号会使有效样本量小于 622；maxT 的块符号置换也只是近似控制。
7. **组合/槽位效应只用 ITT=0 近似**：3 槽位、资金占用、复利未做账户级模拟；"九组汇总"不是账户收益。
8. **115 笔交易早于 200 根 4h 资格起点**（但晚于 42 根箱体），绝对收益口径需注明；不合格区间未做"清洗后重算"。
9. **C1 的机制是"过滤"而非"改善"**：下一项实验应预注册"过滤比例/被过滤事件的反事实收益"作为主要机制指标，而不是只看汇总净额。

**下一项实验建议**：预注册独立留出期 + 含滑点的执行模型 + 事件级功效计算；以 C1 为唯一候选，C2 不作为候选。
