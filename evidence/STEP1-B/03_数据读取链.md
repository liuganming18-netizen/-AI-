**关键结论**：回放链与读接口链**不是同一条**。回放直读 parquet；读接口有自己的一套
（批次目录 + 现算指标 + 图表守卫）。两条链之间没有任何「逐值一致」测试。

## 三、窗口与预热：真实裁剪逻辑

```python
# runner.py:261-266
start_ms = to_datetime(start_date).timestamp()*1000
end_ms   = to_datetime(end_date).timestamp()*1000
df_1h  = raw[(raw.open_time >= start_ms) & (raw.close_time <= end_ms)]
df_15m = raw[(raw.open_time >= start_ms) & (raw.close_time <= end_ms)]

# runner.py:288-292
idx_start_4h = searchsorted(df_4h_raw.close_time, start_ms)
warmup_start = max(0, idx_start_4h - 220)      # ← 代码实取 220 根
df_4h = df_4h_raw.iloc[warmup_start:]
df_4h = df_4h[df_4h.close_time <= end_ms]
```

- **4h 有预热**：最多往前 220 根（≈36 天），足够 42 根箱体 + 14 期 ATR。
- **1h / 15m 没有预热**：从窗口起点开始。状态机在窗口首日即可用预热好的 4h 建档。
- ⚠ **`config.atr_warmup_bars = 200`，代码取 220**，两处不一致且无测试锁定（已进缺口清单）。
- ⚠ 裁剪用 `open_time >= start_ms`，**不校验 `is_closed=1`**，也**不校验连续性**。
  框架侧 `backtest_runner._closed_contiguous` 有「已收盘 + 连续 + 全窗覆盖」三查，回放链没有。

## 四、数据物理形态（本轮实测）

| 项 | 事实 |
|---|---|
| OHLCV 存储类型 | **字符串**（`open/high/low/close/volume/quote_volume/taker_buy_*` 全是 str），代码用 `pd.to_numeric` 转 float |
| 时间单位 | 全部毫秒 `int64`；`open_time` 起点、`close_time` 终点（`=open+周期-1ms`） |
| `available_at` 列 | **全为 None** ⇒ 没有数据可得时刻的证据 |
| OI 列 | `ts / open_interest / open_interest_value / oi_ccy / oi_usd / source / fetched_at`，`fetched_at` 全 None |
| OI period | 全为 `5m`（COTIUSDT 实测） |
| OI 假观测 | COTIUSDT 有 **189 行 `open_interest<=0`**（占 0.037%） |
| funding 列 | `funding_time / funding_rate / mark_price / rate_type / source`；COTIUSDT 6996 行全 `settled`，无空、无 `mark<=0` |
| 数据水位 | `_state.json` 的 `watermark_ms=1791880577632`，对账水位 `2026-10-12` |

## 五、读接口链的文件来源

| 接口 | 读什么 | 不读什么 |
|---|---|---|
| `GET /backtests/batches` | `回测日志/event_trend_v0_1/runs*` 的目录名与 run 数 | 不读 `public/all_trades.json`（已废弃） |
| `GET /backtests/batches/{id}/summary` | 同批次 run 的 `summary.json` + `trades.jsonl` 行数自洽 | 不用 `null` 冒充 0 |
| `GET /backtests/{run}/metrics` | 本 run 的 `trades.jsonl` + `equity_curve.jsonl` **现算** | **不读** `summary.json` 的 `win_rate/max_drawdown`（那里根本没有） |
| `GET /backtests/{run}/chart` | `chart.json`；窗口不符 ⇒ 按 `inputs.json` 窗口**内存重建** | 不写回 run 目录 |
| `GET /backtests/{run}/trades` | `ledger_links.load_ledger_facts`（orders/positions/trades/ledger 四表关联） | 不按行号编 `trd_N` |
| `GET /backtests`（实验列表） | `回测日志/oi_resonance_v1/runs`，且只留 `WX_OI_RESONANCE_V1` | **该根 0 个 run ⇒ 恒空** |
