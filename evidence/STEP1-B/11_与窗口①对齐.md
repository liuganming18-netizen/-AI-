## 三、run 对齐：两套 run 不能互相顶替

| 用途 | run 在哪 | 数量 | 能否互相顶替 |
|---|---|---|---|
| **算得对不对**（费用/成交/净盈亏） | `evidence/ENTRY-AUDIT-03/runs/` | 176 | ❌ |

理由：
1. 两套 run 的**产物完整度不同**：批次 run 有 16 个文件（含 `chart.json`），
   EA03 run 只有 `candidates.csv / trades.csv / rejects.jsonl / run.json` 四个。
2. 两套 run 的**窗口不同**：批次里有 83 个 run 的 chart 窗口被写死在 `2024-01-01~2024-06-30`。
3. 两套 run 的**创建者不同**：批次来自根目录 `run_batch_*.py`；EA03 来自 `02_replay_full.py`。
