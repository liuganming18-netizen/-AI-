## 1. 判定顺序（必须先过样本/完整性，再看效果）

```
S1 样本量足够？ ──否──> 证据不足（不判 PASS/FAIL）
   │是
P8/P9/P10 资格/数据/指纹完整？ ──否──> INVALID（停止，修正后新版本重新累积）
   │是
P1 净期望 + P2 maxT + P3 网格 ──否──> FAIL 或 证据不足（见下）
   │是
P4 胜率 + P6 成本 + P7 极值 ──否──> FAIL
   │是
PASS
```

## 3. 与 AUDIT-09 的关系

- **复用**：指标定义（事件级 ITT、成交口径胜率、更正口径快速止损、分解）、30天块/5000次/seed=20261020、Holm/maxT、跨币/跨时间/极值检查、候选去重。
- **收紧**：
  - AUDIT-09 的"支持进入独立验证"只要求池化 CI + 网格方向 + 稳健性；本验证 **PASS 还要求 maxT<0.05**。
  - AUDIT-09 主族 18 项（含 C2−C0）；本验证确认性族收窄为 **9 项 C1−C0**（C2 已判不支持，只作负对照）。
- **不改变**：C1 的机制定义、P0、确认条件、OI、费用、风险预算、退出、预热、9 组网格。

## 4. 一句话

**C1 要在独立区间同时做到：净期望显著为正（maxT<0.05）、胜率不劣、成本压力后仍为正、不依赖极端盈利单；否则不判 PASS。**
