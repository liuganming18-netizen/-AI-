## 一、隔离长度怎么来的

不写死天数。做法是从 205 笔真实成交里量：

| 指标 | 小时 | 说明 |
|---|---|---|
| 样本数 | — | 205 笔成交 |
| 最短持有 | 20.0 | 止损/失效提前出场 |
| 中位 | 240.0 | 半数顶在最长持有期 |
| 90 分位 | 240.0 | |
| 99 分位 | 240.0 | |
| 最长 | 240.0 | 与配置上界一致 |
| 恰好顶在 240h 的比例 | 56.1% | 不是巧合，是硬平仓 |

配置里 `max_holding_days = 10` ⇒ 240 小时。
实测最大值 240.0h，与配置上界吻合，没有一笔超出。
**采用的隔离长度 = 240 小时（10 天）**，取实测与配置上界的较大者。

为什么必须留：一条样本的标签 = 入场到出场这段行情。如果训练段最后一天入场的样本持有 10 天，它的标签就用到了验证段开头的价格。不留隔离带，等于让模型在训练时偷看验证集。
