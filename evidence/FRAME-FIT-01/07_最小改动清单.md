## 三、修改文件（2 个，共两处）

### 1. `框架/backend/backtest_api.py::create_run`

插入位置：`validate_run_spec` 之后、`_spec_hash` 之前（约 959–980 行）。

```python
# ── FRAME-FIT-01：实验登记 / 冻结 / 分组使用规则闸门 ──
exp_block = (payload or {}).get("experiment") if isinstance(payload, dict) else None
if exp_block is not None and not isinstance(exp_block, dict):
    return _envelope(missing_reason="experiment 必须是 JSON 对象"), 400
clean["experiment"] = exp_block or {}
try:
    import experiment_registry as EXP
    exp_gate = EXP.guard_create(clean)
except Exception as exc:
    return _envelope(missing_reason=f"实验登记库不可用，拒绝创建：..."), 503
if not exp_gate.get("ok"):
    return _envelope(missing_reason="实验资格校验未通过（FRAME-FIT-01）",
                     experiment=exp_gate, errors=exp_gate.get("blockers") or []), 409
clean["experiment"]["experiment_id"] = exp_gate.get("experiment_id")
```

为什么要从**原始 payload** 取 `experiment` 块：`validate_run_spec` 只保留白名单字段，
`experiment` 会被丢掉。取回后显式并进 `clean`，`doc["spec"]` 才会带着它落盘，
`execute_run` 才复核得到（不靠全局变量、不靠进程内缓存）。

响应体加两个字段：`experiment`（闸门完整结论）、`formal_eligible: false`。
调用方一眼能看到「这次 run 不具正式资格」及原因。

### 2. `框架/backend/backtest_runner.py::execute_run`

插入位置：`S.read_run(run_id)` 之后、`set_status(RUNNING)` 之前（约 1410–1428 行）。

```python
try:
    import experiment_registry as _EXP
    gate_err = _EXP.guard_execute(run_id, doc)
except Exception as exc:
    gate_err = f"实验登记库不可用：{type(exc).__name__}: {exc}"
if gate_err:
    S.set_status(run_id, S.STATUS_FAILED,
                 failure_reason=f"实验闸门拒绝（FRAME-FIT-01）：{gate_err}",
                 gate="experiment_registry")
    return S.read_run(run_id)
```

为什么放在 `RUNNING` 之前：被拒的 run 不该出现「跑过」的痕迹。
放在 `read_run` 之后：闸门要读 `doc["spec"]` 里的实验块。
