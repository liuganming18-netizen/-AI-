# SYSTEM-CLOSELOOP-05｜配置身份贯通表

## 1. 贯通设计原则
在全流程闭环执行中，策略规则与执行参数（$\text{stoploss\_s}, \text{trail\_d}, \text{model\_version}, \text{config\_fingerprint}$）必须实现**同源贯通**与**不可篡改持久化**。
- **输入端**：从明确指定的隔离实验配置 JSON（`EFFECTIVE_VIEW`）加载；
- **挂单态**：在 `paper_pending` 登记时进行强校验并落盘配置快照；
- **持仓态**：由挂单自动撮合成交时，快照透传并落盘至 `paper_position`；
- **推进与退出**：引擎与常驻守护仅认准持仓记录自身的固化参数，任何外部试图通过 HTTP 请求体传入不同的参数覆盖均被 400 严格拒绝；
- **生命周期韧性**：服务重启、环境配置变更均不改变原有在途挂单与存量持仓的执行规则。
