## 十一、口径与限制

- 「水位正常」的判据是：最新 1 小时 K 线头与本小时应有值的差不超过一根。整点收盘后约三分钟内补齐，属正常延迟。
- 「零成交冻结」的判据是：成交量为零且开高低收四价全等。库里的 OHLCV 是文本型，比较前必须显式转数，否则 `"0" == 0` 为假、会把整批冻结合约漏判成正常。
- 快照「新鲜」用文件写入时刻判，阈值 `900` 秒；比率「新鲜」用数据自身的 `event_time` 判，轮转阈值 `2880` 秒。两者口径不同，不能互相代替。
- 接口里名为 `taker_buy_sell_ratio` 的字段是**实时层派生值**（按成交额现算），快照里同名的 `long_short.taker_buy_sell_ratio` 是**交易所官方比率**，两者不是同一个东西。
- 恢复前那次归档 K 线探测落在读取不稳定的窗口里：落盘记录的是「归档内无已收盘 K 线」，本报告只采用这条可复现记录，不引用未落盘的中间探测值。恢复后连续两次直读结果一致。
- 导出器日志用的是本地时间，`_export_state.json` 用的是 UTC，引用时必须先归一化，否则会得出「差八小时」的假矛盾。
