# BT-CHART-FIX-05 交付报告与验收凭据

## 一、任务背景与核心问题收口

接续 **SIGNAL-ENDTOEND-04** 与 **BT-KLINE-CONTEXT-01**，本工单针对回测复盘图表的核心体验进行系统性修复：
1. **多图时间不一致修复**：查清并统一 K 线开闭时间口径（开盘时刻与闭合时刻）、资金采样时间口径及最近点匹配规则。对齐十字虚线位置，缺少对应点时明确展示目标时点与采样偏差（如“无精确采样，最近采样 12-14 00:00”），彻底消除不同时刻伪装成同步的问题；
2. **15m/30m 周期标签与实际 K 线周期对齐**：核对请求参数、后端接口、数据聚合、缓存与渲染全流程。后端拓展支持 30m 白名单，前端根据实际数据周期进行智能识别与按需聚合，切换周期时彻底重置视图，绝无上个周期数据残留；
3. **1h 主图联动与订单精准定位**：十字线、平移、缩放全图联动；点击跨币订单（如 COMP）自动切币并精准定位到对应小时归桶与分级时刻（如 `12:15`）；图上 markers 支持反查选中订单；同小时多笔委托可清晰区分并保留精确成交时间与价格；
4. **持久重开与上下文恢复**：从回测列表选择组、币种（如 COMP）、订单后，状态自动同步持久化（URL Query 与 localStorage）。关闭页面重新打开后 100% 恢复对应记录与标的视图；补验通过了上下文行情的预算裁剪分支（budget clip）。
