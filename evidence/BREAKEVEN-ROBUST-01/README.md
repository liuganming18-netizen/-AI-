# BREAKEVEN-ROBUST-01

工单：**1R/2R 保本收益来源与集中度**（判断保本改善/损害是否依赖极少数交易）。

- 样本：**201 个事件级去重样本**（151 标的），A/B/C 口径完全沿用 BREAKEVEN-01，**未试新参数**。
- 主结论：**1R 保本的净损害 −52.90 U 押在单笔上**（PUMPBTCUSDT −56.65，占负侧 40.95%；去掉它差额翻转为 +3.75），
  而符号检验 p=0.57、t=−0.77 ⇒ 差异本身与 0 无法区分；
  **2R 保本的 +3.05 U 100% 来自一笔**，移除后与 A 逐位相同（差额 0.0000）。
- 一句话：**1R 救回报损是分散可重复的机制，掐掉利润是集中偶发的；两个方向都不构成可外推的结论。**
