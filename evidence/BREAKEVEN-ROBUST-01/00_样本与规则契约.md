## 二、三组规则（**全部沿用 BREAKEVEN-01，本单零改动**）

| 组 | 规则 |
|---|---|
| A | 初始止损 + 冻结规则 §4 的 2R 跟踪止损（4h 收盘触发、近 10 根 4h 最低价、下一根 15m 生效）+ 最长持仓 10 天 + 期末强平 |
| B | A + 浮盈达到 1R 时把止损抬到保本价（只收紧） |
| C | A + 浮盈达到 2R 时把止损抬到保本价（只收紧） |

- `R = |实际入场价 − 初始止损价|`，入场时固定。
- 保本价 = 按引擎真实撮合（滑点 + 取整 + 已发生资金费 + 已扣开仓费）后净额 ≥ 0 的价格；
  实际成交仍走引擎撮合，净额仍可能为负。
- 执行时序：先用**未抬升的**止损判本根是否打到；未打到才判本根是否达 kR；
  达到则抬升，**下一根 bar 起才可能成交**（同根先后不明一律按原止损退出）。
- **本单未触碰上述任何一条**，只读取 BREAKEVEN-01 已产出的 A/B/C 成交记录。

## 三、本单新增/复用的计算（全部在 `code/` 内，均只读上游）

| 计算 | 说明 |
|---|---|
| 事件级去重 | 复用同一规则，产出 201 行 |
| 变化交易判定 | `abs(B_net − A_net) > 1e-9`（逐位相同即「未变」） |
| 三项对账 | 少亏（正差额之和）− 错失（负差额绝对值之和）= 净差额，逐组断言 |
| 集中度 | 最大贡献占比、top-k 占比、赫希曼指数 HHI＝Σ(份额²) |
| 移除情景 | 去掉最大正贡献 / 最大负贡献 / 二者 / 前 3 大｜贡献｜ / C 唯一增益后重算三组 |
| 刀切法 | 逐个移除 28 笔变化交易，记录 B−A、C−A 的新值与是否变号 |
| 显著性参考 | t 值（逐笔净额）、符号检验（双侧二项） |
