## 优先整改问题清单（按影响严重度排序）

### 问题 1：【严重语义错位】承接与卖压指标检查时序颠倒
- **现象**：
  在 `accum_early_entry.py` 中，`_sweep_check`（扫低收回）阶段完全没有检查主动买承接与卖压；而在 `_confirm_actions`（收上压制位的确认突破根）上，才调用了 `_sell_pressure`（行 712）。
- **04-A 规则定义**：
  承接逻辑的金融逻辑是：**在扫低跌破局部支撑收回时（恐慌盘涌出瞬间），主力是否在低位吸收卖盘**。因此必须在**扫低根（`i_sweep`）**判定！作为进入 `SWEEP` / `ARMED` 的硬门槛（`absorption_is_gate=True`）。如果不达标，该次扫低作废，不应进入压制位武装阶段。
- **差异及风险**：
  04-B 将扫低时的筹码吸收判断，颠倒成了向上突破压制位时的买入量判断，彻底颠倒了策略因果关系。且 04-B 使用的是币数比值（`taker_buy_volume / volume`）对比绝对阈值，遗漏了 04-A 规范的 USDT 名义额与前 20 根中位数乘数比对。
- **整改建议**：
  1. 将承接与卖压检查从 `_confirm_actions` 移回 `_sweep_check`（在扫低收回成立后立即判定）；
  2. 若承接不达标，不迁移至 `SWEEP`；
  3. 指标改用 1h K 线的 `taker_buy_quote_volume / quote_volume` 与基准中位数比对。

### 问题 2：【严重语义遗漏】局部压制位缺失合格性检查（`resistance_qualified`）与摆动高点
- **现象**：
  `accum_early_entry.py` 中的 `_resistance` 仅实现了 `prior_n_high` 和 `box_high`，未实现 04-A 推荐的核心定义 `swing_high_k3_lookback48`（摆动高点）。更严重的是，算得压制位后，**直接在 `_confirm_actions` 中使用，完全未校验压制位是否离箱底和箱顶有足够空间**。
- **04-A 规则定义**：
  04-A 明确要求压制位必须满足合格性过滤：
  `L + 0.5A <= R_loc <= H - 0.5A`（`resistance_min_gap_atr = 0.5A`）。
  若 `R_loc` 离箱底过近（`< L + 0.5A`），5% 初始止损无法容忍波动；若离箱顶过近（`> H - 0.5A`），提前量消失，策略退化为普通突破。两者均必须终结为 `NO_RESISTANCE`（无操作空间），直接关闭事件，不生成候选。
- **差异及风险**：
  04-B 缺失该过滤，导致大量在箱顶边缘或箱底贴合处的无效压制位被当成信号，产生大量无提前空间的伪候选。
- **整改建议**：
  1. 补齐 `swing_high_k3_lookback48` 实现；
  2. 算得压制位后增加 `resistance_qualified` 门槛判定；
  3. 不合格时记录 `close_action("NO_RESISTANCE", ...)` 并终结事件。

---

### 问题 3：【严重门槛遗漏】扫低对象缺少 `s_loc > box['L']` 约束
- **现象**：
  `accum_early_entry.py` 的 `_sweep_check` 在计算 `prior_n_low` 作为局部支撑 `ref` 时，未检查 `ref > float(box["low_l"])`。
- **04-A 规则定义**：
  04-A 规定：`s_loc > box["L"]` 是局部扫低的前提。若局部支撑本身已经等于或低于箱底 L，该行为属于原策略的箱底破位扫低，绝不得计入吸筹提前入场。
- **差异及风险**：
  若不检查，一旦行情跌穿箱底，前 N 根最低价会低于箱底 L，在箱底下方发生的假反弹会被误判为局部支撑扫低，导致在严重破位区错误入场。
- **整改建议**：
  在 `_sweep_check` 中增加判断：
  ```python
  if ref <= float(box["low_l"]):
      return False, {"reason": "s_loc_below_box_low"}, []
  ```

### 问题 4：【逻辑遗漏】结构破位与压制位二次跌破失效未实现
- **现象**：
  04-B 的 `_invalid_check` 仅检查了当根是否跌破当次扫低的最低点（`sweep_low - buffer_atr * atr`）。
- **04-A 规则定义**：
  04-A 规范中包含双重全局失效保护：
  1. 箱体结构破位：连续 2 根 1h 收盘 < 箱体下沿 L，或任一根 1h 最低价 < L - 0.5A ⇒ `INVALIDATED`；
  2. 假突破跌回：收上压制位后，若连续 2 根 1h 收盘跌回 `R_loc - 0.1A` 下方 ⇒ `INVALIDATED`。
- **整改建议**：
  在状态机推进中补全上述两项失效判定，防止行情发生全局性崩塌或假突破后状态机仍在死守。

---

### 问题 5：【行为规范】未批准状态下的冷却期退化
- **现象**：
  在配置未批准时，04-B 显式将 `cooldown_ms` 设为 0，并且在触发 `blocked_config` 后立即将 `obs.done = True` 释放槽位。
- **差异及风险**：
  导致在未批准状态下扫描多个箱体时，同一标的同一天内重复建档并频繁产生 `blocked_config` 记录。
- **整改建议**：
  当配置未批准时，冷却期应安全回退至默认值 24 小时（`cooling_hours=24`），防止测试记录冗余膨胀。
