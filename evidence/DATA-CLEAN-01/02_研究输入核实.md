## 2 OHLCV：三周期逐币比对

| 数据集 | 成功 | 研究输入独有行 | 仓储独有行 | 共同行数值不一致 |
|---|---|---|---|---|
| `ohlcv_15m` | 525/526 | 1,537,183 | 16,512 | **3 行**（1 个标的） |
| `ohlcv_1h` | 525/526 | 383,863 | 0 | **29 行**（3 个标的） |
| `ohlcv_4h` | 525/526 | 95,550 | 0 | **109 行**（9 个标的） |

- **数值不一致极少**：15m 仅 3 行、1h 29 行、4h 109 行，集中在 `NEIROUSDT`（4h 82 行）、`TRUMPUSDT`、`1000PEPEUSDT`。属个别 K 线修订，不是系统性错误。
- **「研究输入独有」的 153 万 / 38 万 / 9.5 万行是什么**：不是独有数据，是 **2026-09-14 之后的增量**。

### 为什么会有增量

实测 `parquet/candles` 全池都停在 **2026-09-14**（BTCUSDT / ETHUSDT / 0GUSDT / 1000BONKUSDT / SOLUSDT 五个样本一致）。parquet 是**定期导出快照**，不是实时层。09-14 之后的数据只存在于 SQLite。

以 `0GUSDT` 为例：

| 层 | 覆盖范围 | 行数（15m） |
|---|---|---|
| parquet 归档 | 2025-09-17 ~ **2026-09-14** | 34,716 |
| 研究输入 | 2025-09-17 ~ **2026-10-14** | 37,641 |
| 差 | 2026-09-14 ~ 10-14（约 30 天） | 2,925 |

34,716 + 2,925 = 37,641，账完全对上。

### 增量能否重建：已验证可以

`candle_versions` 表存了完整 OHLCV 数值（`open/high/low/close/volume/quote_volume/trade_count/taker_buy_volume/taker_buy_quote_volume`），不是指针表。用 0GUSDT 15m 做验证：

| 检查项 | 结果 |
|---|---|
| 研究输入 09-14 之后行数 | 2,925 |
| `candle_versions` 同期行数 | 3,574（含修订版本，同一 `open_time` 多条） |
| 可匹配行数 | 3,213 |
| `open` / `high` / `low` / `close` / `volume` 不一致 | **各 0 行** |
| 研究输入有但库中无 | **0 行** |
| 库中有但研究输入无 | 361 个时间点（库更新） |

⇒ **研究输入的 OHLCV 是「parquet 归档 + SQLite 增量」的合并快照，不含任何库中没有的数据。**

### 一个仓储缺失的标的

`CTUSDT`（新上市）：parquet 只有 `live.parquet`（无年度归档文件），SQLite 有 5,037 行覆盖 2026-10-01 ~ 10-19。研究输入有它的 15m/1h/4h。**同样可从 SQLite 重建**，不构成独有数据。

### 结论

`oi_metrics` **不是可靠副本**：它在最近 1–2 个月缺字段且错位。仓储版本更完整、更准确。

这意味着两件事：
1. 删掉它**不会丢失唯一数据**（仓储有对应且更好）。
2. 但如果有人拿它做「复现旧实验」，复现出来的结果**可能是错的**——因为它和仓储不一致。

⇒ **这一条要写进待核清单，作为数据质量问题上报，不能当作纯清理事项处理。**

## 6 本目录的准确定性

工单要求区分三类。本目录的实际情况是：

| 分类 | 是否适用 | 说明 |
|---|---|---|
| 真正冗余副本 | `ohlcv` 部分适用 | 可从 parquet + SQLite 完整重建，已验证 |
| 当前运行必需输入 | **不适用** | 无进程、无代码、无定时任务读取 |
| 用于复现旧实验的冻结快照 | **适用** | v3.0 数据窗，manifest 记录 3,152 文件 / 9,462,636,530 字节 |

**它同时是「可重建」和「冻结快照」。** 这两件事不矛盾：数据可以从库里重建，但重建出来的字节不会和当年那份逐字节相同（parquet 写入的元数据、行序可能不同）。所以「可重建」只保证数据内容可恢复，不保证**字节级复现**。

这一点必须让用户知道：**如果旧实验的复现要求是「逐字节相同」，删掉就做不到；如果只要求「数据内容相同」，删掉可以重做。**
