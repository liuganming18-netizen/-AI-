### 2.1 三组提案 → 真实字段（`02_规则接口.md`）

| 问题 | 落到的字段 | 可得时点 |

| 局部压制位怎么取 | 扫低根之前 48 根 1h 内最后一个「左右各 3 根都不高于它」的最高价；找不到回退为 48 根最高 | 扫低根 1h 收盘 |
| 承接/卖压怎么判 | `taker_buy_quote_volume / quote_volume`，基准为前 20 根中位数；卖压 = `quote_volume − taker_buy_quote_volume`（推导量） | 扫低根 1h 收盘 |

| 最早何时成交 | 确认后**第一根 15m 开盘**（`+900000ms`），不回填确认根 | 该根 15m 开盘 |

不设 2R 启动门槛、不设持仓天数上限；12:00 确认 ⇒ 最早 12:15 成交。
这 8 项在 `PARAMS` 里标 `已确定`，依据直接引《用户要求与决策.md》。

## 4 三条比阈值更重要的发现

1. **提前入场的正收益全部集中在「原策略也会关注的机会」上。**

   | | 甲 | 乙 | 丙 |
   |---|---|---|---|
   | 与原策略时间窗相交的笔 R 合计 | +27.6298 | +25.7676 | +7.7032 |
   | 新增机会（不相交）R 合计 | −220.4124 | −246.2313 | −195.4463 |

   相交的那几十笔是正的，新增的几千笔把总和拉成负数。
   口径注意：「重叠」= 同标的 + 时间窗相交，**不是同一笔交易**，
   所以不能读成「同一批机会，提前进场后从 −35.54 变成 +27.63」。

2. **把扫低对象改回箱体下沿 L，机会量掉一个数量级。**
   甲组 3209 笔 → 266 笔，R −192.78 → −34.03。说明「提前」的价值来自「放宽事件链起点」，
   而不是来自「更早的触发位」。

3. **承接阈值是唯一能把结论翻正的旋钮，也是最危险的一个。**
   1.0 → 1.2 倍：甲组 R −192.78 → +6.88，丙组 −187.74 → +21.47，笔数 3209 → 1098。
   单点、方向突变、样本腰斩 —— 过拟合的标准形状。要它成立，必须在一个没看过的区间上重跑。
