## 一、物理级“五大统一底座”契约

为杜绝因环境偏置、资金差异或隐蔽放水导致的虚假有效性，三组对照实验必须运行在**物理级 100% 同构的五大底座**之上：

```
                    ┌── 1. 统一数据可见性 ──► 相同的时间窗口、闭合K线切片，绝对杜绝未来信息与泄露
                    ├── 2. 统一资金基准 ────► 初始权益严格定为 5,000.00 USDT，无外部注资
五大物理级统一底座 ─┼── 3. 统一费用规则 ────► Taker 手续费 5 bps，按不利方向计滑点，真实结算资金费
                    ├── 4. 统一成交模型 ────► 相同 15m 开盘价撮合、跳空穿越真实成交价撮合契约
                    └── 5. 统一风险硬顶 ────► 单笔风险上限恒为 0.5%，账户级最大回撤 20% 刚性熔断
```

| 底座维度 | 统一技术规范 | 违规一票否决判据 |
|---|---|---|
| **1. 数据可见性** | 仅允许访问 `close_time <= now_ms` 且已闭合的 15m/1h/4h 行情与经审核的宏观因子。三组数据输入源必须完全一致 | 任何一组出现访问未来数据、晚到数据未隔离或时间戳超越挂钟者立即废弃 |
| **2. 资金基准** | 初始名义资本严格定为 **$5,000.00\text{ USDT}$**。每组独立账本，严禁多组间资金调拨或共享账户 | 初始资金非 5000U 或存在外部注资补血者成绩无效 |
| **3. 费用规则** | 成交统一扣除 **$5\text{ bps}$（$0.05\%$）** 手续费；滑点按不利方向计提；持仓严格按行情库实际结算时间逐笔扣除真实资金费 | 假设 0 手续费、抹平滑点或未按实际结算时间计提资金费者无效 |
| **4. 成交模型** | 统一基于信号确认后次根 15m 开盘撮合；开盘跳空穿越止损时，**强制以开盘价 `bar_open` 撮合成交** | 发生跳空时仍按理想止损价成交、或事后回填历史低价者无效 |
| **5. 风险硬顶** | 单笔最大名义亏损风险上限：**$0.5\%$ 账户初始权益**（即最大单笔风险敞口 $25\text{ USDT}$）；账户级最大回撤阈值恒为 **$20\%$** | 任何调仓动作突破 $0.5\%$ 风险硬顶，或触及 $20\%$ 未触发清仓熔断者无效 |

## 二、三组实验具体定义与动作权限

```
┌──────────────────────────────────────────────────────────────────────────────────┐
│                             三组平行对照实验架构                                  │
├──────────────────────┬─────────────────────────────┬─────────────────────────────┤
│   Group A (基准组)   │     Group B (简单规则组)     │       Group C (AI 动态组)    │
│  FT-LOW4H 固定策略   │   客观多因子规则驱动动态    │     大语言模型/机器学习动态  │
├──────────────────────┼─────────────────────────────┼─────────────────────────────┤
│ · 初始止损 5%        │ · 底层策略池与 Group C 相同 │ · 底层策略池与 Group B 相同 │
│ · 4h 最低价下方 5%   │ · 动作权限与 Group C 相同   │ · 动作权限与 Group B 相同   │
│ · 无十天退出         │ · 决策频率与 Group C 相同   │ · 决策频率与 Group B 相同   │
│ · 无两倍风险启动     │ · 可解释三因子客观裁决      │ · 严格受控动作空间          │
│ · 彻底删除 3% 跟踪   │ · 绝不故意做弱              │ · 超时 Fail-Closed 安全拒单 │
└──────────────────────┴─────────────────────────────┴─────────────────────────────┘
```

### 1. Group A：固定策略基准组 (FT-LOW4H Benchmark)
- **定位**：经修复执行缺陷后的官方权威基准策略，代表无动态干预下的标准表现；
- **核心参数**（严格采用已确认事实）：
  - 初始止损比例：$s = 0.05$（入场实际成交价下方 $5\%$）；
  - 跟踪止损比例：$d = 0.05$（最新已收盘 4 小时最低价下方 $5\%$，向下取整至最小价格步进）；
  - 启动门槛：无 $2R$ 启动门槛（首根入场后收盘的 4h K 线即开始推进）；
  - 退出限制：无 240 小时（十天）硬平仓退出；
  - **禁止修改**：彻底删除 $3\%$ 跟踪止损设定，参数全局冻结。

### 2. Group B：简单规则动态组 (Rule-Based Dynamic)
- **定位**：作为 AI 动态策略的直接对照靶标，采用完全透明、可解释的经典量化规则进行动态管理，**绝不故意做弱**；
- **底层策略池**：与 Group C 100% 同构，消费完全相同的候选突破信号集合；
- **动作空间**：与 Group C 100% 对等：
  - 仅允许在 $[0, 1.0]$ 既有风险内安全收紧止损或上移保护位；
  - 允许触发保本移动（当浮盈达到 $1.5R$ 时将止损上移至成本线）；
  - 允许在极端动能衰竭时提前发出平仓退出指令；
  - **严禁放大风险，严禁下移止损**；
- **决策频率**：与 Group C 完全相同，统一在 4h K 线闭合时刻或 15m 扫描周期触发。

### 3. Group C：AI 动态策略组 (AI-Driven Dynamic)
- **定位**：引入大语言模型（LLM）或机器学习决策代理，对信号质量、市场状态与在持仓位进行动态调整；
- **底层策略池**：与 Group B 100% 同构，禁止私自扩充候选池；
- **动作权限同构约束**：
  - **风险上限硬顶**：单笔风险敞口严格 $\le 0.5\%$，彻底删除原方案中允许上调风险 $20\%$ 的越界设计；
  - **允许动作集**：仅限于（1）确认入场或安全拒单；（2）收紧当前止损；（3）动态保本平水；（4）动能衰竭平仓；
  - **禁止动作集**：严禁加仓、严禁下调止损线、严禁突破持仓名义上限；
- **决策频率与时钟**：与 Group B 同步，在相同推进时点接收相同的特征输入；
- **超时与异常防线**：
  - 决策超时阈值内未返回有效 JSON，**严格执行 Fail-Closed 安全拒单**；
  - 在持仓位严格维持既有已落盘跟踪止损线；
  - **严禁越界擅自切换系统策略模式**，绝不伪造或切换为固定组执行。

## 三、三组对照实验评估指标矩阵

三组实验必须在样本外执行期，按照统一标准进行量化打分与横向对比：

| 评估维度 | 指标名称 | 计算口径与要求 | 对照基准要求 |
|---|---|---|---|
| **核心收益** | **净收益率 (Net Return)** | 扣除所有手续费、滑点与真实资金费后的最终净收益 | 动态组收益必须扣除所有交易摩擦成本 |
| **风险调整** | **夏普比率 (Sharpe Ratio)** | 基于等频对齐的净值曲线日化收益计算 | 动态组夏普不得劣于固定基准组 |
| **下行控制** | **最大回撤 (Max Drawdown)** | 峰谷权益回撤极值 | 动态组最大回撤严禁突破 $20\%$ 熔断线 |
| **盈利能力** | **盈亏比 (Profit Factor)** | $\sum \text{盈利净额} / \sum \text{亏损净额}$ | 动态组应显现截断亏损让利润奔跑能力 |
| **信号胜率** | **胜率 (Win Rate)** | 扣除摩擦成本后的净盈利交易占比 | 结合盈亏比综合评估 |
| **因果合规** | **时序违规次数** | 发生借用历史 bar、跳空失真、漏检中间线次数 | **必须恒为 0**（发生 1 次一票否决） |
| **风控合规** | **越权调仓次数** | 突破 0.5% 风险硬顶或下调止损次数 | **必须恒为 0**（发生 1 次一票否决） |

## 四、新增门槛的待审建议性质说明

在前期讨论中提出的部分指标，具有重要的工程与经济价值，但**尚未获得最终正式验收标准批准**。依据整改要求，本协议将其性质准确归正为**有依据的待审建议（Pending Review Proposals）**：

### 建议 1：样本外前向实时检验 30 天建议 (Pending Review)
- **理论依据**：主流大语言模型在预训练时已广泛消化 2021-2024 年甚至 2025 年的公开市场行情，历史回测无法排除“记忆泄漏（Data Contamination）”；
- **建议内容**：建议在实盘或模拟盘环境下，对三组策略进行不少于 **30 个自然日**的样本外前向实时盲测；
- **性质定调**：**待审建议**。待评审委员会正式核准前向测试周期方案，不替代现有回测与代码级验收标准。

### 建议 2：模型推理响应 P95 $\le 15$ 秒建议 (Pending Review)
- **理论依据**：15m K 线明细撮合要求决策必须在时效内完成，超过 15 秒可能造成行情滑移；
- **建议内容**：建议将 AI 推理耗时纳入服务质量协议（SLA），P95 响应时间建议 $\le 15\text{s}$；
- **性质定调**：**待审建议**。作为工程系统非功能性性能指标待审，不作为业务策略正确性唯一门槛。

### 建议 3：净超额覆盖 3 倍 API Token 成本建议 (Pending Review)
- **理论依据**：动态调用大模型产生实际云端 API 账单消耗，若策略带来的超额收益无法显著覆盖其推理成本，则在商业与工程上不具备落地意义；
- **建议内容**：建议 Group C 相对 Group B 的净超额收益，应至少覆盖其消耗的 API 费用总额的 **3 倍**（$\Delta \text{Net Profit} \ge 3 \times \text{API Cost}$）；
- **性质定调**：**待审建议**。作为经济可行性测算参考待审，不替代策略统计有效性检验。

## 五、三组对照执行流程与隔离规范

1. **执行隔离**：三组必须分别运行在独立的隔离进程与独立账本文件（如 `paper_fixed.sqlite3`、`paper_rule.sqlite3`、`paper_ai.sqlite3`）中，严禁共享数据库连接；
2. **时钟同步**：统一由外部离线或实时驱动器按 15m 步长推进时间戳，三组在每个时间步必须消费完全相同的已闭合行情事实；
3. **日志留痕**：每组的每次决策（发单、拒单、调止损、超时）必须携带完整上下文快照（Context Snapshot）与哈希指纹落盘，确保每笔交易均可 100% 离线确定性复算。
