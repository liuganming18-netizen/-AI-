## 2. 二、逐笔退出规则与因果执行

### 2.1 重建方法

按冻结规则逐 15 分钟 K 线重放引擎语义：候选价取"最近一根**已收盘** 4 小时 K 线的最低价 ×(1−d)"（已收盘 = 4 小时桶起点 + 4 小时 ≤ 本 15 分钟开盘时刻）；生效止损 = max(初始止损, 上一生效止损, 候选价)；只有当"当前生效止损 < 本根最低价"时才允许调整；止损高于本根最高价时按开盘价成交。

### 2.2 核对结果

| 项 | 结果 |
|---|---|
| 可重建笔数 | **9,849 / 9,849** |
| 退出时刻与账本一致 | **9,849 / 9,849** |
| 账面止损**低于**重建止损的笔数 | **0**（不存在凭空拿到更优止损价） |
| 账面止损超出重建值 >0.2% 的笔数 | **0**（相对差中位 6.2e-05，最大 1.49e-03，全部是最小价位向上取整） |
| 非跳空成交价 = 账面止损 | **9,776 / 9,776**（已剔除 73 笔期末结算） |
| 期末结算成交价 = 最后一根开盘价 | **73 / 73** |
| 止损高于本根最高价（跳空） | **0 笔** |
| 成交价可解释（止损 / 本根最低 / 本根开盘三者之一） | **9,849 / 9,849** |
| 取整导致的边界触发 | **281 笔**（占止损退出 2.87%）：本根最低价略高于未取整止损，引擎按向上取整后的止损触发，以最低价成交 |

**跳空 0 笔**需要说明：这批样本里没有出现"整根 15 分钟 K 线都在止损下方"的情形，所以"跳空按开盘价成交"这条规则在本样本上**没有被触发过**，属于"未发生"，不是"已验证"。

### 2.3 无未来数据

- **静态**：重建全程只用 `4 小时桶起点 + 4 小时 ≤ 本 15 分钟开盘` 的 K 线，构造上不可能引用未收盘 K 线。
- **动态区分力检验**：抽样 600 笔，把规则放宽成"允许使用正在形成的那根 4 小时 K 线"（即偷看未来），**17 笔的退出时刻会改变**（2.83%）。这说明该检验在本批样本上**有区分力**（不是空转），而真实结果与"不偷看"一致。
- **同根处理**：退出那根 15 分钟 K 线上"新止损被采用"的笔数为 **0**，不存在"用退出根之后的信息回头改止损"。

### 2.4 标签不能替代机制判断（重要）

引擎给的 `exit_reason` 只有三类，而真实机制有四类。交叉表（`out/02_分类与标签交叉.csv`）：

| 引擎标签 | 笔数 | 其中：初始止损 | 跟踪亏损 | 跟踪盈利 | 期末结算 |
|---|---|---|---|---|---|
| `stop_loss` | 2,979 | **2,827** | 152 | 0 | 0 |
| `trailing_stop_loss` | 6,797 | 36 | 3,988 | **2,773** | 0 |
| `force_exit` | 73 | 0 | 0 | 0 | **73** |

三条结论：

1. **`stop_loss` 基本等价于初始止损，但不完全等价**：2,827/2,979 = **94.9%** 是初始止损，另有 **152 笔（5.1%）** 是"止损已上移、但生效止损仍低于入场价"的跟踪亏损。所以不能把 `stop_loss` 一律读成"初始止损出场"。
2. **`trailing_stop_loss` 绝不等于"跟踪盈利出场"**：6,797 笔里只有 **2,773 笔（40.8%）** 出场价高于入场价，另有 **3,988 笔是跟踪亏损**，还有 **36 笔其实是初始止损出场**。只看标签会把 `trailing_stop_loss` 整批当成盈利，实际上其中 **4,024 笔**（6,797 - 2,773）不是盈利。
3. **有 36 笔初始止损被标成 `trailing_stop_loss`**，原因是 `adjust_stop_loss` 的 `ROUND_UP` 把止损抬了一个最小价位，引擎就认为"止损被上调过"。这与项目既往结论一致（常数止损也会因取整被标成 trailing）。

判断"止损是否真的上移过"的口径是"重建生效止损 > 初始止损 P0"，全表只有 **152 笔 `stop_loss`** 和 **6,761 笔 `trailing_stop_loss`** 满足；`force_exit` 里 43 笔满足、30 笔不满足。

> 自我更正：本报告草稿曾把"账面止损因取整高于重建值"误当成"止损上移"，写成"`stop_loss` 2,979 笔中 2,849 笔（95.6%）止损已上移"。该数字无法被任何口径复现（按取整口径是 2,843，按"重建>P0"口径是 152），**已作废**，以上表为准。

按机制重建的四类构成：

| 类别 | 笔数 |
|---|---|
| 初始止损 | **2,863** |
| 跟踪盈利（出场价 > 入场价） | 2,773 |
| 跟踪亏损（出场价 ≤ 入场价） | 4,140 |
| 期末技术结算 | 73 |

逐组合看：初始止损笔数为 **0** 的组合有 **6 个** —— `S10_D05`、`S15_D05`、`S15_D10`、`S20_D05`、`S20_D10`、`S20_D15`（上游报告只点了 3 个，漏了 `S15_D10`、`S20_D10`、`S20_D15`）。原因是入场即跟踪，窄距离 d 在入场那一刻就把止损抬到初始止损之上。

### 3.3 真实权益回撤：报告的数字必须替换

主口径：15 分钟收盘盯市，`权益(t) = 2000 + Σ已实现 + Σ未平仓[(P15(t) − 开仓价)×数量 − 开仓费 − 已发生资金费]`。

| 口径 | 144 组回撤区间（USDT） | 与盯市相比 |
|---|---|---|
| **盯市 MTM（主口径）** | 18.52 / 中位 154.86 / 601.50 | — |

## 9. 九、最终回答

### 9.1 哪些结果可信？

**可信的部分：**
- 144 组确实是用修复后的基类（`5559027d…`）在 16:06–17:41 跑出来的，派生类源码逐文件比对一致，四档仓位率与 16 组合结果都没有塌缩。
- 逐笔退出链路可信：9,849 笔的退出时刻 100% 能从原始 4 小时 + 15 分钟 K 线重建出来，账面止损从未低于因果重建值，成交价 100% 可解释。
- 账户与费用可信：手续费、资金费、槽位、风险预算全部闭合到机器精度。
- 16 组合的笔数、净收益、中位、盈利组数可信（与上游一致）。

**不可直接引用的部分：**
- "最大回撤"（引擎口径，低估 15.5%~70.9%）。
- "极低回撤"这个定性结论。
- 上游 144 表的手续费与资金费（全 0）。
- 系统批次页的"每 run 笔数/盈亏"（接口读成 0）。
- "某组合稳定盈利"这类表述——见 9.2。

### 9.2 哪些组合值得冻结进入下一阶段？

**按本轮冻结的判据：没有任何一种组合达到门槛（最高 4/8）。所以不建议把任何一种冻结为生产参数。**

如果一定要给下一阶段一个**候选**（不是结论），按"盈利组数 + L2 中位为正 + ΔR 为正 + 回撤不是最大"四条同时看：

- **S10_D20**：唯一 8/9 组盈利，L2 中位 +97.79，Δ总R **+122.24**（16 组合最高），盯市回撤中位 303.94（中等）。**但**：缩尾 ±5R 后中位 −133.80、剔前 3 币后 −177.84、13 个结束日只有 5 个为正。它属于"值得继续观察"，不属于"可以冻结"。
- **S05_D20**：合计收益最高（+1,218.61），但 9 组里 2 组亏、盯市回撤最大 601.50（**28.64%**）、13 个结束日只有 3 个为正。**高收益是极端交易堆出来的**，不适合作为默认选择。
- **S05_D05 / S10_D05 / S15_D05 / S20_D05**（四个 d=5% 组合）：回撤最小（盯市中位 35.69~148.93），但收益薄、且 Δ总R 有正有负（S05_D05 是 −8.14）。适合当"低回撤对照臂"，不适合当收益主线。

### 9.3 收益与回撤的代价是什么？

1. **收益高度依赖少数极端交易**：前 5 笔盈利占净收益 **92%~282%**；把每笔盈亏在 ±5R 缩尾，16 个组合里 **9 个**中位收益转负，剩下 7 个只剩 +3.77 ~ +35.76 USDT。
2. **收益高度依赖少数上涨季度**：`S05_D15` 的利润全部来自 2023Q4（+884）、2024Q1（+955）、2024Q4（+1,609）三个季度，其余 10 个季度合计 **−2,868**；`S05_D20` 还要再加上 2024Q2（+1,311）。任何"年化稳定"的预期都不成立。
3. **收益高度依赖少数币**：前 3 个币贡献 **201%~447%**；剔掉后 16 个组合**全部转负**。
4. **回撤被系统性低估**：引擎口径漏掉未平仓浮亏，144/144 组都低估，最大低估 70.9%。
5. **换手成本不低**：手续费合计 **1,006.76 USDT**、资金费 **−1,764.14 USDT**，两项成本合计 **−2,770.90 USDT**，相当于 144 组价差毛利（7,195.01 USDT）的 **38.5%**。净收益 4,424.12 USDT 就是"价差毛利 7,195.01 − 手续费 1,006.76 + 资金费 (−1,764.14)"的结果。
6. **期末结算贡献不小**：73 笔期末技术结算 +789.74 USDT（+82.87R），这部分不是"已实现"，是按最后一根 K 线开盘价算的账面值。
7. **交易集合本身变了**：相对上一轮新增 1,358 笔、减少 373 笔、跳过 2,305 笔（19.0% 的确认信号因槽位/最小下单额没成交）。所以"本轮更好"里有一部分是**账户路径**变化，不是同一批交易做得更好。

### 9.4 是否存在可证明未参与选参的留出数据？

**没有。**

- 本批全部落在 2021-12-01 ~ 2024-12-31 这一区间；这 144 组本身就是在这段区间上比较出来的，**没有任何一段是"选参时没看过"的**。

因此，本报告所有结论都只是**样本内**结论，不能作为"策略有效"的证据。
