### 3.2 为什么重复

不是命名规则不同这么简单，有两层：

**第一层（合并逻辑失效）**：`FACTOR-ENTRY-01/enrich_unified_candidate_dataset.py:190` 的判重是

```python
if rec["symbol"] == sym and abs(rec.get("entry_time", 0) - t_in) <= 3600000:
```

用的是「入场时刻相差 ≤1 小时」，而**未成交行的 `entry_time` 是 NaN**，`abs(NaN − t_in)` 恒为 NaN，比较恒为 False ⇒ 未成交候选永远匹配不上，旧成交就被当成新记录追加了。同一文件 `:77` 处其实算过一个正确的 `(symbol, snapshot_time_ms)` 键 `existing_keys`，但**从头到尾没被使用**（死变量）。

**第二层（两次运行结论相反）**：这两行不是同一条记录抄了两遍，而是**同一个市场信号在两种回放切分下得到了相反结论**：

| | 连续回放（2021-12-01~2026-10-18） | 365 天窗口回放（group 39，2021-12-16~2022-12-16） |
| :--- | :--- | :--- |
| 箱体下沿 | 0.28777 | 0.2879015 |
| 突破收盘 | 0.3985 | — |
| 允许最高入场价 | 0.4047115 | — |
| 该 15m 开盘 | **0.40545** | 0.40545 |
| 结论 | 0.40545 > 0.4047115 ⇒ **取消** | 成交于 0.405572（= 开盘×1.0003） |

箱体下沿差 0.00013，说明两次运行形成的箱体并不相同（窗口起点不同导致建箱过程不同），于是闸门判定不同。**同一时刻、同一价格，一次被拦、一次放行。**

### 3.3 影响

- 对成交计数：**不改变** 205（未成交那条本来就不计成交）。
- 对样本数：把 227 说成「227 个样本」是**错的**，真实信号 226 个。
- 对统计：COTI 这笔 −1.75 被计入 205 的盈亏，但按现行规则它**根本不该成交**。这是「205 不是单一策略代际」的最小可复现例证（见第五节）。
