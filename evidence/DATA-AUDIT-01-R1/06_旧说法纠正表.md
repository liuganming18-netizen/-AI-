## 三、「三币」相关说法的纠正

先说一个检索事实：**在 `evidence/` 全量文本里没有「三币完整」这个字面结论**（已用 4 类关键词检索 md/json/csv/txt）。
实际存在的是下面三种用法，它们共同构成了「用三币样本代表全池」的问题：

| 原说法 | 出处（原文） | 问题 | 修正 |
|---|---|---|---|
| 「三币验证全绿」 | `BACKTEST-LOSS-03/REPORT_BACKTEST_LOSS_03.md` L110：「0.01 对 BTC（6 万）、ETH（3 千）几乎无影响，所以**三币验证全绿，问题被掩盖**」 | 原文本身就在说「三币全绿掩盖了问题」；但后续引用常只截前半句 | 引用时必须带后半句：**三币全绿不能证明无问题** |
| 「三币 0 候选」 | `Work_事件趋势第四次复核整改报告_2026-10-17.md` L198：「研究 Gate：FAIL —— 真实 2024H1 **三币 0 候选**，无统计显著性样本」 | 三币连候选都出不来 | **不能**用三币样本证明策略可用 |
| 「三币 Run 实体不完整」 | `WORK-07_三币交付第三次独立复核_2026-10-16.md` L20：「三币 Run 实体仍不完整」 | 三币连 Run 实体都不完整 | 三币只能算**抽样验证**，不是数据完整性证明 |

**统一表述（以后一律照这句写）**：

> 三币（BTC/ETH/SOL）是**抽样验证样本**，不是数据完整性证据，也不是策略有效性证据。
> 全池数据完整性以 `FACTS-DATA-v1` 的全量统计为准；策略有效性至今**未验证**（自然候选 0）。
