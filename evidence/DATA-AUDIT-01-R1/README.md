## 怎么复算

```bash
cd "/Users/boos/Desktop/威科夫因子共振趋势"
sh evidence/DATA-AUDIT-01-R1/reproduce.sh
```

它会做三件事：

1. **只读前置断言**：记录业务代码与币池文件的 sha256、记录原报告目录 30 个文件的 sha256
2. **重跑 10 个取证脚本**，产物落 `out_repro/`（**不覆盖交付的 `out/`**——采集器一直在写热库，
   重跑一次行数就变，覆盖了正文引用的数字就对不上）
3. **复算对撞**（`scripts/93_复算对撞.py`）：
   - A 段：结构性事实**必须完全相同**（0 行、列不存在、文件数、路径深度、关闭证据时点）
   - A 段：增长性事实**只报差异**（行数、新鲜度秒数、停更天数）——这是行情在写库，不是失败
   - B 段：正文里引用的每个数字**逐个回算**，对不上就判硬失败（防手抄错）
   - C 段：业务代码 sha256 未变
   - 后置：业务代码与**原报告目录**逐字节未变，否则退出码 1

单个查询的跑法见 `queries/README.md`（含两个实测踩过的坑：`PRAGMA query_only` 是连接级的、
只读连接不能建临时视图）。
