## 一、 核心指标去伪存真对照

| 指标名称 | 代码中宣传/展示标签 | 官方原始字段与物理公式 | 严肃量化语义校正（真实含义） | 滥用与误导风险提示 |
| :--- | :--- | :--- | :--- | :--- |
| **阶段均价** | `聪明钱巨鲸成本` / `站稳巨鲸成本` / `whale_cost` | $\text{VWAP} = \frac{\sum (P_{\text{close}} \times V)}{\sum V}$（取自 5m/1h K线） | **全市场成交量加权平均价格 (VWAP)**，代表该窗口内全市场所有参与者的平均成交重心。 | **严重偏误**：交易所不提供“巨鲸”私有成交明细。全市场 VWAP 绝不代表巨鲸成本；巨鲸可能在场外大宗、甚至根本未参与。 |
| **主动买卖量比** | `主动买卖比` / `买盘强` / `Taker Ratio` | $\text{Taker Ratio} = \frac{\sum V_{\text{taker\_buy}}}{\sum V_{\text{taker\_sell}}}$（Binance 官方指标） | **主动吃单买量与主动吃单卖量的比值**。反映短周期内市价单主动进攻的方向倾向。 | **严重偏误**：不识别交易者身份（机构也用市价单，散户也用限价单）；**不是净流入资金 (CVD)**，比值 > 1 不等于有增量净资金入场。 |
| **大户持仓多空比** | `大户多空` / `大户做多` / `whale_bullish` | $\text{Top Pos Ratio} = \frac{\text{Top20\% Long Vol}}{\text{Top20\% Short Vol}}$（Binance 官方指标） | **持仓排名前 20% 账户持有的多头仓位与空头仓位比值**。 | **严重偏误**：这是一个比值，**不是净买入金额或资金流**。多头比例上升完全可能是空头平仓导致的被动变化。 |
| **持仓量变动率** | `OI 6h 变动率` / `OI强增` / `oi_growth_6h` | $\Delta \text{OI}_{6h} = \frac{\text{OI}_{t} - \text{OI}_{t-6h}}{\text{OI}_{t-6h}}$（基准：币本位持仓张数） | **未平仓合约总张数在 6 小时内的相对增减率**。 | **注意口径**：必须使用币本位张数 `open_interest` 计算真实仓位增减，不可混用受币价波动影响的 USDT 名义价值 `open_interest_value`。 |

## 二、 详细公式与计算链路

### 1. 阶段成交量加权均价 (VWAP)
- **代码实现**：`metrics_feed.py::phase_avg_price`
- **输入**：`symbol`、`phase_start_ms`、`decision_ms`
- **SQL / 逻辑**：
  $$\text{VWAP} = \frac{\sum_{i=1}^n (\text{close}_i \times \text{volume}_i)}{\sum_{i=1}^n \text{volume}_i}$$
- **审计评语**：公式本身属于标准的 VWAP 计算，但函数返回字典把键名定义为 `"阶段均价"`，下游 `wyckoff_factor_resonance.py` 却直接在摘要中组装为 `"站稳巨鲸成本"`，属于典型的**展示层过度包装**。

### 2. Taker 主动买卖比
- **数据源**：币安合约官方 API `GET /futures/data/takerlongshortRatio`
- **字段**：`buyVol`（吃单买量）、`sellVol`（吃单卖量）、`buySellRatio`（比值）
- **审计评语**：该指标在短线突破时能辅助观察市价单追涨意愿，但不能作为确定性的“散户/主力行为”划分依据。

### 3. 大户持仓量多空比
- **数据源**：币安合约官方 API `GET /futures/data/topLongShortPositionRatio`
- **字段**：`longAccount`（大户多仓比例）、`shortAccount`（大户空仓比例）、`longShortRatio`（比值）
- **审计评语**：大户持仓多空比存在明显的均值回归特性，极端高位多空比往往伴随多头拥挤风险，不能简单认为“大户多空比高就必然继续大涨”。
