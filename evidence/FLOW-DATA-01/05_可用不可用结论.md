# 05 可用 / 不可用字段结论

一句话：**能用历史的只有"成交 + OI + 官方四个比率 + 资金费"这四类；"聪明钱"和"真实资金流入"只能实时看或根本拿不到。**

---

## 一、可直接用于历史回测（有长历史、口径已核实）

| 字段 | 起点 | 覆盖 | 备注 |
|---|---|---|---|
| `volume` / `quote_volume` | 2019-12-31 | 528 标的，100% 非空 | 5m 只有 2025-10-04 起 |
| `taker_buy_volume` / `taker_buy_quote_volume` | 2019-12-31 | 100% 非空 | 买量从未超过总量 |
| `taker_net_base` / `taker_net_quote` | 同上 | 派生 | 只表达主动方向 |
| `taker_buy_share_base` / `taker_buy_share_quote` | 同上 | 派生 | 两个口径分开存 |
| `cvd_base_cum` / `cvd_quote_cum` / `cvd_quote_norm` | 同上 | 派生 | 跨断档必须断开 |
| `oi_base` | 2020-09-01 | 526 标的 | 零值当缺失 |
| `delta_oi_base` | 2020-09-02 | 派生 | **唯一能判真实加减仓** |
| `delta_oi_quote` | 同上 | 派生 | 含价格效应，不能叫资金流 |
| `funding_rate` / `funding_cost` | 2020-01-01 | 526 标的 | 周期 4h/8h/1h 混合 |

## 二、可用但有明确缺口（用的时候必须带缺失标记）

| 字段 | 缺口 | 处理 |
|---|---|---|
| `top_position_ls_ratio` | **2022 年 87% 为空**（三段：01-31→05-01、06-27→09-03、09-03→12-14） | 空就是空，不许插值 |
| `top_account_ls_ratio` | 同上 | 同上 |
| `global_account_ls_ratio` | 2022-01-01→01-19 缺 19 天 | 同上 |
| `taker_ls_vol_ratio` | 2022-01-01→01-29、01-31→05-09 | 同上 |
| `oi_quote` | 小币上 `oi_quote/oi_base` 与收盘价差到 10.4% | 不能当收盘价 |

> 这三个比率字段的缺口**区间不同**，不能共用一个"2022 不可用"标签。
> 已从官方原始档案逐行确认是**上游本身就空**，不是本工程漏采。

## 三、只能实时观察（不能进历史回测）

| 字段 | 为什么不能 |
|---|---|
| `smart_money_long_avg_entry_price`（及 3 个同族均价） | 只有当前值，无历史序列；本地仅 11 天、106 个标的、137 个小时桶的残缺日志 |
| `smart_money_cohort_positions` | 同上；且是"按标记价折算的持仓市值"，不是开仓成本 |
| `smart_money_named_trader_row` | 同上；伪匿名 ID + 昵称，每标的 ≤8 行 |

这些字段可以进**实时看板**和**口径核验**，但不能出现在任何历史回测里。
硬把它们按"取回时刻"塞进历史，等于用 2026-10 的队列去解释 2022 年的行情，是典型前视。

## 四、根本拿不到（明确写死，不用别的顶替）

| 想要的 | 状态 | 不许用什么顶替 |
|---|---|---|
| 全市场多空平均持仓价 | 不可获取 | 不许用 VWAP、成交均价、`oi_quote/oi_base` 顶替 |
| 大户（top 20%）多空平均持仓价 | 不可获取 | 不许用聪明钱队列均价顶替（范围不同） |
| 真实充值/提现净流入 | 不可获取 | 不许用主动净额、CVD、ΔOI 顶替 |
| 账户级持仓与真实身份 | 不可获取 | 不许把 `topTraderId` 说成账户号 |
| 聪明钱队列成员规则 / 鲸鱼门槛 | 未公开 / 未验证 | 不许写成"保证金余额前 20%"当事实 |

## 五、名称红线（违反即视为伪造）

| 真实字段 | 允许的名字 | **禁止**改成 |
|---|---|---|
| `top_position_ls_ratio` | 大户持仓量多空比 | 聪明钱持仓、资金金额、净流入 |
| `top_account_ls_ratio` | 大户账户数多空比 | 持仓量比、聪明钱人数 |
| `global_account_ls_ratio` | 全市场账户数多空比 | 大户比、资金金额 |
| `taker_ls_vol_ratio` | 主动买卖额比 | 主动买入量、CVD、净流入 |
| `taker_net_quote` | 主动成交净额 | 资金流入、净流入 |
| `delta_oi_quote` | OI 名义额变化率 | 资金流入 |
| `smart_money_*_avg_entry_price` | 聪明钱队列平均开仓价 | 全市场多空均价 |

## 六、对反重力 FLOW-OI-01 的三条整改建议

1. **必修**：取 K 线改成 `close_time < ts`、取 metrics 改成 `ts + 5min <= ts`。
   现在是 227/227 全部用了未收盘数据（当根 7 个字段含未来 60 分钟）。改完必须重跑。
2. **必改**：`coverage_status` 从"全 COMPLETE"改成字段级，把 28/1/5 个空如实标出。
3. **建议**：`snapshot_time_ms` 与 `datetime_utc` 统一（现在 42 笔差 15 分钟）。

> 这三条我只登记，**没有改它的代码、没有改它的产出**。它交特征后我再抽查新增计算，不重跑它全套回测。

## 七、一句话总结给决策用

- 想做**主动成交 / CVD / OI** 的历史研究：数据够，口径已核实，可以用。
- 想做**大户情绪**的历史研究：能用，但 2022 年那段基本是空的，样本会掉一大块。
- 想做**聪明钱 / 真实资金流入**的研究：**做不了**，只能实时观察；任何"历史聪明钱"的说法都不成立。
