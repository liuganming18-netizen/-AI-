## 二、四项确认（逐条）

### 确认1：每个被拒候选与旧交易的对应是否可靠？——**可靠，但主键必须含策略**
- 反重力 FT-ENTRY-05/01 表 68 行，用「实验组 + 候选ID」去重。本审核**独立**判定：
  - A) 68 行**全部**确认在 FT-ENTRY-04 审计日志里被 `fill>=H` 拒单（68/68）；
  - B/C) 用**独立**重建的 FT-ENTRY-03 成交，按事件键 **`(strategy, pair, box_ms)`**（已剔除 enter_tag/candidate_id 尾部 sig-ms）匹配：
    - **分类逐行一致 68/68**（EXCLUDED_LOSS=30 / MISSED_PROFIT=17 / REJECTED_NEITHER=21）；
    - **ft03 逐行盈亏一致 68/68**（误差 0）。
- **关键教训（踩坑已纠）**：第一版按 `(pair, box_ms)` 匹配 → 141 个跨网格假匹配（同一候选事件会在 9 个参数网格各自独立成交一次），把 COTI 误判成 MISSED_PROFIT。**只有带 strategy 的主键才可靠**。这正说明「被拒候选↔旧成交」的匹配强依赖主键口径，AUDIT-05 未做此逐行主键闭环。

### 确认2：避免亏损 vs 错失盈利是否分开（不混淆净影响）？——**已单列且数值对上**
- 反重力报告：避免亏损 −251.31U(30 candidates) / 错过盈利 +405.80U(17) / 旧版也未成交 21 / 释放仓位 3 / 无法对应 0。

- 无混淆：把「避免亏损」和「错失盈利」分列、且用恒等式 `Δ= −被拒盈亏 + 新增 + 保留变化`（残差 0）控制，非混为「少做交易」。

## 三、闭环核对：反重力 ΔPnL=−157.65 **不等于**真实总差 −113.49

反重力报告称其 ΔPnL=−157.65U「严格等于 FT-04 与 FT-03 的总差额分解」。本审核用锁定 03/04 逐笔**按 (策略,候选) 独立拆 added/kept/dropped**（残差 0）：

| 项 | 值 |
|---|---|
| A 路线 03 净 / 04 净 | +396.2251 / +282.7328 |
| **A 路线真实总净差 Δ_actual** | **−113.4923 U** |
| 反重力拒单切片 ΔPnL | **−157.6581 U** |
| **缺口（actual − 切片）** | **+44.1658 U** |

全量交易级分解（残差 0）：added(−3.1644, 3 笔) + keptΔ(+4.1381) − dropped(114.4660, 55 笔) = −113.4923。
其中 **dropped 55 笔 = 47 笔被 fill≥H 拒单（03 pnl +154.4937）+ 8 笔「其它」**。

**这 8 笔「其它 dropped」**（03 成交、04 未成交、**非 fill≥H 拒单**），FT-ENTRY-04 审计显示它们被 `outside_min_max_bounds` **原边界**拒掉：
- ARPA/USDT(box 1667361600000) ×L06 三格：各 −10.0175
- ADA/USDT(box 1661644800000) ×L04 三格：各 −2.0663
- APE/USDT(box 1730692800000) ×L02 两格：各 −1.8881，**合计 −40.0277U**

**缺口算术（+44.1658 的精确来源）**：反重力切片把 dropped 全部当成 fill≥H 拒单（154.4937），而真实 dropped 只有 114.4660，故切片**多减了 40.0277**；再加 kept 重定价 +4.1381 ⇒ `40.0277 + 4.1381 = 44.1658`，恰等于缺口。**这 8 笔是缺口主因且与 fill≥H 约束无关。**

**结论（闭环）**：反重力的拒单归因在其自身口径（68 拒单 + 3 槽位释放）内**逐行成立**；但**「ΔPnL 严格等于总差额」不成立**——真实总差 −113.4923，切片 −157.6581，缺口 **+44.1658U** = 8 笔被原边界拒掉、与 fill≥H 约束无关的成交（切片多减 +40.0277U）+ kept 重定价（+4.1381U）。反重力该「闭环」表述过头。

## 四、结论：哪些归因可支持 / 哪些证据不足

**可支持（独立复算逐行对上，残差 0）**：
1. 顶部数量 71(未去重请求)/68(去重候选)/13(唯一物理事件)——口径清晰、去重正确。
2. 四层数量桥 `380 = 234 + 146`、`234 − 6 = 228`、`228 = 118 + 68 + 42`、`118 fills = 118 pass`——逐格 E1~E4 全 True。
3. 五分类中「避免亏损 30/−251.31U」「错过盈利 17/+405.80U」「旧版也未成交 21」「释放仓位 3/−3.16U」「无法对应 0」——68 行分类与 ft03 盈亏 **68/68** 一致。
4. 匹配可靠性：**主键 `(策略,候选)` 可靠**；跨策略候选须按网格分别核（不可混）。
5. 深 Δ(0.6A) 正贡献、浅 Δ(0.2A) 负贡献的方向性归因（与 AUDIT-05 一致）。
6. 审计日志存在 6 行重复记录、真实被拒数应为 **68**（不是 71）。

**证据不足 / 需修正（不得据此宣布新因子有效）**：
1. **闭环表述过头**：反重力「ΔPnL=−157.65 严格等于总差额」不成立；真实 A 路线总差 = **−113.49U**，缺 **+44.17U**（8 笔原边界拒单 −40.03U + 重定价 +4.14U）未纳入。
2. **8 笔原边界拒单的机理存疑**：同一候选在 FT-03 成交、在 FT-04 被 `outside_min_max_bounds` 拒，两侧策略源码已证一致，需进一步解释（受限于锁定产物只能确认到 reason，不能定论根因）。
3. **21 个「旧版也未成交」**只能证旧批无对应成交；其「为何未成交」（槽位/边界）需另证，不宜出强结论。
4. **特征筛选用据极薄**：FT-ENTRY-05 后三节假设检验基于 **13 个唯一候选（避免亏损 6 / 错过盈利 3 / 未成交 4）**，统计上不足以支撑任何「真/假突破筛选因子」；只够支撑「单样本量下未发现可用区分条件」的弱结论。
5. **主导演性**：结论容易受 BEL/BONK/ARPA/CHR 等少数几枚推动，勿据此宣称稳健区间。
6. **「68」数字撞车（本轮新增口径风险）**：AUDIT-04 混合目录的 `at_or_above_H=True` 行数同为 68（= A 路线 49 + Baseline 19），与「FT-ENTRY-04 去重后 fill≥H 拒单候选 68」数值相同、口径不同。后续任何报告引用「68」必须注明口径，否则必然串味。
7. **旧成交侧 49 vs 47 缺口**：AUDIT-04 目录称 03 旧成交 fill≥H 为 49 笔，独立匹配得 47 笔；差 2 源于该 H 表覆盖缺陷。本审核一律以独立重建的 03 逐笔为准。
8. 继承性限制：OI `PitMode.DECLARED` 无 fetched_at、历史规格 0 verified、研究期已被反复观察、无样本外区间 ⇒ 上述拒单归因仅对**研究期内、已锁定的 03/04** 有效，不外推。
