- 其中 **51 次走到了 OI 判定**且全部被判 `OI_UNAVAILABLE`。这与 02 单的对照（候选 51→0 / `OI_UNAVAILABLE` 0→51）**完全一致** ⇒ OI 门槛是候选归零的直接原因。
- 但 **1,255 − 51 = 1,204 次在到达 OI 之前就已失效/过期/仍在观察** ⇒ **即使把 OI 门槛关掉，也不等于候选会大量出现**。这一点必须写清，避免「关掉 OI 就好了」的误判。
