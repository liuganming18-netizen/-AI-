## 6 契约缺口（缺字段 ⇒ 判「未验证」，不伪绿）

| 编号 | 缺什么 | 后果 | 现状 |
|---|---|---|---|
| C-01 | `/api/v1/data/pool-scope` 不返回快照时点（`snapshot_utc` / `updated_at`） | 第 1 段无法算数据年龄与新鲜度 | 该段固定判 `unv`，页面明写缺口编号 |
| C-03 | 无「冷库（parquet 归档）全量覆盖」接口 | 第 3 段冷库侧只能写「未验证」 | 热库侧正常判绿，冷库侧不冒充已补齐 |
| C-05 | 账本接口不返回最近一次写入时点 | 第 6 段只能给「本次读取成功时刻」 | 不把读取成功当成写入成功 |
| GAP-01 | `/api/v1/paper/stops/{pos_id}` 非法入参返回 500 而非 4xx | 展开区该项记为接口缺陷 | 已在展开区标注 |
| GAP-02 | 交易所名大小写不敏感、非法值静默回落 | 请求写错交易所仍返回 200，易误判 | 展开区标注，不作为判定依据 |
| GAP-03 | `/api/v1/markets` 的 `limit` 参数不生效 | 返回行数与请求不符 | 展开区标注 |

## 7 复现方法

```bash
cd evidence/DATA-CANVAS-01
# 1) 起同源取证代理（页面 + /api/v1 同一 origin，带请求日志与故障注入）
python queries/fault_proxy.py --port 8912
# 2) 四态一次跑完：构隔离库 → 推进时间 → 起隔离后端 → 截图 → 收工
bash queries/run_all_states.sh
# 3) 重新生成报告与哈希清单
python queries/make_report.py
```

隔离纪律：`ISOLATED_MODE=1` 且 `MARKET_DB`/`LIVE_DB`/`PAPER_LEDGER_DIR`/`PAPER_LOCK_DIR` 等全部显式指向 `/tmp/dc01/<态>/`，后端启动时强校验，缺一项就拒绝启动；端口 8901~8904 启动前检查占用、启动后校验监听 pid 与本次启动 pid 一致，不一致即中止（防止连到上一轮的旧实例）。

四态怎么造：

| 态 | 制造方式 |
|---|---|
| 正常 | 心跳钉到 now-3s，各周期闭合水位推到当前应闭合的那根 |
| 停止采集 | 心跳回拨 3 小时、`status=no_messages`，且**不跑**心跳推进循环 |
| 缺数据 | 删掉 300 个标的的 15m 覆盖、15m `last_close` 回拨 4 小时；心跳正常推进（证明「采集在跑但数据缺」） |
| 接口失败 | 数据侧正常，截图后由代理把 `/api/v1/paper/accounts` 注入 500，再点刷新重截 |
