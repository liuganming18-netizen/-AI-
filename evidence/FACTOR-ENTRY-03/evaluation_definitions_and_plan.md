## 二、入场质量（“接盘”）的全新评价标准冻结

为了避免单一二分类阈值的局限性，本轮同时采用**多时窗连续数值收益**与**解耦分类**：

### 1. 连续微观价格变动收益
- `fwd_ret_15m`：入场后 15 分钟（次根 15m K 线收盘）相对于入场价的价格变动百分比；
- `fwd_ret_1h`：入场后 1 小时（4 根 15m K 线收盘）的价格变动百分比；
- `fwd_ret_4h`：入场后 4 小时（16 根 15m K 线收盘）的价格变动百分比。

### 2. 固定早期观察窗口 (Fixed Early Window)
设定两个固定时间尺度的标准化观察窗口（不受后续止盈止损策略离场时间影响）：
- **4 小时窗口 (Early 4h Window)**：包含入场后的前 16 根 15m K 线；
- **24 小时窗口 (Day-1 24h Window)**：包含入场后的前 96 根 15m K 线。

在窗口内计算：
- `mae_r_4h` / `mae_r_24h`：以入场时刻 4h Wilder ATR(14) 归一化的最大不利偏离；
- `mfe_r_4h` / `mfe_r_24h`：以 4h ATR 归一化的最大有利偏离；
- `first_adverse_vs_favorable`：
  - 记录价格首次达到 -0.3 ATR 的时间戳 $t_{adv03}$ 与首次达到 +0.3 ATR 的时间戳 $t_{fav03}$；
  - 若 $t_{adv03} < t_{fav03}$：判定为“先不利下杀”；
  - 若 $t_{fav03} < t_{adv03}$：判定为“先有利上攻”；
  - 若同根 15m K 线同时触及或先后无法判断：严格标记为 `UNKNOWN_SAME_BAR`，绝不编造顺序；
  - 若持有窗口因数据集末尾不足 4h 或 24h：单列标记为 `INSUFFICIENT_WINDOW`。

### 3. 解耦分类标签
综合连续数值与路径行为，解耦为四类典型状态：
1. **入场即弱 (Immediate Weakness / 接盘)**：
   - 条件：入场后 4 小时收益为负 (`fwd_ret_4h < 0`)，且 4h 内未产生有效上攻 (`mfe_r_4h < 0.5`)，同时最大下杀深度 `mae_r_4h >= 0.5`（或先触及 -0.3 ATR）。
2. **先涨后回吐 (MFE Pullback / 假突破回吐)**：
   - 条件：曾产生显著有利幅度 (`mfe_r >= 1.0`)，但随后回落，最终平仓净收益 `net_pnl <= 0`。
3. **持续主升 (Sustained Trend)**：
   - 条件：入场后平稳推进，`mfe_r >= 1.5` 且最终平仓获利 `net_pnl > 0`。
4. **窄幅震荡 (Choppy / Neutral)**：
   - 其余在成本线附近无显著单向运动的交易。

### 4. 成本与基准口径
- ATR 基准：入场候选产生时即时闭合的 4h K 线 Wilder ATR(14)；
- 手续费口径：真实撮合 Taker 0.05% 单边；
- 资金预算：固定 2000 USDT；
- 缺失值一律保持 NaN，不填 0、不向前回填。

## 三、研究四维指标与入场质量关联的归因方案

按信号当时可用信息深入探查：
1. **维度 A：入场几何位置 (Geometry)**
   - 突破 K 线涨幅 `bar_return_1h`
   - 突破 K 线上影线比例 `upper_shadow_ratio_1h`
   - 买价距箱体上沿 ATR 距离 `breakout_atr_dist = (p_entry - box_high) / atr_4h`
2. **维度 B：主动成交流 (Flow)**
   - 主动买入量占比 `taker_buy_ratio_1h = tb_vol / vol`
   - 主动买入额占比 `taker_buy_quote_ratio_1h = tb_quote / quote_vol`
   - 主动买卖量比 `taker_ls_ratio_1h = tb_vol / max(vol - tb_vol, eps)`
   - 明确总成交量、主动买入量、比值与占比的物理区别。
3. **维度 C：持仓多空结构 (Structure & OI)**
   - 4h OI 变化率 `delta_oi_4h`
   - 全市场多空账户比 `retail_account_ls_ratio`
   - 大户持仓多空比 `top_position_ls_ratio`
   - 大户账户多空比 `count_toptrader_ls_ratio`
4. **维度 D：市场状态与费率 (Regime & Cost)**
   - 最新已知已结算资金费率 `funding_rate`
   - 已闭合日线趋势状态 `market_regime` (BULL / SIDEWAYS / BEAR)

## 四、两个待选入场假设提炼要求
本轮根据归因数据，最多提出两个具有清晰数据支持的假设，每个假设须明确：
- 解决何种入场问题（针对“入场即弱”还是“假突破回吐”）；
- 依赖什么时点已知信息；
- 会付出何种代价（错失哪些赢家）；
- 设定明确的可证伪失败标准。
若指标无显著稳定区分能力，如实得出“现有数据尚不支持新增过滤”的客观结论。
