### 七阶段（必须按顺序、逐工单验收）
1. 环境与基础框架：启动、重启、配置、接口、任务、日志、健康与权限。
2. UI页面和组件：保持既定深蓝紫三栏、四主导航、右侧模拟盘；先用标明演示的Mock数据验收K线、画线工具、AI对话、筛选与交互；不改变已定格局。
3. 历史数据统一治理及实时接入：复用已授权的原始K线/OI等数据，统一读取，不重复采集或复制整库；核验来源、缺口、可得时间、去重、断点恢复、冷热分层与白名单实际瘦身。
4. 回测环境：先用固定事件与测试信号验收历史时钟、禁止未来数据、保守模拟成交、费用、资金费、量化规则、风控及账本；与后续实时模拟共用核心逻辑，账户/时钟隔离。
5. 真实数据可视化：在第二阶段已验收的同一套页面接入真实K线、OI、回测结果和动态运行状态，不重新设计UI。**历史回测页面必须有可交互K线图**，支持逐根回放、图形、信号与交易定位；用户提供的示意图片不是布局模板。
6. 按规则接入信号：量化计算与筛选持续触发AI行为分析；AI在K线上提出支撑、阻力、箱体、趋势、承接/派发区域和失效线，并给出支持证据、反证、时间与版本；已批准量化规则优先约束执行，独立风控拥有否决权。AI研究判断与执行许可分离。
7. 实时行情驱动的模拟持仓：正式信号经过量化与风控校验后，驱动仅模拟的入场、动态资金分配、持仓管理、退出与核算；AI故障时风险管理继续运行；不接真实交易。

### Data角色与回测验证
- 项目内持续运行的是后台计算/量化/AI服务，**ChatGPT Data不是7×24小时行情进程**。
- Data每日对全市场信号、未入选样本、误报、漏报、失效、回测与模拟表现进行复盘，**只生成有证据的优化建议**，不自动修改策略、筛选、风控或模拟账户。
- 建议先在隔离环境验证，再由用户批准。回测同时验证AI行为识别能力与交易执行效果，采用时间推进、Walk-Forward及样本外；历史AI回放必须区分当时已记录判断与今天模型重评。
- 量化规则不能剔除：客观计算、筛选条件、信号校验与风险管理均保留；风控硬限制不能被AI解释或评分抵消。
