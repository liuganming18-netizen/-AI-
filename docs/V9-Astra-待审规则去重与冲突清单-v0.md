## C. 不可静默覆盖的冲突与待决

1. **AI报告留存**：既有基线为关键全文最近100份、旧摘要留存；新口径“全文全量无损保存”冲突。标记 DECISION_REQUIRED，不能按新口径直接实施。
2. **AI开仓门禁**：R02的“双确认必需”与既有“AI故障可量化降级”需明确不同运行模式；降级不可伪称AI复核通过，风险限制不可绕过。
3. **两套状态机**：趋势五态描述市场结构；既有信号状态 EARLY_OBSERVATION / RESONANCE_CONFIRMED / TRACKING / INVALIDATED / SUSPENDED_DATA 描述信号生命周期。分别维护并建立版本化映射。
4. **8h缺失**：既有数据质量门禁要求受影响分析降级；“最高只能接近触发”是候选假设，不能直接改写客观趋势阶段。
5. **数据源和历史**：Binance主源、OKX有条件补充；生命周期关联不得拼接无来源标记的价格序列；市值和USDT指标不得未经来源审计参与评分。
6. **进度与阶段**：A/B/C/D为技术分层，不能替换既有十模块逐个验收与UI先验收的执行门禁。
