# 视觉质感升级 · 交付说明（2026-10-19）

## 一句话

在**不动框架、不动业务逻辑、不加依赖**的前提下，把四个页面从「框套框、字碎、线多」调到「简洁 + 有质感 + 图表好读」；顺手修掉一个存在很久的硬伤：深色主题的品牌色是蓝的（浅色是绿）。

## 一、这次改了什么

### 1. 设计令牌（`src/design/tokens.css`）

| 项 | 改法 | 为什么 |
|---|---|---|
| 深色品牌色 | 蓝 `#3b6df6` → 品牌绿 | 同一产品两套主题两种品牌色，是硬伤 |
| 深色中性阶梯 | 蓝黑（饱和 44%）→ 中性石板灰（饱和 8–14%） | 蓝底会把绿数字衬黄、红数字衬紫，涨跌色永远「不正」 |
| 浅色中性阶梯 | 绿灰 → 冷中性灰；文字三级拆成三档 | 绿灰底让盈利绿「陷进去」；标题和正文原本同色，层次拉不开 |
| 字号阶梯 | 10/11/12/13/15/20/26 → 11/12/13/15/17/22/28 | 原阶梯四档挤在 3px 里，等于没有阶梯 |
| 字重纪律 | 只用 400/500/600，700 只留页面主标题 | 12–13px 中文在 700 下笔画粘连，越粗越糊 |
| 圆角 | 4/6/12/14 + 散落硬编码 8 → 4/8/12/16 四档 | 一屏出现五种圆角，眼睛「觉得不对但说不出哪不对」 |
| 阴影 | 分层：卡片托底 / 浮层 / 一律不给按钮和指标卡 | 一屏带阴影元素 ≤ 3 个，否则阴影变成背景噪声 |
| 动效 | 110/160/240ms + 新缓动 | 旧曲线两头都慢，短时长下「按下去没反应然后突然到」 |

新增 14 个变量（`--ds-row-line`、`--ds-accent-fg`、四组 `-bg-soft`、四个字重、`--ds-shadow-card`、`--ds-dur-slow`、`--ds-ease-out`、`--ds-7/--ds-10`、`--ds-chart-order`），**旧变量一个没删**。

### 2. 组件层（`components.css` / `shell.css` / `backtest.css`）

- **框套框从规则层消灭**：一条规则让卡片内的指标卡、表格外框、折叠区、提示条一律去描边改底色 —— 四页 40+ 张卡同时变干净。层级只允许出现在「表面色」上，一屏最多两层边框。
- **表格从 Excel 感变报表感**：表头去灰底、字号降一档（11）、只留一条分界线；行高 24→30；行线单独用一个更淡的令牌；悬停不再整行变绿（绿只留给选中行）；数字列与列头同侧右对齐。
- **徽标四重信号降到两重**：去描边、去等宽字体（中文在 mono 下字距不匀）、字重降一档。
- **提示条从整块黄底改成左侧 2px 竖线 + 近中性底**：眼睛对垂直短色条远比大面积浅色块敏感，警示性不减、压迫感大减。
- **侧栏当前项**：浅绿底 + 2px 品牌竖线 + 一级文字（原来是整条绿字，形成「绿柱子」）。
- **策略管理页**：整页接入新体系（4 卡 28/600、8 个列表项去描边、6 个阶段块去重阴影、选中态统一为「底色 + 左侧竖线」）。
- **数据中心瓦片**：去掉图标块第三层底色、10 个彩色图标统一中性灰、选中态从五重信号收到两重。
- **涨跌色退回涨跌**：表头两列、持仓额（恒定量）、每日增量全部改中性色。一屏彩色数字从 7 个降到 4 个，且每一个都是会变的数。
- **循环动画清零**：5 处常驻呼吸点全部静止，只保留异常态一处；补 `prefers-reduced-motion` 兜底。

### 3. 图表（`chartTheme.ts` / `LightweightChart.tsx` / `EquityCurvePanel.tsx` / `LabFundingPanel.tsx` / `InlineExpandedChart.tsx`）

- 竖网格全关（它与蜡烛影线重叠，是纯噪声）；横线只在 K 线与净值曲线保留，成交量与 OI 不画。
- 价格轴去掉竖线；刻度只画完整的；刻度密度调稀；顶部留 12% 底部 8%，蜡烛变高又不贴边。
- 最新一根右侧留 2 格呼吸；窗口缩放时视窗不再跳（`lockVisibleTimeRangeOnResize`）；拖不到第一根左侧的空白。
- 净值曲线改面积图 + 16%→0 渐变、线宽 2、关掉末值脉冲。
- 标记全部缩到最小尺寸、颜色全部走调色板（含新增的委托色令牌），深色下对比度 6.4–9.8:1。
- **一条写进纪律的原则：不把折线掰弯**。曲线平滑会在两个真实采样点之间画出不存在的形状，在量化工具里等于视觉造假 —— 「流畅」指交互跟手与渲染稳定，不是把线画弯。

## 四、还剩什么没做（下一轮可选）

1. **价格小数位**：聪明钱均价仍是 12 位小数（`84674.24367409`），应改成按量级自适应。属于数据格式化，牵动格式化工具函数，单独做更稳。
2. **工作台右栏文案换行**：「实际成交 · 在持仓位(0)」在窄栏里断成两行，需要缩短文案而不是改样式。
3. **数据中心「归档与任务队列」8 行小方块**仍是「边框 + 深底」，是最后一处框套框。
4. **一屏字号仍有 5 种**（11/12/13/15/22），规格要求 ≤4；把表头并回 12 即可，但会牺牲一点表头/数据的区分度，留待你定。
5. **工作台左栏空态占位过大**：无信号时那块 200×500 的空态把主内容挤到右边，建议折叠成一行。
