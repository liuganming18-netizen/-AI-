## 一、五维评分

| 维度 | 评分 | 一句话证据 |
|---|---|---|

## 三、必须整改项

### P0 — 不改不能交付

#### P0-1 图表标记体系脱离调色板，深色下数据标记不可读

- **页面 / 区域**：回测复盘页 K 线图（`浅_backtest_图表区.png`、`深_backtest_图表区.png`）
- **现在是什么样**：
  1. 同一张图上出现 **4 种标记形态**：绿箭头（开仓）、红箭头（平仓）、蓝色方块 + 文字「候选」、紫色圆点（委托）。其中蓝、紫两色**不在调色板内**。
  2. 像素实测：方块 `(29,78,216)`=`#1d4ed8`、圆点 `(124,58,237)`=`#7c3aed`、箭头 `(4,120,87)`=`#047857`。源码对上：`LabChartPanel.tsx:238 color:'#3b6ef6'`、`:257-259` 的 `#1d4ed8 / #7c3aed / #64748b`、`:196/:207` 的 `#047857 / '#b91c1c'`、`:247 LAB_STOP_COLOR='#b45309'`。**六个硬编码色全部绕过 `chartTheme.ts`**，而该文件自己的第 1 条纪律就是「不许在组件里写字面量」。
  3. 深色下这些色值不变（硬编码），对比度复算：`#047857` = 3.34:1、`#1d4ed8` = 2.73:1、`#7c3aed` = 3.21:1 —— **数据元素低于规格 C6 要求的 5:1**，落在「装饰上限 2.6:1」与「数据 5:1」之间的禁区。
  4. 选中标记 `size: sel ? 2 : 1`，双倍箭头 + `text: '开仓(选中)'` 文字标签，箭头宽度约等于 2–3 根蜡烛，**直接把蜡烛压住**（放大图可见平仓箭头覆盖其所在那根 K 线）。
  5. `#3b6ef6` 正是规格 D1 明令要消灭的那个品牌蓝（旧 `--ds-accent` 深色值）。
- **应该改成什么样**：
  1. 六个硬编码色全部改为读 `ChartPalette`：开/平仓箭头用 `p.up` / `p.down`；候选方块、委托圆点新增两个令牌（如 `--ds-chart-signal`、`--ds-chart-order`）并在 `VAR_MAP` 里登记，**深色必须单独给值**（建议深色用 `#7ea6ff` 一类的亮蓝，保证 ≥5:1）。
  2. `size` 去掉 `2`，统一 `1`；`text` 去掉，改为悬停/点击后由读数条承担文案（`KlinePanel.tsx:88/98` 的 `'买入'/'卖出'/'平仓'` 同样处理）。
  3. 一屏只保留 2 类标记（成交箭头 + 候选方块），委托圆点收进「显示委托」开关，默认关闭。
- **依据**：规格 C4「`size: 1`」「`text: ''` 不加文字」；C6「数据必须 ≥5:1，中间地带不许放东西」；D1「`#3b6df6` 在 tokens.css 里 0 命中」；`chartTheme.ts` 文件头纪律 1。

#### P0-2 策略管理页整页未进入新体系（框套框、700 字重、层级倒挂）

- **页面 / 区域**：策略管理页全页（`浅_strategy_顶部.png`、`light_strategy.png`、`dark_strategy.png`）
- **现在是什么样**：
  1. 页面用 `bg-neutral-900/90 border border-neutral-800 rounded-xl` 手写卡片，**没有吃到 `.ds-card` 的新描边 / 新内边距**；卡内又套了 14 个带描边的块（8 个列表项 + 6 个阶段块）。规格 B1 的核心目标「一条规则消灭四页的框套框」在这一页没有生效。
  2. 8 个策略列表项标题全部是 `font-bold text-emerald-400` —— 一根 176px 窄栏里 8 个绿色 700 标题，正是 B9 要消灭的「绿柱子」在原地重演；且 12px + 700 违反 A4。
  3. 选中阶段块 `shadow-md`，内层阴影比外层卡片重，层级倒挂；未选中块 `border-neutral-850` 几乎看不见，选中块 `border-emerald-500/50` 又很重 —— 同一列表里两种强度的描边并存。
  4. 4 张指标卡用 `text-2xl font-bold`（24px / 700），规格要求 28px / 600（A3 表 + A4）。
  5. 页面里 `text-[10px]` / `text-[11px]` 密集出现，靠 `index.css` 抬到 12px 兜住，但 `font-bold` 遍地都是。
- **应该改成什么样**：
  1. 所有 `bg-neutral-900/90 border border-neutral-800 rounded-xl` 换成 `.ds-card`（或至少把 `border-neutral-800` 换成 `--ds-border-subtle`、补 `--ds-shadow-card`）。
  2. 8 个列表项去掉描边，改 `background: var(--ds-surface-2)`；标题改 `color: var(--ds-text)` + 500，**绿色只留给选中项**，选中项用「底色 + 左侧 2px 品牌竖线」（与 B1 瓦片、B9 侧栏同一套语言）。
  3. 6 个阶段块去掉 `shadow-md` 与描边，改「底色差」区分选中；序号 `01` 的绿色保留（这是唯一允许的彩色），标题改 `600`。
  4. 指标卡数字改 `28px / 600`。
- **依据**：规格 B1、B4、B9、A3、A4、A5；验收清单「任取一张卡片，卡内可见的矩形描边数量 ≤ 1」。

#### P0-3 涨跌色被当成「强调色」用，语义失效

- **页面 / 区域**：工作台行情表、工作台右栏、数据中心 FEEDS 表（`浅_workbench_表头区.png`、`浅_workbench_右栏.png`、`浅_datacenter_瓦片与日志.png`）
- **现在是什么样**：
  1. 行情表**表头**用涨跌色：`<th className="text-emerald-400">4. 聪明钱多头</th>` / `text-rose-400 5. 聪明钱空头`（`TokenTable.tsx:985/987`）。表头是「列的名字」，规格 B3 要求表头统一 `--ds-text-4` 最弱一档。
  2. **持仓额**（恒定量，不随时间涨跌）用涨跌色 + 700：`text-emerald-400 font-bold` / `text-rose-400 font-bold`（`TokenTable.tsx:524/537`）。规格 B8 明写「恒定的量（持仓量、总资金、胜率）用 `--ds-text`，不用彩色」。
  3. 数据中心右栏 FEEDS 表 8 行增量（`+0.01 MB` … `+0.6 MB`）全部为绿 —— 增量大小不是涨跌。
  4. 工作台右栏 `盈亏多少: $0.00 / $0.00` 在盈亏为 0 时仍着绿。
  5. 结果：工作台一屏 7 个彩色数字、数据中心 8 个，**涨跌色不再表示涨跌**，用户扫表时无法靠颜色定位真正的变动。
- **应该改成什么样**：
  1. 表头两列改回 `--ds-text-4`；「多头 / 空头」的方向语义交给单元格内的箭头图标或 `多 / 空` 字样。
  2. 持仓额改 `--ds-text` + 500，去掉 700。
  3. FEEDS 增量改 `--ds-text-2`；只有「异常 / 停更」才允许彩色。
  4. 盈亏为 0 时不取涨跌色，用 `--ds-text-2`。
  5. 目标：一屏彩色数字 ≤ 4 个，且每一个都是「会变的数」。
- **依据**：规格 B3（表头 `color: var(--ds-text-4)`）、B8「涨跌色用法」段、验收清单「一屏内彩色数字 ≤ 4 个」。

### P1 — 该改（影响品质）

#### P1-1 数字精度未收敛，最该「人性化」的地方读不动

- **位置**：行情表「聪明钱多头 / 空头」列的「均价」（`浅_workbench_表头区.png`）
- **现在**：`均价: 84674.24367409 USDT`（12 位小数）、`均价: 78435.42565087 USDT`。一屏两处，宽度被撑满，读者要先跳过 12 位小数才看到量级。
- **应该改成**：按价格量级自适应小数位（≥1000 保留 1–2 位、≥1 保留 2–4 位），完整值进 `title` 提示。同一列的小数位必须一致。
- **依据**：用户原话「流畅图表人性化」；规格 A3 三条硬规则之外的可读性原则（数字是给人读的，不是给机器打印的）。

#### P1-2 右栏长值溢出卡片被硬裁，无省略号

- **位置**：工作台右栏「模拟实盘持仓」的「参数来源」行（`浅_workbench_右栏.png`、`/tmp/z3_L_param.png` 3 倍放大）
- **现在**：`参数来源: fallback_frozen_v2_2_conser` —— 在卡片右边缘被**直接切断**，没有省略号，读者会以为数据坏了。而且它是内部标识符，本身就是不可读内容，还占用了琥珀色（全栏唯一的琥珀色块之一）。
- **应该改成**：容器加 `min-width: 0` + 值加 `overflow: hidden; text-overflow: ellipsis; white-space: nowrap`，`title` 放全值；或换成人类可读的短名（如「冻结参数 v2.2」）。颜色改 `--ds-text-3`，把琥珀留给真正的告警。
- **依据**：规格 A5 / B2「值不得溢出容器」的精神；B4「彩色是信号，不是装饰」。

#### P1-3 深色下空态四项键值几乎不可见

- **位置**：工作台右栏「实盘仓位（只读）」空态底部（`浅_workbench_右栏.png` 底部、`/tmp/z4_L_kv2.png` 与 `/tmp/z4_D_kv2.png`）
- **现在**：`账户 / 连接状态 / 持仓方向 / 入场均价` 四项实测 浅色 `#d2d7de` / 白 = **1.39:1**，深色 `#3a424c` / `#0e1014` = **1.87:1**。这已经不是「弱化」，是「渲染失败」的观感。
- **应该改成**：即使按禁用态处理（WCAG 对禁用控件豁免），也请提到 `--ds-text-4`（浅 4.16:1 / 深 4.59:1），并把值统一为 `—`。禁用态靠「底色」和「不可点」表达，不靠「看不清」。
- **依据**：规格附录二对比度表（四级文字是下限，不许再往下）；Anti-Slop 清单「文本对比度不达标」。

#### P1-4 数据中心 17 个瓦片图标用了 6 种色相，「绿红是唯一彩色」不成立

- **位置**：数据中心「全域数据名称状态图标看板」（`浅_datacenter_顶部.png`、`/tmp/z5_tiles_light.png` 与 `/tmp/z5_tiles_light2.png` 3 倍放大）
- **现在**：K 线 6 个瓦片是蓝（`sky-400`）、资金费率是紫（`purple-400`）、衍生品多空比与聪明钱是琥珀（`amber-400`）、资产概览是绿（`emerald-400`）、主动买卖量差是青（`cyan-400`）、持仓量/流通是品红（`fuchsia-400`）。根因是 `DataCenterView.tsx:785-794` 逐行写死 Tailwind 色，而 `index.css` 只把 neutral / emerald / rose / amber / sky 映射到令牌，**indigo / purple / cyan / fuchsia 是裸色**（`--color-indigo-*` 还被刻意留成「品牌蓝紫」）。
- **应该改成**：图标统一 `--ds-text-4`（灰）；「数据源类型」的区分交给图标形状本身（现在形状已经不同了，够了）。最多允许「异常」一种彩色。
- **依据**：规格 D2 / A1 设计意图「让绿/红成为屏幕上唯一的彩色」；Anti-Slop 清单「同一页面使用 4+ 种不同颜色」。

#### P1-5 瓦片内「图标块」还有一层底色，框套框只拆掉一层

- **位置**：同 P1-4 的瓦片（3 倍放大图可见每个图标外面还有一圈浅灰圆角方块）
- **现在**：层级是 卡片(白) → 瓦片(`surface-2`) → 图标块(`bg-neutral-800/60`) → 彩色图标，**仍是三层底色**。规格 D2 把「瓦片内图标块有底色」明确列为要消灭的层级。
- **应该改成**：`DataCenterView.tsx:784` 的 `p-1.5 rounded-md bg-neutral-800/60` 改为透明，图标直接坐在瓦片底色上。
- **依据**：规格 D2；B1「层级只允许出现在表面色上，且一屏最多两层」。

#### P1-6 选中瓦片是四重信号，与 B1 的选中态规格相反

- **位置**：数据中心选中瓦片「资金费率」（`浅_datacenter_顶部.png`）
- **现在**：`bg-[var(--ds-accent-50)] border-[var(--ds-accent)] ring-1 ring-[var(--ds-accent-100)] shadow-sm` + 标签 `font-bold` + 标签变绿（`DataCenterView.tsx:767/799`）= 底色 + 实色描边 + 第二圈 ring + 阴影 + 绿色粗字，**五重**。
- **应该改成**：只留「`--ds-accent-50` 底色 + 左侧 2px 品牌竖线」，去掉 `border` 与 `ring` 与 `shadow-sm`，标签改 `--ds-text` + 600。
- **依据**：规格 B1「选中态：只留「底色 + 一条 2px 品牌线」，去掉 ring-1 的第二重信号」。

#### P1-7 表格数字列对齐不一致，出现「头左尾右」
