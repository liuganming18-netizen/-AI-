## A. 令牌层（`src/design/tokens.css`）

### A0. 结构不变，只换值 + 加变量

延续现有架构：**中性阶梯 `--ds-n-950…100` 是唯一事实源**，语义令牌一律写成 `var(--ds-n-*)`；浅色块只覆盖「不跟随阶梯」的部分。本次新增的变量按现有习惯命名（`--ds-` 前缀 + 短横线分段），全部追加，不删任何一个旧名。

### A3. 字号阶梯：新阶梯与用途映射

| 变量 | 旧值 | 新值 | 允许用在哪（白名单） | 禁止用在哪 |
|---|---|---|---|---|
| `--ds-fs-2xs` | 10 | **11** | 徽标内文字、脚注、图例色块旁的单位 | 正文、表格单元格 |
| `--ds-fs-xs` | 11 | **12** | 表格全部文字、密集标签、`.ds-note`、`.ds-stat__label`、`.ds-card__meta`、图表外图例 | 正文段落 |
| `--ds-fs-sm` | 12 | **13** | 正文、按钮、输入框、侧栏导航、`.ds-kv` | 卡片标题 |
| `--ds-fs-md` | 13 | **15** | 卡片标题 `.ds-card__title`、次级区块标题 | 正文 |
| `--ds-fs-lg` | 15 | **17** | 页面区块标题、侧栏品牌名 | 卡片标题 |
| `--ds-fs-xl` | 20 | **22** | 指标数字 `.ds-stat__value`、页面主标题 h1 | 表格 |
| `--ds-fs-2xl` | 26 | **28** | 主指标数字（回测页 4 张主指标卡） | 其余任何位置 |

**为什么这么排**：11 / 12 / 13 三档密、15 / 17 两档疏、22 / 28 两档开。小字密是为了信息密度，大字拉开是为了「一屏之内只有 2–3 个大字」。旧阶梯 10/11/12/13 四档挤在 3px 里，等于没有阶梯。

**三条硬规则**（构建师必须遵守）：

1. **任何承载正文语义的文字 ≥ 13px**。12px 只允许出现在「表格 / 标签 / 说明」这类**可扫不可读**的位置；11px 只允许出现在徽标内部。
2. **`index.css` 第 214–218 行的「抬底到 12px」保持不动**。它抬到的 12px 正好等于新的 `--ds-fs-xs`，于是「被抬底的 Tailwind 小字」和「表格文字」终于同档，不再出现 12 与 11 并存。
3. **同一屏内字号种类 ≤ 4 种**。超过 4 种说明有地方用错了档位，回到上表核对。

### A4. 字重纪律

- 允许：`400`（正文、说明）、`500`（按钮、导航、输入值）、`600`（标题、关键数字、强调）。
- 禁止：`700` 出现在 13px 及以下的任何位置。
- `700` 唯一合法位置：`.ds-pagehead__title h1`（22px 页面主标题）。
- 需要「更重」的视觉时，用**颜色加深一档**（text-3 → text-2）或**加 0.5px 字距**，不要加粗。

### A5. 阴影使用表（哪一层用什么、什么时候不用）

| 层级 | 用什么 | 什么时候**不**用 |
|---|---|---|
| 页面画布 | 无 | — |
| 卡片 `.ds-card` | `--ds-shadow-card`（浅色=1px 托底；深色=内顶高光）+ 1px `--ds-border-subtle` 描边 | 卡片里再套卡片时，内层**不用阴影** |
| 内嵌块（卡内的 `.ds-stat` / `.ds-details` / `.ds-metrics-inline`） | 无阴影、无描边，只换底色 `--ds-surface-2` | 永不加阴影 |
| 浮层（`.ds-toolbar`、弹窗、抽屉、下拉） | `--ds-shadow-md`；抽屉/全屏弹窗用 `--ds-shadow-lg` | — |
| 按钮 | **不加阴影**（含主按钮） | 全部 |
| 表格 / 图表 | 不加 | 全部 |

**一句话**：一屏内带阴影的元素 ≤ 3 个。超过 3 个，阴影就不再表达层级，而是变成背景噪声。

### A6. 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 悬停 / 聚焦 / 描边变色 | `--ds-dur-fast` (110ms) | `--ds-ease` |
| 展开 / 折叠 / 抽屉 | `--ds-dur` (160ms) | `--ds-ease` |
| 弹窗进出 | `--ds-dur-slow` (240ms) | `--ds-ease-out` |

**该动**：`color`、`background-color`、`border-color`、`box-shadow`、`opacity`、`transform`。
**不该动**：`width` / `height` / `top` / `left` / `font-size`（触发布局重排，掉帧的元凶）；任何循环动画（呼吸、流光、扫光 —— 项目已清理，不要加回来）；`prefers-reduced-motion` 下全部关掉（骨架屏已有先例）。

## C. 图表规范（`chartTheme.ts` + `LightweightChart.tsx`）

> 本节所有选项名都对着 `node_modules/lightweight-charts/dist/typings.d.ts`（5.2.1）逐条核对过，**没有编造的 API**。核对不到的（例如 `lastValueColor`）不存在，不要写。

### C0. 先把桥接补上（`chartTheme.ts`）

`layout.fontFamily` 与 `layout.fontSize` 是图表配置里**唯一两个必须由 CSS 侧提供**的值。canvas 不解析 CSS 变量，所以必须把字体栈的**字面量字符串**读出来传进去。

```ts
// 【新增】ChartPalette 增加一个字段
export interface ChartPalette {
  // …原有字段不动
  /** 图表文字字体栈：必须传真实字符串，canvas 不认 var() */
  font: string;
}

// 【新增】VAR_MAP 增加一行（注意读的是 --ds-font，不是 --ds-chart-*）
const VAR_MAP: Record<keyof ChartPalette, string> = {
  // …原有映射不动
  font: '--ds-font',
};

// 【新增】两个兜底对象同步加 font 字段（值必须与 tokens.css 的 --ds-font 完全一致）
// LIGHT_PALETTE.font = DARK_PALETTE.font =
//   '-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", system-ui, sans-serif'
```

**⚠ 这里有一个真实的坑**：`getComputedStyle().getPropertyValue('--ds-font')` 返回的是**原始声明文本**，不是解析后的值。所以 `--ds-font` 在 `tokens.css` 里必须保持「字面量写法」，**不能改成 `var(--ds-font-base)` 之类的嵌套**，否则读出来的字符串会是 `var(--ds-font-base)`，canvas 直接回退成默认衬线体，图表刻度会突然变字形。

### C2. 逐项说明（为什么是这个值）

| 项 | 值 | 理由 / 反例 |
|---|---|---|
| `layout.background` | `--ds-chart-bg`（= 卡片色） | 图表底色必须与卡片同色，否则会出现「卡片里又一张卡片」的第五层框 |
| `layout.textColor` | `--ds-chart-text`（浅 `#6e7681` 4.6:1 / 深 `#8c939e` 5.9:1） | 轴文字要能读，但必须明显弱于数据（数据 5.3–9.8:1） |
| `layout.fontSize` | `12` | 11px 在 125% 缩放的显示器上会糊；13px 会让四位数刻度互相挤压 |
| `layout.fontFamily` | `p.font` | 不传就回退成库默认字体，与全站字体不一致，轴上的中文（`万`/`亿`）会变形 |
| `layout.attributionLogo` | `false` | 保持现状（页面已有可见文本链接，合规不变） |
| `grid.vertLines.visible` | **四类图全部 `false`** | 竖线与蜡烛影线、柱子边缘重叠，视觉上等于「加密了的噪声」。时间位置靠时间轴刻度 + 十字线就够了 |
| `grid.horzLines.visible` | K 线 / 净值 `true`；成交量 / OI `false` | 横线的作用是「把高度换算成数值」。柱状图的高度由柱子本身表达，再加横线只会切碎柱群 |
| `grid.*.style` | `Solid` | 虚线网格在浅色下会碎成点，看起来像渲染错误 |
| `crosshair.mode` | `Normal` | 见上（Magnet 会跳） |
| `crosshair.*.style` | `Dashed` + 1px | 实线十字线会把图切成四块，观感像「报错」 |
| `crosshair.labelBackgroundColor` | 浅 `#3a424c` / 深 `#4a5462` | 库的十字线标签**文字色固定为白**（没有 `labelTextColor` 这个选项），所以底色必须够深才达 AA |
| `rightPriceScale.borderVisible` | `false` | 价格轴竖线是纯装饰，去掉后绘图区更「宽」，且不会与卡片右内边距形成双线 |
| `rightPriceScale.scaleMargins` | `{top: 0.12, bottom: 0.08}` | 库默认 `{top: 0.2, bottom: 0.1}`，蜡烛偏矮。0.12 让蜡烛变高又不贴边 |
| `rightPriceScale.entireTextOnly` | `true` | 关闭时，顶/底角标会画出被裁掉一半的文字（项目已踩过这个坑） |
| `rightPriceScale.tickMarkDensity` | `2.8` | 默认 2.5；调到 2.8 刻度少一格左右，轴更干净。**不要超过 3.5**，会稀到读不出刻度 |
| `rightPriceScale.minimumWidth` | `72`（保持） | 两图对齐必须靠它，见既有 `alignPriceScaleWidths` |
| `timeScale.rightOffset` | `2` | 最新一根贴着右边框时，十字线在最右侧的标签会被切；留 2 根空档后「还能往右拖一点」的手感也在。**两图必须同值**，否则 `fitContent` 后的窗口不同（按逻辑范围同步不受影响） |
| `timeScale.fixLeftEdge` | `true` | 拖到第一根左侧的空白区是纯粹的挫败感来源 |
| `timeScale.fixRightEdge` | `false` | 锁死右侧会让 `rightOffset` 失效 |
| `timeScale.lockVisibleTimeRangeOnResize` | `true` | **这是「顺滑」的一个真实来源**：默认 `false` 时，窗口尺寸变化会重算可见范围，图会「跳一下」。设为 `true` 后缩放窗口时视窗稳定 |
| `timeScale.minBarSpacing` | **不要改（保持默认 0.5）** | 有人会想设成 1.5 防「蜡烛糊成一片」，但这会**挡住首屏落位**：500 根 K 线铺满 700px 只有 1.4px/根，`fitContent` 与 `applyInitialViewport` 都会被这个下限顶回去，蜡烛铺不满（项目踩过同类坑） |
| `handleScroll` / `handleScale` | `true` | 滚轮缩放、拖动平移、捏合全部走库原生，不要自己写 |

**折线 / 面积（净值曲线、回撤曲线）**

```ts
chart.addSeries(AreaSeries, {
  lineColor: p.pos,                 // 或 p.neg（回撤曲线）
  lineWidth: 2,                     // 1 太细（在 2x 屏上会断），3 太抢
  lineType: LineType.Simple,        // ★ 不要用 Curved
  topColor: withAlpha(p.pos, 0.16), // 渐变上端 16%
  bottomColor: withAlpha(p.pos, 0), // 渐变下端 0%（完全透）
  crosshairMarkerVisible: true,
  crosshairMarkerRadius: 3,
  crosshairMarkerBorderColor: p.background,   // 描边用底色 = 白圈，与背景融合
  crosshairMarkerBackgroundColor: p.pos,
  lastValueVisible: true,
  priceLineVisible: false,
  lastPriceAnimation: LastPriceAnimationMode.Disabled,  // ★ 关掉末值脉冲
});
```

**为什么不用 `LineType.Curved`**：曲线平滑会在两个真实采样点之间「画出一条不存在的数据」——在量化工具里这是**视觉层面的编数据**。用户要的「流畅」指交互跟手与渲染稳定，不是把折线掰弯。**这条要写进设计纪律：图里不允许出现数据点之间被平滑出来的形状。**

**为什么关掉 `lastPriceAnimation`**：它是「末值点呼吸」，在实时刷新（每几秒一次）时会持续闪，属于装饰性动画，违反「不做装饰性动画」的既有纪律。

### C5. 「顺滑」到底从哪来（真实可控项，按贡献排序）

1. **不重建实例**（已实现）：主题切换走 `applyOptions`，数据更新走 `update()`，缩放位置不丢。
2. **`lockVisibleTimeRangeOnResize: true`**（本次新增）：窗口尺寸变化不再重算视窗。
3. **数据增量更新**（已实现）：`isIncrementalTail` + `update()`，不整表 `setData`，视窗不重置。
4. **双图按逻辑范围同步**（已实现）：同一时间点落在同一 x，横向拖动时两张图不错位。
5. **`rightOffset: 2`**（本次新增）：拖到最右时还有一点余量，不会「顶到墙」。
6. **`autoSize: true`**（已实现）：靠 `ResizeObserver`，不用监听 window。
7. **网格与轴降噪**：视觉噪声少，眼睛追踪十字线更快 —— 这是「主观顺滑」的最大来源。

**不要去调**：`barSpacing` / `minBarSpacing`（会与首屏落位打架）、`crosshair.mode = Magnet`（纵向跳）、任何自己写的 `requestAnimationFrame` 补间（库内部已经是逐帧渲染）。

### C6. 一句话原则：图里什么是数据、什么是装饰

> **数据 = 蜡烛、柱、线、标记、价格线；装饰 = 网格、坐标轴、十字线、边框、底色、图例。**
> **装饰的对比度必须 ≤ 2.6:1（对图表底色），数据必须 ≥ 5:1。中间地带（3–4:1）不许放任何东西。**

| 轴分界线 `#e3e6ea` / `#262c35` | 1.23 / 1.18 | 装饰 ✔ |
| 十字线 `#98a1ab` / `#4e5764` | 2.62 / 2.50 | 装饰上限 ✔ |
| 轴文字 `#6e7681` / `#8c939e` | 4.59 / 5.91 | 参考读数（唯一允许的中间值，因为它是文字） |

## 附录一：构建师最容易做错的 14 件事

1. **把「去描边」做成 `border: none`**。会改变盒模型尺寸，整页布局位移 1–2px。正确做法：`border-color: transparent`（保留宽度）。
2. **把 sticky 表头改成透明底**。滚动时下面的行会从表头穿过去，字叠字。必须用不透明的 `var(--ds-surface)`。
3. **把 `--ds-fs-sm` 改成 13 之后忘了表格限高**。`.ds-tablewrap--tight` 等三个常量是按 24px 行高算的，行高变 30 后每档会少显示一行，看起来像「数据丢了」。
4. **把 `--ds-accent` 改成绿色后，深色主题的主按钮仍写 `color: #fff`**。亮绿配白字只有 2.99:1，不达 AA。必须换成 `var(--ds-accent-fg)`。涉及 `.ds-btn--primary`、`.ds-opt[aria-pressed]`、`.ds-nav__idx` 选中态、`.ds-tf[aria-pressed]` 四处。
5. **给 `.ds-card__head` 加分隔线**。四页 40 张卡 = 40 条线，直接毁掉「简洁」。
6. **把 `.ds-table` 的 `font-size` 改成 13**。表格是 `--ds-fs-xs`（12），正文才是 13。表格用 13 会横向溢出，尤其工作台行情表（`min-width: 1210px` + `table-layout: fixed`）。
7. **忘了 `--ds-font` 必须保持字面量**。一旦嵌套成 `var()`，图表字体桥会读到 `var(--x)` 字符串，canvas 回退成默认衬线体，轴上的中文变形。
8. **给 `timeScale.minBarSpacing` 设了值**。会挡住首屏「铺满全部已加载数据」的落位，蜡烛被压到右侧一小条。
9. **`rightOffset` 只改了一张图**。K 线改 2、OI 仍 0，`fitContent` 后两图窗口不同（按逻辑范围同步不受影响，但用户点「全部」时会看到差异）。两图必须同值。
10. **用 `:has()` 或 `[class*=...]` 去改数据中心的瓦片，却不写注释**。这类选择器依赖 Tailwind 字符串，Tailwind 升级会静默失效。每条都必须在注释里写明「依赖哪个字符串、失效时怎么发现」。
11. **给 `.ds-stat` 加阴影「让它更立体」**。一屏 8 张指标卡 = 8 个光源，立刻廉价。指标卡永远不加阴影。
12. **在提示条里保留彩色徽标**。改造后提示条底色是 `--ds-warn-bg-soft`，徽标底色是 `--ds-warn-bg`，两者几乎同色，徽标会看起来「没有底」。必须按 B7 末尾把提示条内徽标压成中性。
13. **只改 `.ds-page` 的左右内边距、忘了 `.ds-pagehead`**。页头是滚动容器的**兄弟节点**（不在 `.ds-page` 里），它自己写死了 `padding: 16px 22px 0`。把 `.ds-page` 的左右改成 24px 而页头仍是 22px，标题会和内容差 2px —— 2px 的错位比 10px 更难受。两者必须同值，本次统一保持 22px。
14. **给 `.ds-note` 写 `border-color: transparent` 来去描边**。这是四条边一起清，左侧那条语义竖线会跟着消失，提示条退化成一块没有身份的小灰块。必须逐边清（见 B1 的代码块注释）。
