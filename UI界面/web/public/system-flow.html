判定纪律：只有「已验证可用 / 等待条件 / 故障 / 未验证」四态，外加子项级「不适用」；未验证不计入通过。 HTTP 200 只作为“接口可达”的前置条件，不作为业务结论。
同源：本画布与交易工作台读取同一组 /api/v1 接口（相对路径、同 origin），不另设数据通道、不读本地文件、不直连交易所。
三池分母不混用：下载池（全部合约目录）／展示池（工作台列表）／策略监控池（信号引擎 universe）分别标注来源与排除规则，数字不同是口径不同，不是缺失。
