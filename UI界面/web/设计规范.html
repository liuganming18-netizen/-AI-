趋势研判系统 · 设计规范

这是一套「量化研究终端」的界面语言：克制、以数据为中心、深色与浅色双主题。规范分三层 —— 令牌层（颜色 / 字号 / 间距等原子值）、组件层（按钮 / 卡片 / 表格等可复用块）、 页面层（页头、区块导航、工具条的固定组合）。所有层级只允许向下引用，不允许跳层硬编码。

01

设计原则

四条原则按优先级排列。发生冲突时，序号小的优先。

1

数据优先于装饰

界面存在的唯一目的是让数字可读、可比、可信。任何不帮助读数的渐变、光晕、动画都应删除。分隔用 1px 描边，不用色块堆叠。

2

缺失就说缺失

取不到的数一律显示 —，绝不用 0 冒充。空态文案要说明「为什么空」，而不是「暂无数据」。

3

层级靠结构与字重，不靠颜色

颜色只承担语义（涨跌 / 通过 / 告警 / 选中）。主次关系用字号、字重、间距、描边表达，这样在任何色觉条件下都成立。

4

数字等宽且不跳动

所有数值走 --ds-mono + tabular-nums。同一列的数字必须右对齐、位数对齐，刷新时不允许横向抖动。

主题开关的四个约束
约束做法为什么
切换入口 <html data-theme="dark|light"> 令牌挂在属性选择器上，属性一换全站重算；不用给任何组件传参。
首屏不闪 在 <link rel="stylesheet"> 之前跑一段内联脚本 判定顺序 ?theme= → localStorage['wk-theme'] → 缺省深色。放到 CSS 之后就必然先画一帧默认色。
原生控件跟随 两套主题里都声明 color-scheme 否则滚动条、<select> 下拉、日期选择器仍是系统浅色，出现「半深半浅」。
图表跟随 setTheme() 先写 DOM 再 setState 图表用 getComputedStyle 读令牌取色；先 setState 会在同一帧读到旧值，图例与 K 线颜色错位。
图表颜色是「数据级」的，不是「选项级」的
lightweight-charts 的 series.applyOptions({ color }) 管不到成交量柱、买卖标记、指标柱的已写入数据。 切主题时必须 setData() / setMarkers() 重设一遍，否则会出现「坐标轴变了、柱子还是旧色」。
踩过的坑：强调底上的文字不能用 accent-700
选中态（分段控件当前项、当前导航项、--accent 徽标）都是「accent-50 底 + 深蓝字」。 深色主题里 accent-50 本身就是深蓝，再叠 accent-700（#2449bb）只剩 2.2:1，文字等于消失。 正确做法是引入 --ds-accent-text：深色取 accent-300（5.8:1），浅色取 accent-700（6.9:1）。

动效

只做「状态变化」的过渡，不做装饰性动画。三档时长：120ms 悬停/焦点、 180ms 面板展开、260ms 布局位移。缓动统一 cubic-bezier(.4,0,.2,1)。 所有动画必须响应 prefers-reduced-motion。

栅格与等高

单屏仪表盘用 12 列栅格排布：.ds-col-7 / .ds-col-5 左右并排， .ds-col-6 等宽对分，.ds-col-12（默认）整行。 窄于 1200px 时并排一律退化为整行堆叠 —— 退化的只是排布，不隐藏任何内容。

同一排的两张卡片，高度由「高的那张」决定，矮的自动拉伸对齐。 这件事交给栅格层完成（.ds-dash 的 align-items: stretch + 两级 flex）， 不要在页面里逐张调像素去凑等高 —— 并排时行高取两侧的较大值，只压一侧永远不够。

一屏之内看完的前提是「一行做完一件事」。下面三类原语负责把内容压回单屏， 它们只改变「什么时候出现」，不改变「有没有」。

类名用途与约束
.ds-bar .ds-bar__label .ds-bar__sep单行工具条：标签在左、控件在右、align-items: flex-end。用于「运行配置」「收益指标」这类一行放完的控件行。

20

图表配色

图表是回测页的核心视图，配色必须与语义色一致：策略净值用强调蓝、买入持有基准用黄、 回撤用负向红、涨跌沿用绿涨红跌。基准永远比策略弱一档，避免喧宾夺主。 所有图表色都落在 --ds-chart-* 上 —— lightweight-charts 拿不到 CSS 变量， 运行时由 chartTheme.ts 用 getComputedStyle 读出后传进图表配置。

令牌用途当前值

使用准则

写代码时对照这组正误示例。判据只有一条：新代码里不允许出现硬编码的色值、字号、间距。

✓ 应该这样做
  • 用 var(--ds-text-3)，不用 #6b7a91
  • 用 padding: var(--ds-3)，不用 padding: 12px
  • 数值容器加 ds-num / ds-table__num
  • 语义色三件套成组使用（fg + bg + border）
  • 缺失值输出 —，并在旁边说明为什么缺
  • 长数字截断 + title 保留完整值
  • 空态写清「空的是什么 + 为什么 + 怎么解决」
✕ 不要这样做
  • 硬编码 #fff / 13px / 7px 这类散值
  • 用强调蓝表达盈亏（盈亏只能用 pos / neg）
  • 用颜色深浅表达层级（层级用结构 / 字重）
  • 缺数据显示 0（会让「无数据」被读成「收益为零」）
  • 一个视图里出现两个 primary 按钮
  • 用 transition: all（会连带布局属性一起动画）
  • 空态只写「暂无数据」
