# 第一模块：项目启动与基础行情

这是独立新项目的第一个最小可运行版本，不包含真实交易功能。

## 运行条件
需要 Node.js 20 或更新版本，并且运行环境能够访问币安合约公开行情接口。

## 启动
在仓库目录运行：

```bash
npm start
```

浏览器访问 http://127.0.0.1:3000 。

## 当前范围
- 内置轻量服务，提供页面与行情转发接口。
- 获取币安真实合约K线，显示价格蜡烛图和成交量。
- 支持输入交易所原始代币代码，支持5分钟、15分钟、30分钟、1小时、4小时、8小时、12小时、1天。
- 提供中文加载状态、错误提示和手动刷新。
- 不包含自动扫描、人工智能分析、回测、模拟仓位和实盘交易。
